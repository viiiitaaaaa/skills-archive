Её задача (14.10.2026): одно окно вместо кучи; она диктует голосом поток указаний в «Главную», Claude там
раскладывает на задачи по категориям и запускает их во вкладках; ей видно, кто работает, кто ждёт, сколько %.

## Перезапуск после правки кода
**Самой НЕ перезапускать никогда**, даже на «обнови пульт»: перезапуск обрывает Claude во ВСЕХ вкладках посреди
работы (14.10.2026 оборвал вкладку «Проверка пульта вживую»). Вместо этого — ей одной строкой «перезапусти пульт,
когда удобно». Свои правки проверять проверочной копией (ниже), её окно не трогать.
Как перезапускает она (для справки): `Get-Process electron | ? Path -like '*pult*' | Stop-Process -Force` → `explorer.exe "C:\Users\User\Desktop\Пульт агентов.lnk"`.
Только через explorer: запуск из сессии Claude передаёт CLAUDE_CODE_CHILD_SESSION, и вкладки перестают сохранять
разговоры (в main.js чистится `cleanEnv`, но через explorer надёжнее). Её открытые вкладки вернутся через `--resume`.

→ запустить `node_modules\electron\dist\electron.exe .` → посмотреть снимок. Ошибки окна — в stderr со словом RENDERER.

## Проценты задач
Вкладке передаётся env `PULT_SESSION`; `~/.claude/agent_status.py set` записывает его в поле `session`,
`agent_status.py json` отдаёт пульту. Правило «задача из 3+ шагов → табло» — в глобальном CLAUDE.md.

## Журнал шагов (приём Traces из Langflow, 14.10.2026)
`agent_status.py` пишет в задачу поле `log` — каждую смену стадии со временем (последние 50); `agent_status.py log <id>`
печатает «время · стадия [N] — сколько длилась». В `json` поле уходит пульту как есть.
Сам Langflow не ставим: он гоняет модели по API, а подписку Claude в чужие оболочки не подключаем.
В пульте: 📜 у задачи слева раскрывает журнал (самый долгий шаг оранжевым, «↺» — повторить один шаг);
шаблоны частых задач — массив `TEMPLATES` в `apppp.js` (добавлять туда: категория, название, текст «Готово = …», число шагов).

## «📝 Мои дела» (15.10.2026)
Её дела-напоминания (не вкладка Claude): `pult\dela.json` (не в git). Вкладки пишут:
`python C:\Users\User\pult\razdat.py todo --text "<что сделать>" --from "<вкладка>"`. Окно — `app\dela.js`
(кнопка под «Главной» со счётчиком); main.js `dela:load` / `dela:op` (добавить/галочка/удалить поверх свежего файла)
и следит за файлом. Для проверок — `PULT_DELA=<temp.json>`.
Строка внизу списка (текст или голос golos): `dela:ask` → одноразовый `claude -p --model claude-sonnet-5-5 --tools ""`
в temp-папке отвечает JSON `{reply, ops}` (done / archive / restore / add / edit), меняет файл сам пульт. «Не нужно» —
поле `archived` (архив, тусклый раздел); насовсем дела не удаляются.

## Грабли
- Электрон не скачался при npm install → `node node_modules\electron\install.js`.
- В папке-категории Claude один раз спрашивает «trust this folder»; в домашней `C:\Users\User` — каждый запуск.
- Распознавание речи браузера (webkitSpeechRecognition) в Electron не работает — поэтому свой голос golos.js.
- Проверочные фразы в копии — только безобидные: «Спроси у Perplexity…» ушло в её Pro настоящим вопросом.
- `--resume` пустого разговора сразу выходит → пульт сам начинает новый (проверка «вышел за 6 с»).
- Подписку Claude в сторонние оболочки (Hermes, OpenClaw) не подключать — бан; пульт запускает сам `claude.exe`, это можно.
