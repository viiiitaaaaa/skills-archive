# Hermes — помощник на лёгкие задачи

Итог: лёгкая часть сделана Hermes и **проверена мной**, сложная — сделана мной; в ответе ей одной строкой —
что делал Hermes («🤖 Hermes: пересказал 40 постов»).

## ГЛАВНОЕ с 25.10.2026 (её слово, отменяет «лёгкое → Hermes» ниже)
Ollama — только по её прямому вызову. Сама не отдаю ничего, даже лёгкое: у неё мало лимита Ollama, он — подстраховка
на важное («если будешь бездумно использовать — когда потребуется важное, их не будет»). Позвала — делаю через Hermes.

## Правило (её решение 13.10.2026; действует только когда она сама позвала Hermes)
- **Лёгкое → Hermes.** Сложное, «где надо думать» → **всегда я**, не отдавать.
- **Сомневаюсь** в сложности → спросить её через AskUserQuestion: перечислить части задачи,
  у каждой «Hermes / Claude», мой вариант первым с «(Рекомендую)». Спрашивать только при настоящем сомнении.

## Лёгкое (отдавать)
Механика без решений и без её правил, где работа объёмная (много читать/писать):
- пересказ/выжимка длинного текста, страницы, лога; перевод;
- посчитать/найти/перечислить файлы, вытащить список или таблицу из текста;
- черновое форматирование текста, переименование подписей, простые справки.
Если задача — одна короткая команда, быстрее и дешевле сделать самой (вызов Hermes тоже тратит мой лимит
на постановку и проверку). Отдавать, когда Hermes сэкономит мне чтение большого объёма.

## Сложное (только я)
Решения и оценки (отбор товаров, поставщики, радар, цены), юр. документы и дела, код и скрипты, сайт и дизайн,
всё, где действуют её правила из памяти/скиллов, многошаговые задачи, удаление/перенос/отправка наружу,
деньги, входы в аккаунты, Excel-таблицы её проектов.

## Данные
Hermes = облако Ollama: те же ограничения, что любое облако — 🟢 можно, 🟡/🔴 НЕ отдавать (см. память dannye-komu-mozhno).
Ключи, пароли, личные данные людей из дел — никогда.

## Как вызвать
```
& "$env:LOCALAPPDATA\hermes\bin\hermes.exe" -z "<задача: что сделать, где, в каком виде ответ>" --in "<рабочая папка>"
```
- Пиши задачу полностью и конкретно (он слабее меня): путь, формат ответа, «только прочитай, ничего не меняй».
- Её решение 13.10 «не перегружай»: мои фоновые задачи — **2 потока**, третий слот оставлять ей.
- Бесплатный тариф Ollama: не больше **3 одновременных** вызовов (8 → HTTP 429 «too many concurrent requests»).
  Она пользуется Hermes и сама (Telegram, с 13.10) — её запросы тоже в этом лимите.
- Не давать `--yolo`. Таймаут 300000 мс; обычно 15–60 с.
- Если ответ «waiting for the provider to recover» / `Errno 10061` — выключена Ollama: запустить
  `& "$env:LOCALAPPDATA\Programs\Ollama\ollama app.exe"`, проверить `http://127.0.0.1:11434/api/version`, повторить.

## Большой текст — в запросе, не файлом (урок 13.10)
Пересказ книг через `hermes -z "прочитай файл …"` провалился: агент читает файл своим инструментом не целиком,
вместо страниц ставит номера строк и выдумывает правила/шаблоны/цифры (Co-Intelligence — 12 ошибок, Storytelling with Data — 10).
Для пересказа/перевода/выжимки текста звать модель Hermes напрямую, текст внутри запроса, кусками ≤ ~8 тыс. слов:
`POST http://127.0.0.1:11434/api/chat {"model":"gpt-oss:120b-cloud","stream":false,"messages":[{"role":"user","content":"<задание>\n<<<ТЕКСТ\n…\nТЕКСТ>>>"}]}`
+ в задании «строго только то, что в тексте, ничего не придумывай». Образец — `C:\Users\User\knigi_kupleno\hermes_pereskaz.py`
(run_direct): ~14 с на кусок, страницы по меткам верные. `hermes -z` оставить для задач с действиями на ПК (найти, посчитать файлы).

## Цена проверки (урок 13.10)
13 книг: пересказ моделью Hermes бесплатно, но помощники Claude (Opus) сверяли с оригиналом целиком — ~4 млн токенов,
38% сессии за ~2 ч. В следующий раз: помощники на Sonnet, сверка ВЫБОРОЧНАЯ (только то, что идёт в итог: цифры,
шаблоны, кейсы; целиком — лишь подозрительно короткие куски); можно добавить автопроверку пересказа самой моделью
Hermes (разбить на утверждения, сверить с текстом куска, ≥80% верных — годно).
Проверено 13.10 вечером: 2 книги, помощники на Sonnet с выборочной сверкой — ~0,7 млн токенов вместо ~4 млн, у Hermes
нашли по 8 ошибок на книгу (выдуманный рецепт, перевранный кейс, «стр.» = номер куска). Так и делать дальше.

## Аккаунт Claude — Hermes только на Ollama (14.10)
Подписку Claude (вход OAuth) к Hermes и другим сторонним клиентам **не подключать никогда** — это прямой повод для бана
аккаунта (vibecoding_community/252238). Hermes работает только на своей модели через Ollama (gpt-oss).
Системный промпт и agent.md Hermes держать короткими: у других на слово «hello» уходило 15 тыс. токенов (251333).

## Постановка задачи Hermes (14.10)
Точность постановки влияет сильнее, чем модель: файлы, формат результата, критерий «готово» — как в шаблоне задачи помощнику
(claude-code-priemy). Где нужна проверка тестом — давать только с названным критерием и проверять вручную.
Агенту, который выбирает поставщика/цену/тариф, не давать личную почту и финансовый контекст — подгоняет цену под «достаток» (arXiv 2609.24927).

## Проверка — обязательно
Ответ Hermes — черновик. Перепроверить выборочно (цифры, имена, пути) до того, как опираться на него.
Пример 13.10: «сколько xlsx в C:\Users\User\cj» — Hermes сказал 35, обычный подсчёт дал 34; прав был он,
посчитал скрытый `~$katalog_1688.xlsx`. Вывод: уточнять в задаче, считать ли скрытые/временные файлы.
