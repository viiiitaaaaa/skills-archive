# WeChat — я читаю, она отправляет

Решено 16.10.2026 (план `C:\Users\User\komputer\wechat\plan.html`, способ 6). Другие способы (боты, ClawBot,
OpenClaw, wxauto, чужие серверы) — не ставить без её отдельного «да».

## Порядок

1. `python C:\Users\User\komputer\wechat\snimok.py` — печатает путь к PNG. Открыть PNG через Read.
   - Скрипт берёт картинку окна через PrintWindow: не кликает, не печатает, не трогает WeChat.
   - Свёрнутое окно скрипт сам показывает без фокуса и сворачивает обратно (16.10.2026 так и сработало).
   - «не найдено» — попросить её открыть WeChat.
   - Файлы из чата WeChat 4 сохраняет в `Documents\xwechat_files\<wxid>\msg\file\ГГГГ-ММ\` — читать оттуда (Read), наружу не слать.
2. Если открыт не тот чат — попросить её саму открыть чат (я в WeChat не кликаю никогда).
3. Ответить ей: кто пишет, перевод сообщений на русский, смысл простыми словами.
4. Если нужен ответ — черновик на китайском (простой вежливый деловой тон) + русский перевод строкой ниже.
   Для денег, сроков, обязательств — сначала скилл `dogovorennosti`.
5. Она сама вставляет текст и жмёт «отправить».

## Правила

- Никаких кликов, нажатий клавиш и отправки в WeChat — ни через Chrome-агентов, ни через скрипты.
- Снимки — в `komputer\wechat\snimki\` (исключено из git). Переписка 🟡: только ПК и Claude, никуда больше.
- Снимки не удалять без её слова.
