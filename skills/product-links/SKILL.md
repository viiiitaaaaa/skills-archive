# Ссылки на товары AliExpress по фото

Скрипты лежат и здесь, и в `C:\Users\User\dolphin_anty\` — **запускать надо из
`dolphin_anty`**, они импортируют оттуда `dolphin.py` и `shots.py`. Правишь — обнови обе копии.

Место в цепочке: `cut-products` (нарезка) → `style-collections` (коллекции) → этот скилл.

| Скрипт | Зачем |
|---|---|
| `match_folder.py` | Папка со сборной подборкой из РАЗНЫХ магазинов → один Excel. **Основной режим.** |
| `match_products.py` | Один магазин, папка фото → CSV. Когда магазин задаётся вручную. |

Импорт полученных ссылок в Dsers — отдельный скилл **`dsers-import`** (там же `dsers_add.py`,
который жмёт «Add To DSers» на страницах товара).

## Папка с фото → Excel

```powershell
cd C:\Users\User\dolphin_anty
python match_folder.py --folder "C:\Users\User\Desktop\скрины магазинов\Новая папка"
```

Магазин берётся **из имени файла** (`<Магазин>-001.png`), ссылка на него — из
`dolphin_anty\state_tabs.json` (там url всех отснятых магазинов; если магазина там нет,
строки помечаются «ССЫЛКА НА МАГАЗИН НЕ НАЙДЕНА»). Каталог каждого магазина обходится
один раз, даже если из него 76 фото.

Результат — `ссылки на товары.xlsx` в той же папке: магазин, файл, ссылка, расстояние,
уверенность, название; шапка закреплена, автофильтр включён. **Excel пересохраняется
после каждого магазина**, поэтому падение на последнем не обнуляет предыдущие.

## Один магазин → CSV

```powershell
python match_products.py --store 1105084156 --folder "<папка>" --pages 40
```

## Импорт в Dsers

```powershell
python dsers_add.py --file links_decor.txt            # нажать на всех
python dsers_add.py --file links_decor.txt --probe    # разведка, если вёрстка поменялась
```

Профиль по умолчанию — 859648353, там стоит расширение. Кнопка основного товара:
`BUTTON` с текстом **ровно** «Add To DSers», в правой панели под Share. Кликать строго по
точному совпадению текста: рядом есть **«Add all to DSers»** над блоком Related items —
она добавляет рекламные товары чужих продавцов, её трогать нельзя.
Подтверждение приходит всплывашкой «AliExpress product import success!», живёт пару секунд,
так что поймать её удаётся не на каждом товаре — итог проверять в Dsers → Import List.

## Читать расстояние phash

0–2 — то же самое фото; до 8 — тот же товар; 9–16 — похоже, проверить глазами;
больше 16 — совпадения нет, товара в каталоге скорее всего уже не существует.
На проверенной подборке из 126 фото: 118 «высокая», 6 «средняя», 2 «низкая».

## Грабли (вылечено, не ломать обратно)

1. **`&page=N` каталог НЕ листает** — отдаётся та же первая страница, собирается 40 товаров
   вместо 1181, ссылки получаются мусорные при внешне нормальном логе. Листать только
   `switch_page` из `shots.py` (клик по пагинатору).
2. **Редирект во время прокрутки** убивает контекст Playwright
   (`Execution context was destroyed`). Отсюда `settle()` — ждём, пока URL перестанет
   меняться, — и повтор попытки.
3. **Разбор до загрузки** даёт 0 карточек: нужен `wait_for_selector('a[href*="/item/"]')`.
4. Только aliexpress.com; профиль 859648353 с американским прокси показывает страницы на
   aliexpress.us — ID товара тот же, цены для США.
5. Внутренний ID магазина в адресе может отличаться от ID в ссылке — сверяться по заголовку.
6. Вывод буферизуется: запускать с `python -u`, иначе фоновый лог пуст до самого конца.
