# Печать одной командой

Итог: лист(ы) вышли из принтера, в ответе — что напечатано, сколько страниц, на какой принтер.

## Как печатать
```
python "C:\Users\User\.claude\skills\pechat\print_file.py" "<полный путь>" [--pages 1,3-4] [--copies 2] [--printer "<имя>"]
```
- Принтер по умолчанию в скрипте — **RICOH SP 221SNw** (лазерный A4, USB, подключён 07.10.2026).
  Системный «по умолчанию» Xprinter XP-365B — принтер этикеток, обычные документы на него НЕ слать.
  Есть ещё HP Color Laser 150 (цветной, по сети) — только если она попросит «в цвете»/«на HP».
- `--list` — список принтеров.
- Без вопросов: нашла файл → печатаю. Спросить только если подходят несколько разных файлов
  и по её словам не понять какой, или документ больше ~20 страниц.
- После отправки проверить очередь: `Get-PrintJob -PrinterName "RICOH SP 221SNw"`.

## Где искать файл
- Дела: `G:\Мой диск\Дела\<дело>\` (1. Наши готовые / 3. Полученные …). Имена файлов часто
  содержат «(N стр.)» — по ним видно объём.
- `.gdoc`/`.gsheet` — это ярлыки Google, их не напечатать напрямую: скачать PDF через
  Google Drive (export) или взять рядом лежащий .pdf/.html.
- `.docx` — Ворда нет: искать рядом PDF/HTML-версию; если нет — открыть .docx в Google Drive и экспортировать в PDF.

## Грабли
- PDF на компьютере открывается Chrome, отдельной программы нет — поэтому печать идёт через
  Python (PyMuPDF рисует страницу → pywin32 шлёт на принтер), а не через «Открыть → Печать».
- Статус задания «Printing, Retained» — нормально: принтер хранит копию после печати.
