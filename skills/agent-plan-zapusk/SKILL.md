# Подготовка и запуск своего агента (наш вариант)

Образец и точные формы API-запросов: `C:\Users\User\.claude\karantin\snyato-launch-your-agent\` (SKILL.md и references\cma-api.md — только читать как черновик, не ставить и не запускать оттуда). Скилл держит 4 шага; 1-й и 3-й — бесплатные.

## Шаг 1. Опрос → план (ключ НЕ нужен, ничего не тратится)
- Один вопрос за раз, лучше выбор из вариантов. Выяснить: какую задачу делает агент, откуда берёт данные, что выдаёт, как часто, что ему ЗАПРЕЩЕНО.
- Назвать первую версию v0 — самую маленькую, что уже полезна. Всё остальное — в `NEXT-DIRECTIONS.md` (v1, v2…).
- Показать план 5–7 строк и получить «да» до создания файлов.

## Шаг 2. Файлы агента в папке `my-agent\` (в рабочей папке дела)
1. `agent.json` — имя, `model` оставить `PICKED-AT-LAUNCH`, системный промпт (работа + запреты + «результаты писать в /mnt/session/outputs/»), инструменты ровно `[{"type": "agent_toolset_20260401"}]`.
2. `outcome.md` — 3–6 проверяемых критериев «готово» (да/нет).
3. `first_prompt.txt` — задание с её настоящими входными данными.
4. `evals\case-01\` (input + expected) — проверка на её реальном примере.
5. `NEXT-DIRECTIONS.md`, `LAUNCH.md` (пошаговый запуск, каждый шаг можно повторить), `.gitignore` с `.env` и `IDS.env`.
6. Все JSON проверить, что читаются. Показать ей папку через `razdat.py show`.

## Шаг 3. Запуск — ТОЛЬКО с её «да»
- Перед запуском сказать: «Запуск идёт в твоём аккаунте Anthropic, один прогон стоит ~копейки/центы (сумму назову по `max_iterations`); запускаю?» и ждать «да».
- Ключ `ANTHROPIC_API_KEY` её собственный: брать из окружения, не печатать, не копировать никуда кроме `my-agent\.env`, не отправлять, в память/GitHub не класть. Нет ключа — сказать ей, что выпустить (таблица: что · где · что делать), не просить прислать его мне.
- Форма запросов — `references\cma-api.md` в образце (`karantin\snyato-launch-your-agent`). Идентификаторы сохранять в `IDS.env`; повтор запроса при сбое — только после проверки, создался ли объект в первый раз.

## Шаг 4. Проверка и улучшение
- Прогнать `first_prompt.txt`, сверить результат с `outcome.md` по пунктам, показать ей «совпало N из M».
- Расхождение — править системный промпт одним изменением и повторять (не больше 3 кругов), без «на всякий случай».
- Нужен запуск по расписанию — отдельное «да» (это постоянные траты).

Правило ей: в конце — 3 строки «планировала / вышло / сделаю иначе».
