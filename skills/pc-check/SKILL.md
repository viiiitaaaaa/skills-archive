# Проверка компьютера (pc-check)

Скрипт `scripts\pc_check.ps1` только смотрит и пишет отчёт. Ничего не удаляет.
Удаление — отдельным шагом, после того как она прочитает разбор и скажет, что убрать.

## Запуск

Всегда от администратора: иначе не видны исключения Защитника и часть задач.
Из Claude Code повышение прав работает только без песочницы (`dangerouslyDisableSandbox: true`),
а вывод нужно писать в файл через `cmd /c ... > log`, иначе окно администратора закроется без следа:

```powershell
$s = 'C:\Users\User\.claude\skills\pc-check\scripts\pc_check.ps1'; $log = 'C:\Users\Public\pc_check_run.log'
$p = Start-Process cmd.exe -ArgumentList "/c chcp 65001 >nul & powershell.exe -NoProfile -ExecutionPolicy Bypass -File `"$s`" -Seconds 6 > $log 2>&1" -Verb RunAs -PassThru
$null = $p.WaitForExit(540000); Get-Content $log -Encoding UTF8
```

- Обычный прогон: около 2–3 минут.
- `-Scan quick` добавляет быструю проверку Защитником (5–15 минут), `-Scan full` — полную (1–3 часа, запускать в фоне).
- Отчёт: `C:\Users\User\pc_check\reports\pc_check_<дата>.md`, рядом `.json` с сырыми данными.

## Грабли скрипта (уже исправлены, не повторять)

- `@($list)` для `List[object]` в PowerShell 5.1 падает «Argument types do not match» → `$list.ToArray()`.
- Свойство объекта с именем `Where` ломает выборку → поле называется `Place`.
- В шаблоне замены `-replace` строка `$_` подставляет весь исходный текст. Для буквальной замены — `.Replace()`.
- Скрипт с русским текстом сохранять в UTF-8 **с BOM**, иначе Windows PowerShell 5.1 ломает разбор.
- `ConvertTo-Json` на сотнях строк hosts тормозит минуту+ → в json только счётчик и первые 30 строк.
- С `-Scan full` состояние Защитника читалось до проверки → ложное «полная не делалась» и пустая дата. Теперь перечитывается после.
- Задача планировщика AlibabaProtect (`AliProctectUpdate`) не видна без администратора — искать остатки только от админа.
- Сама проверка и Claude Code (`CLAUDE_CODE`, `pc_check.ps1`) исключены из «подозрительных команд».
- Сверка скиллов через `git hash-object` дала 160 ложных «изменён» (CRLF у файлов вне репозитория), а PowerShell 5.1
  в трубе к git дописал BOM в первый путь → сверка побайтно SHA256 с рабочей папкой копии + `git status` копии.
