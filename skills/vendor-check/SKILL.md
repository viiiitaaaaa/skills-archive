# Проверка поставщика/партнёра (vendor-check)

Инструмент: [Aliens Eye](https://github.com/arxhr007/Aliens_eye) — сканер юзернеймов/брендов по 840+ площадкам, установлен как `aliens_eye` (`pip show aliens-eye`).

**Назначение: только деловая проверка контрагентов ARTMELLIO** (поставщики, партнёры, подрядчики) перед началом сотрудничества или переводом денег — убедиться, что у компании/бренда есть последовательное, живое цифровое присутствие, а не фейковый аккаунт-однодневка. Не используется для проверки частных лиц без деловой причины.

## Как запускать

Взять предполагаемый юзернейм/бренд поставщика (из его сайта, визитки, профиля на маркетплейсе):

```bash
# базовая проверка + проверка регистрации домена под этим именем
aliens_eye <бренд_или_ник> --domains --format html,json --output results

# если похоже на реальную компанию - сразу собрать отчёт со всеми форматами
aliens_eye <бренд_или_ник> --correlate --domains --format all --output results
```

Результат: `results/<ник>_basic_<дата>.{json,csv,html,md}` — таблица Found/Maybe/Not Found по площадкам с confidence.

## Как читать результат

- **Found на 5+ независимых площадках** (сайт, LinkedIn, профиль на своём маркетплейсе, Instagram/соцсеть, GitHub — если IT-подрядчик) с одинаковым описанием/логотипом → хороший знак, цифровой след реальный.
- **Found только в 1-2 местах или Maybe везде** → не является доказательством мошенничества само по себе (инструмент даёт precision ~0.65, recall ~0.51 — это наводки, не факты), но повод проверить вручную: позвонить, попросить документы, посмотреть регистрацию юрлица отдельно.
- **Домен из `--domains` не зарегистрирован** при том, что поставщик называет его в переписке → красный флаг.

Никогда не считать вывод инструмента окончательным доказательством — это только наводки для дальнейшей ручной проверки.

## Из книг (09.10.2026) — подробно `references/iz_knig.md`
- Партнёру в итоге ставить оценку по трём осям: экспертность (объекты, допуски) · надёжность (отзывы, суды) · симпатичность (как общается) + риск оппортунизма (уведёт клиента) (Котлер ММ1).
- Поставщика спрашивать: своя фабрика или субподряд; брать прозрачное производство — фото цеха, адрес совпадает (Grewal 2).

## Второй инструмент — Flowsint (когда будет время, не установлен)

Источник: PushEnter/13815, пост 932, 07.10. Бесплатный открытый OSINT-инструмент: по нику, почте, телефону или
криптокошельку ищет связанные аккаунты, сайты и утечки и рисует интерактивную схему связей; данные хранятся локально.
- Зачем нам: где Aliens Eye проверяет только ник, Flowsint свяжет почту/телефон поставщика или партнёра с его
  аккаунтами и сайтами (Found на разных площадках с одним телефоном = живая компания). Второе применение —
  проверить, что утекло о наших рабочих почтах (Shopify, BuckyDrop, Frivent).
- Установка: репозиторий на GitHub (ссылка спрятана в посте под словом «тут» — взять со страницы
  https://t.me/PushEnter/13815). Перед установкой прочитать код (что запускает, куда шлёт) — правило «чужие скиллы».
- **Код прочитан 07.10 (reconurge/flowsint, 9,5 тыс. ⭐, Apache-2.0, обновлён 03.10): 🟡, не установлено, ждёт её ОК.**
  Это не программа, а сервер из 5 частей в Docker (Postgres, Redis, Neo4j, API, сайт) — нужен Docker Desktop (~4 ГБ
  ОЗУ). В `docker-compose.yml` базы открыты на все сетевые адреса с паролями по умолчанию (`flowsint/flowsint`,
  `neo4j/password`) → при установке сменить пароли и `MASTER_VAULT_KEY` в `.env`, порты привязать к `127.0.0.1`.
  Сильные проверки (утечки DeHashed, история WHOIS Whoxy, HudsonRock) — платные ключи сторонних сервисов; бесплатно —
  WHOIS, поддомены, Gravatar, HIBP (тоже с ключом). Вывод: для нас тяжеловат; сначала Aliens Eye + ручной WHOIS,
  Flowsint — только если проверок контрагентов станет много. Установка (после ОК):
  `git clone https://github.com/reconurge/flowsint C:\Users\User\tools\flowsint` → правка `.env` → `docker compose up -d`.
- Те же границы: только деловая проверка контрагентов; частных лиц и жителей посёлков (lead-engine) — нет.
  Данные: 🟡 почты/телефоны контрагентов — вводить только в локальный инструмент, не в онлайн-сервисы.
