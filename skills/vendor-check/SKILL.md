# Проверка поставщика/партнёра (vendor-check)

Инструмент: [Aliens Eye](https://github.com/arxhr007/Aliens_eye) — сканер юзернеймов/брендов по 840+ площадкам, установлен как `aliens_eye` (`pip show aliens-eye`).

**Назначение: только деловая проверка контрагентов ARTMELLIO** (поставщики, партнёры, подрядчики) перед началом сотрудничества или переводом денег — убедиться, что у компании/бренда есть последовательное, живое цифровое присутствие, а не фейковый аккаунт-однодневка. Не используется для проверки частных лиц без деловой причины.

## Как запускать

Взять предполагаемый юзернейм/бренд поставщика (из его сайта, визитки, профиля на маркетплейсе):

```bash
# базовая проверка + проверка регистрации домена под этим именем
aliens_eye <бренд_или_ник> --domains --format html,json --output results

# если похоже на реальную компанию - сразу собрать отчёт со всеми форматами
aliens_eye <бренд_или_ник> --correlate --domains --format all --output results
```

Результат: `results/<ник>_basic_<дата>.{json,csv,html,md}` — таблица Found/Maybe/Not Found по площадкам с confidence.

## Как читать результат

- **Found на 5+ независимых площадках** (сайт, LinkedIn, профиль на своём маркетплейсе, Instagram/соцсеть, GitHub — если IT-подрядчик) с одинаковым описанием/логотипом → хороший знак, цифровой след реальный.
- **Found только в 1-2 местах или Maybe везде** → не является доказательством мошенничества само по себе (инструмент даёт precision ~0.65, recall ~0.51 — это наводки, не факты), но повод проверить вручную: позвонить, попросить документы, посмотреть регистрацию юрлица отдельно.
- **Домен из `--domains` не зарегистрирован** при том, что поставщик называет его в переписке → красный флаг.

Никогда не считать вывод инструмента окончательным доказательством — это только наводки для дальнейшей ручной проверки.
