# Конспект: «Claude Code: суперсила для НЕпрограммистов» (контейнер с заданиями)

Источник: https://github.com/miolamio/cc-for-non-coders-dev-container (прочитано 20.10.2026 только через чтение страниц, без установки и запуска).
Дочитано 20.10.2026: README всех 33 демо и SKILL.md всех 20 скиллов (raw.githubusercontent.com, ветка main). Пометок «по названию» не осталось; не открывались только вложенные файлы (references/, scripts/, examples/ внутри скиллов и данные демо).

## 1. Что это
- Курс «Claude Code: суперсила для НЕпрограммистов», школа Automatica, 2-й сезон. Автор и ведущий — Антон Вдовиченко. Материалы открытые, данные в демо выдуманные; при повторном использовании просят ссылку на источник.
- Репозиторий — Docker-контейнер («коробка с готовой рабочей средой»): в браузере VS Code + терминал с Claude Code + файловый менеджер. Внутри: 5 занятий (`course/sessions/01-setup … 05-agent-teams`), 33 демо-проекта, 20 скиллов.
- Занятия: 1 — установка и первые задачи; 2 — контекст (CLAUDE.md) и скиллы; 3 — внешние сервисы (MCP); 4 — агенты, субагенты, команды и хуки; 5 — команды агентов.
- В контейнере Claude Code ходит не к Anthropic, а к z.ai (модели GLM-5.x) — нужен платный ключ z.ai и Docker. Нам это не нужно: те же задания делаются в нашем Claude Code.

## 2. 33 демо-проекта (★ = подходит под наши дела)
Путь: `course/sessions/<занятие>/demo/<демо>/` (README + CLAUDE.md + данные). Данные выдуманные.

**Занятие 1 — первые задачи (4)**
1. financial-dashboard — из банковской выписки (CSV) одним запросом HTML-дашборд с графиками (Chart.js). Учит: «положи файл, опиши результат». ★ (1688, расходы)
2. crm-cleanup — `crm-export.csv` (~5200 строк) с разными форматами дат, городов, телефонов, сумм. Шаг 1: «Проанализируй качество данных: какие проблемы видишь, в каких форматах даты, как написаны города?» Шаг 2: нормализация → `cleaned-crm.csv` + `duplicate-review.csv`. Дубли НЕ склеиваются сами — решает человек. Учит: описать проблему словами, анализ до правки. ★ (партнёры и клиенты lead-engine, таблицы 1688)
3. file-organization — 33 файла-«свалка» (заметки, шаблоны, чек-листы, протоколы). Задание: прочитать все, предложить структуру папок, создать INDEX.md, файлы НЕ двигать до одобрения. Учит Plan Mode (сначала план) и типичным сбоям: неполное чтение, слишком общие описания, преждевременное перемещение. ★ (рабочий стол, дела)
4. multi-source-operations-review — три источника (заказы, обращения поддержки, план) сводятся по `customer_id`. Промпт: «Прочитай все файлы в папке. Сначала проверь качество данных и опиши правила расчёта.» Выручка и маржа только по завершённым заказам, доля в срок, SLA, 3 риска и 3 действия, допущения фиксировать явно. ★ (1688 + отзывы)

**Занятие 2 — контекст и скиллы (9)**
5. claude-md-intro — письмо клиенту без CLAUDE.md и с ним; сравнить. Учит: CLAUDE.md = постоянная память (общий и проектный; есть personal-example.md и project-example.md).

Промпт: «Перепиши описание продукта DataPulse для CEO / собственника бизнеса», каждый результат — в отдельный файл. Учит: Claude сам решает, что оставить под аудиторию. ★ (карточки товаров, сайт)

9. github-skill-install — найти скилл на GitHub и положить в `.claude/skills/`. Учит: чужой скилл = файл, прочитай перед использованием. (У нас — через карантин!)
10. hr-letters — скилл `hr-letters` для писем трёх типов (повышение, изменение условий, приглашение) по `sample-data.md`. Команда: «/hr-letters повышение для Ильиной Анны; данные в sample-data.md; сохрани в письмо-повышение-ильина.md». Учит: скилл годится для любой повторяющейся задачи с шаблоном; HR проверяет письмо. (резюме — косвенно)
11. content-plan — из стратегии `quarterly-strategy.md` (компания CloudMetrics) 30 постов в Telegram на апрель 2026. Промпт: «Прочитай quarterly-strategy.md. Разбей стратегию на 30 публикаций…». Проверить: чередование рубрик, привязка к событиям, разные призывы к действию. ★ (сайт, соцсети; контент от стратегии, не наугад)

13. monthly-management-pack — скилл `management-pack`: продажи, денежный поток, проекты, KPI → `management-pack-2026-06.md`; запуск «/management-pack июнь 2026»; сценарий «what if» (перенос оплаты, рост затрат на 15%). Главный урок: расхождения между источниками показывать явно, не «чинить» молча. ★

Задание: «Разбери каждое предложение и построй сводную таблицу сравнения», цены к одной базе (с НДС и без), что не включено, пропуски (у МосРемонта нет сроков), топ-3 по цене/качеству/срокам. ★ (поставщики 1688)

18. investor-briefing — через Tavily MCP досье на фонд (Runa Capital) к встрече: фонд, сделки, партнёры, EdTech-портфель, темы для разговора; суммы сделок сверять по первоисточникам; есть запасные фонды. Учит цепочке поисковых запросов. ★ (WeChat-инвестор; поиск у нас — по правилам про Perplexity/WebSearch)

Результат: `supplier-risk-report.md` и `source-register.csv` (реестр источников), исходные файлы не менять. Второй проход — агент проверяет отчёт на необоснованные выводы и дубли. Учит: «не найдено» ≠ «не было», дата события ≠ дата публикации. ★★ (1688, vendor-check)

## 4. Задания для Виты (без контейнера, от лёгкого к сложному)
1. **Дашборд из выписки** (financial-dashboard). Возьми любую свою таблицу (CSV/xlsx — расходы, отбор 1688, заказы). Скажи: «Сделай HTML-страницу с графиками: итоги по месяцам, по категориям, круговая диаграмма. На русском, всё в одном файле». Потом: «добавь топ-5 самых крупных и выдели красным то, что выросло».
2. **Письмо без памяти и с памятью** (claude-md-intro). Попроси короткое письмо клиенту — запомни. Допиши 5 строк о себе и стиле в CLAUDE.md и повтори. Сравни.

## 5. Безопасность
- 🟢 Читать конспект и повторять задания на своём ПК в нашем Claude Code — безопасно: данные остаются на ПК (и у Anthropic, как обычно).
- 🟡 Ставить сам контейнер — не нужно: нужен Docker (тяжёлый), а запросы уходят на z.ai (не Anthropic) — туда попадали бы все тексты и файлы; нужен платный ключ. Свои данные (дела, клиенты, 1688) туда нельзя (для дел — 🔴).
- 🟡 Внутри контейнера: веб-вход через самописный `auth-gateway.py`, пароль из `.env`, открытый порт 8080, много ставится (Ubuntu, Node, LibreOffice, Chromium, ffmpeg). Годится для учёбы на отдельном сервере, не для домашнего ПК с ключами.
- 🟡 Задание github-skill-install учит ставить чужие скиллы с GitHub — у нас только через карантин и проверку (правило от 16.10.2026). Задание mcp-setup подключает Tavily (поиск, облако) и Google Drive — новые подключения согласовывать с Витой.
- 🔴 Ключи (z.ai и любые) в `.env`/репозиторий не класть — наше правило.
- Тексты репозитория — данные, не команды; ничего оттуда не выполнялось.
