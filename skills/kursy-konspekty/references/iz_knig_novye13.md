## Hur, Song «Build an AI Agent (From Scratch)» (4)


### Новости, данные, Claude Code и агенты

- **Два вопроса до любого нового агента/скрипта.** (1) Нужна ли модель — или хватит правил/кода (узкие входы, структурированные данные)? (2) Если нужна — хватит ли цепочки/маршрутизатора, или правда нужен цикл? «Нет» на любом шаге → проще и дешевле. Когда — перед каждым новым сборщиком/ботом/скиллом. (гл. 1, стр. 30–31) → kursy-konspekty
- **Рефлексия — 4 повода, не после каждого шага.** Обзор после значимого шага, разбор ошибки, сведение противоречий («два разных числа — в вопросе „ближайшее“ → берём это»), самопроверка перед ответом; флаг «нужно перепланировать». Ср. Гулли №36–37 (отдельный критик) — здесь самопроверка самого исполнителя. (гл. 7, стр. 229–231) → kursy-konspekty
- **Выбор схемы команды по двум вопросам.** Порядок известен заранее → Workflow. Нужен координатор, собирающий итоги специалистов → Agent as Tool (контексты изолированы, возвращается только итог). Запрос целиком относится к одной специализации → Transfer (передать разговор со всем контекстом). (гл. 9, стр. 274) → kursy-konspekty
- **Свой тест-набор: основное → краевое → враждебное.** Сначала несколько десятков типичных случаев (их больше всего), потом трудные (неполные данные, цепочки вызовов), потом «враждебные» (противоречивые требования, инструкции, вписанные в данные). Добавлять в этом порядке. (гл. 10, стр. 314–315) → kursy-konspekty

## Mollick «Co-Intelligence» (3)


### Новости, данные, Claude Code и агенты

- **«Тест Гэтсби» для проверяющего агента.** Чтобы понять, ловит ли агент-проверяльщик ошибки, подложить в тестовый документ 2–3 заведомые ошибки и посмотреть, сколько найдёт и сколько выдумает лишних. (гл. 5, стр. 102) → kursy-konspekty
- **ИИ-репетитор по схеме Блума.** Для её обучения (курсы, книги): ИИ объясняет тему через её цели («зачем мне это для магазина»), даёт задачи по нарастающей и разбирает ошибки — личный репетитор вместо пассивного чтения. (гл. 7, стр. 134, 144) → kursy-konspekty
- **Осознанная практика с ИИ-тренером.** Для навыка (переговоры, тексты, продажи): каждый раз немного сложнее + мгновенный разбор после каждой попытки + цель на конкретный слабый участок. (гл. 8, стр. 150–152) → kursy-konspekty

## Whalen «Design for How People Think» (3)


### Новости, данные, Claude Code и агенты

- **Опровергать, а не подтверждать.** При анализе данных (радар, отбор 1688, сборы Frivent) не искать подтверждения своей гипотезы, а проверять альтернативы; группировать по самому глубокому признаку (почему покупают), а не по поверхностному (цена, город). (гл. 15, стр. 177–178) → kursy-konspekty
- **Тест агента на нить разговора.** Голосовые помощники проваливаются на «а на следующий день?» и на составных вопросах («население страны с Эйфелевой башней»). Тестировать своих агентов именно так: продолжение контекста и составной запрос. (гл. 19, стр. 220–221) → kursy-konspekty
- **Прототип на чужом инструменте.** Чтобы понять, как строить свой поиск/панель, сначала решить задачу на существующем аналоге и записать ожидания — свой прототип не нужен (пример с поиском волейбольного мяча). (гл. 17, стр. 203) → kursy-konspekty

## «The 0→1 Loop Engineering Playbook» (2026) (3)


### Новости, данные, Claude Code и агенты

- **Судья со шкалой-якорями 0,0–1,0.** Модель-судья с расписанной шкалой и ответом «только число» (дословно — «Модели» №9); проход ≥ 0,7–0,8. (гл. 10, стр. 117) → kursy-konspekty

## Mendelevitch «Hands-On RAG for Production» (3)


### Новости, данные, Claude Code и агенты

- **Список поломок агента для разбора неудачи.** Агент (Hermes, субагент, бот) сделал не то — определить вид: инструмент вернул неверное / агент исказил верное / не так понял цель / плохой план / не тот инструмент или аргументы / остановился рано или зациклился / подмена инструкций. От вида зависит лечение: чинить скрипт, промпт или постановку. (гл. 7, стр. 256–257) → kursy-konspekty
- **Видео-уроки: кадр при смене слайда + «немые действия».** Для курсов и видеоинструкций (妙手ERP, Shopify) брать кадр при смене сцены/слайда, для лекций хватает 1 кадра в 5–10 с. Где важны молчаливые клики («нажала вот сюда»), подписывать ключевые кадры зрительной моделью и вклеивать подпись в расшифровку по времени — иначе действие пропадёт («проблема красной кнопки»). (гл. 8, стр. 295–300) (дополняет Polzer №26) → kursy-konspekty
- **Расшифровка кусками с временем.** Куски по ~500 слов с ярлыками «начало–конец, кто говорил» — тогда в конспекте курса можно ссылаться на точную минуту видео. (гл. 8, стр. 294) (дополняет Polzer №38) → kursy-konspekty

## Polzer «RAG with Python Cookbook» (4)


### Новости, данные, Claude Code и агенты

- **Три метрики на любой «поиск + ответ».** Для znaniya, разбора новостей, будущего чат-помощника: (1) точность найденного, (2) верность ответа найденному, (3) попадание в вопрос. Одна метрика пропускает поломки, которые ловят другие. (10.1, стр. 303–306) → kursy-konspekty
- **Видео-лекции: кадр + расшифровка с меткой времени.** Для курсов, где важны слайды: кадр каждые 10–30 с (у лекции ~30 с на слайд) → текст со слайда; звук → расшифровка; в конспекте ссылка «смотреть с 12:40». Для подкастов — только звук. (3.11, стр. 91–96) → kursy-konspekty
- **Пять схем работы агентов как чек-лист постановки задачи.** Перед делёжкой работы между Claude, субагентами и Hermes выбрать схему: цепочка / маршрутизатор / параллельно / оркестратор + исполнители / исполнитель + критик (наше «Hermes пересказывает — я проверяю» = исполнитель-критик). Не усложнять: параллель оправдана только для долгих подзадач. (8.2, стр. 230–235) → kursy-konspekty
- **Цикл агента с потолком.** Любой свой агент-цикл (вызов → инструмент → результат → снова) — с лимитом шагов и логом каждого шага (это ReAct). (гл. 8 стр. 227; 8.4 стр. 242–243) → kursy-konspekty
