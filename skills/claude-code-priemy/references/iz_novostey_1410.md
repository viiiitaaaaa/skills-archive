## Аккаунт Claude — не потерять
- **Чужие клиенты = бан.** Подписку Claude (вход OAuth) нельзя подключать к Hermes и другим сторонним клиентам — только
  Claude Code и приложения Anthropic (vibecoding_community/252238). У нас Hermes на Ollama (gpt-oss) — так и оставить.
- Один постоянный IP: весь трафик системы через один VPN-туннель, не только браузер — Claude Desktop и CLI ходят на разные
  адреса, клиент «мимо VPN» и приводил к банам; сервер Happ во время работы не переключать (251931, 252367).
- Платить своей настоящей картой; чужие кошельки, обходные карты, перекупленные аккаунты — нет. Возврат после бана
  не дают (249044, 244499, neuraldeep/2360). Claude хранит «досье» в памяти — страна может записаться по темам запросов (249044).
- Ротация аккаунтов через прокси (Quotio и т.п.) — не ставить: у Codex «теневой бан» на дни (digital_ponos/1240).
- С 12.11 политика запрещает системные оскорбления модели — обычно заканчивается остановкой диалога (246359, uxlive/18512).
- Всё важное — в GitHub и .md вне claude.ai (уже так: ARTMELLIO_SKILLS, automation-scripts) — проверять, что копия свежая.

## Лимит и контекст
- **Кэш субагентов `subagentPromptCacheTtl: "1h"` — НЕ включать. НАШ замер 14.10** (`scripts/cache_gap_check.py`, только
  чтение логов, без сети; gist DannyMac180 из notboring_tech/4404, код прочитан 🟢): за 14 дней 314 помощников, 6 502 запроса,
  пауза 5–60 мин лишь у 0,7%, с часовым кэшем было бы **на 26,9% дороже**. Перепроверять раз в месяц:
  `python -I ~/.claude/skills/claude-code-priemy/scripts/cache_gap_check.py --days 14` (выгодно, только если «LIKELY WORTH IT»).
- Уровень усилий: по умолчанию низкий/средний; ultra/max съедают 70% недельного лимита за день почти без прироста качества;
  высокий — только аудит и сложная логика (249300, 250763). Дешёвая модель на low с точной карточкой задачи = Opus на простом.
- Карточка задачи субагенту: цель, входные файлы, «готово = …» — точный промпт вдвое сокращает стартовый контекст (250763).
- Пачка субагентов на Opus для ресёрча съела 5-часовое окно за 32 минуты — ресёрч на Haiku/Sonnet, число параллельных ограничивать (249477).
- Новая задача — новая сессия; `/clear` между задачами, контекст держать ≤150–170 тыс. (лучше ~30%); после нескольких
  /compact модель путает язык и род (251602, 249614, 249888). Раз в неделю смотреть /context: размер CLAUDE.md, MCP, скиллы (246155).
- Тариф считать по недельному лимиту: x20 — это ×20 к 5-часовому лимиту Pro, но ×10 к недельному (247706).
- Fable 5.1 по умолчанию не включать — расход огромный, в коде Opus сильнее (250290).

## CLAUDE.md и скиллы
- CLAUDE.md — карта со ссылками на скиллы и справочники, а не свалка правил (vibecoding_community/245565).
- Порядок в файле ради кэша: сверху неизменное (правила), посередине редко меняемое, внизу — даты и состояния;
  состояние между сессиями передавать файлом в git (249528: кэш 97–99%, правок после ошибок втрое меньше).
- Прямо писать: тесты и новые файлы — только по запросу, иначе агент тратит лимит на «тесты на каждый чих» (249208, 247663).
- Длинные сборы: «3 неудачные попытки → остановиться и доложить»; в начале сложного скилла — «построить карту проекта» (247663).
- Цель «делай пока не закончишь» не ставить: резать на этапы, этап проверять скриптом/линтером, а не вторым агентом (245745).
- Проверку результата делает отдельный агент с чистым контекстом — автор сам себе «подлизывает» (249455).
- Проверка проверки: подложить заведомо неверную строку и убедиться, что тест падает; пару итогов таблиц пересчитать руками
  (neurozeh/1862). Агент, написавший и код, и тесты, может проверить «не то».
- Идея code-modernization (Anthropic): старый и новый скрипт гонять на одних данных, итог «совпало M из M»; плагин не ставить (vibecoding_tg/4085, 253635).
- Простые страницы и демо — «один html-файл без сборки», чтобы не плодить node_modules (252529).
- Факты (цены, комиссии, правила площадок) — только из свежего поиска с датой, не из памяти модели (244944).

## Безопасность на её ПК
- Claude снёс диск C: ошибкой экранирования в PowerShell при работе без запросов разрешений; хуки и запреты отдельных команд
  не спасают — агент напишет иначе (vibecoding_community/245720). У нас: рекурсивное удаление — только по её слову,
  переменные в пути проверять на пустоту, перед массовым удалением — копия. `/sandbox` на Windows — только через WSL2.
- Автономные длинные задания — только в папке под git и с копией базы (249122).

## Модели для помощников
- Haiku 5.5 вышла ($0,10/$0,50 за млн токенов) — для простого (разрезать, слить json) пробовать `model: haiku`, сверив одну пачку
  с Sonnet (245604). API-кредиты Max работают только в облачных сессиях — нам не считаются.
- Субагенты-разведчики «только читают» через хуки SubagentStart + запрет записи (frontendnoteschannel_ru/5990, vibecoding_tg/4074):
  шаблоны `npx claude-code-templates` не ставить, сначала читать код. Опыт 14.10: помощник пачки 5 не прочитал правила и
  отсеял лишнее — в брифе требовать «прочитай SKILL.md целиком через Read».
