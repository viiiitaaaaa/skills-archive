# Как учить Claude понимать её материалы (Perplexity, глубокое исследование 23.10.2026)

Полная страница — `C:\Users\User\komputer\claude_obuchenie.html`. Это ПРЕДЛОЖЕНИЕ; внедрение (пилот на одном деле) — по её «да».
- Формула: оригиналы → карточки знаний с «адресом» (глава/стр., урок/минута, пост/дата, запись/минута) → скиллы → брать только нужное → проверка по источнику.
- Четыре метки: «источник говорит» / «толкование» / «совет» / «её правило». Совет из книги сам не становится правилом. Пересказ не ставить в кавычки.
- Три проверки цитаты: место существует? подтверждает именно это? соседний текст не меняет смысл?
- Длинный документ: сначала выписать нужные места дословно, потом ответ; разрешено «в источниках нет».
- Карточка-действие: когда / когда НЕ / что нужно / порядок / доказательство / как понять, что верно. 3–5 примеров (обычный, нехватка данных, исключение, похожий-но-не-тот, конфликт с её правилом).
- Ошибка → узкое правило «если — делай — кроме», с областью действия + тест, ловящий эту ошибку.
- Тесты: вспомнить, исключения, перенос, отказ, ложная посылка, противоречие, её правило, новая вкладка, чужая команда в документе. ~20 настоящих задач; проверяльщику давать оригиналы.
- Чего у нас нет: адресов в конспектах, меток, набора тестов, проверки в новой вкладке.
