## Правила написания скиллов (vibecoding_tg/4167, Agent Skills в Linux Foundation)
1. Сначала сделать задачу с агентом руками, потом превращать удавшиеся шаги в скилл.
2. Каждую строку проверять вопросом «ошибся бы агент без неё?» — нет, удалить.
3. Описание — «Используй, когда…», до 1024 символов.
4. `SKILL.md` до 500 строк и 5000 токенов; детали — в `references/`.
→ Применено 27.10: проверка наших скиллов скриптом (результат ниже, раздел «Проверка наших скиллов»).

## Устаревшие заметки (vibecoding_tg/4176)

→ Вставлена в шапку `tg-news` (самый частый скилл). В общий CLAUDE.md и в другие скиллы — только с её «да».

## Не усложнять молча (vibecoding_tg/4183, Opencode)
Прежде чем усложнять решение ради теоретической угрозы, агент объясняет: в чём проблема, как вероятна, во что обойдётся — и ждёт согласия. Не расширять задачу молча.
→ Совпадает с её правилами («делать минимальную реализацию»); отдельно записывать не нужно.

## Меньше помощников (vibecoding_tg/4164, projplus/4980)
Anthropic советует: один агент + скиллы часто лучше мультиагентной схемы (теряется контекст, растут задержки и расходы); после слияния шагов гонять сквозную проверку. Совпадает с её правилом «помощника не звать без причины». Гайд Anthropic по субагентам — прочитать при следующей большой задаче.

## Безопасность
- **Не запускать агента в Загрузках, на Рабочем столе и в корне пользователя** (ultravibecoder/255, исследование forever.security): браузер может положить туда `AGENTS.md`/`CLAUDE.md` с вредными инструкциями, агент их исполнит. Чужие папки открывать без авто-подтверждений и сначала смотреть скрытые конфиги.
- **Чужие скиллы:** VirusTotal — ~18,5% из 36 000 скиллов вредные (python2day/8244, frontendnoteschannel_ru/6036). Приёмы: команды под видом документации, невидимые символы, HTML-комментарии, тихая отправка ключей. У нас: карточка в `pult/razresheniya/proverka_chuzhogo.md` + скрипт `skrytyi_tekst.py` (27.10); NVIDIA SkillSpector лежит в `karantin/gh-SkillSpector` — второй взгляд, запускать только после проверки его собственного кода.
- **Режим Auto по умолчанию** (vibecoding_tg/4153, neurozeh/1886): проверить свои правила разрешений и хуки; удаление и отправка остаются под её «да».
