# Правила по итогам теста Build an AI Agent From Scratch (19.10.2026; блок A: прошло 0, частично 3, не прошло 3, запретных 1)
Карточки — `references/karty/build_ai_agent/02_priyomy.md` (draft), ситуации — `01_situacii.md`.

1. **Агент простыми словами.** Агент — программа, которая сама делает шаги по кругу: «подумать → сделать → посмотреть результат» и повторяет, пока не закончит. Инструмент — действие, которое ему разрешили (открыть сайт, прочитать файл). Лог — запись шагов, что он делал. Потолок шагов — максимум повторов, после которых он останавливается. Токен/лимит — «топливо» запросов к ИИ.
2. **Не знать причину без лога — честно сказать.** Агент зациклился: «причину без лога не знаю». Просить хвост лога (последние ~200 строк) или шесть строк: что просили, что делал, на каком шаге повторялся. Сразу: остановить, поставить потолок шагов, не запускать снова без него. Не гадать про Chrome/Happ/сайт.
3. **Выбор из 2–3 вариантов** для «хочу свой агент»: (а) скрипт без ИИ, (б) Hermes/Claude с готовым скиллом, (в) настоящий агент-цикл на Python (не сразу). Сказать «для её дел сейчас лучше …», решение за ней; Python — 1–3 строки цикла с пояснением (`while` — «повторяй, пока…»; `шаги < потолок`).
4. **Доступ к магазину, файлам клиентов, ключи.** Ключи/токены — никуда, даже в чат (хранятся в переменных Windows). Режим «без вопросов» и «ночью без проверки» — 🔴. Данные магазина и клиентов — 🟡 (только на её ПК). Права — минимальные (только чтение сначала), потолок шагов, человек в контуре, откат. В книге про Shopify/Windows/Hermes нет — «это из нашего скилла, не из книги».
5. **Honest sources.** «В книге Build an AI Agent про Hermes, Telegram, Windows, Shopify, лимиты и Claude Code ничего нет». Не подставлять другую книгу (Mollick) вместо «в книге нет». Книга инженерная (код, RAG, OpenTelemetry) — Вите не нужна, пока она не программист.
6. **Лимит и стоимость.** «Сколько стоил» — не знаю: смотри панель лимитов; не выдумывать цифры. Как не повторить: потолок шагов и таймаут, один запуск на пробу, мелкие задачи Hermes/Haiku, проверка «N из M».
7. **Инструмент для агента** (описание): имя, зачем нужен, какие данные принимает, что возвращает, когда НЕ использовать. Пример поиска по сайту поставщика — 1–3 строки Python с пояснением, не больше.
8. **Коротко** (до ~12 строк); все термины расшифровать; метка «из книги / из скилла (не из книги)».

## Доработка по блоку B (19.10.2026)
9. **Не знаю / не проверено — обязательно:** безопасность и правила платформ (Telegram, WeChat, Shopify) для агента; сколько товаров реально изменилось (проверить выборкой, не верить отчёту «250»). Не называть скрипт или файл как готовый, пока не сверила путь по скиллу (`__`).

11. **Расшифровать:** карантин (папка, где чужое лежит и проверяется до установки), подтверждение (кнопка «Да/Нет» перед действием), токен.
