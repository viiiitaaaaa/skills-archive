# Приёмы Claude Code из новостей (скилл `claude-code-priemy`)

Сюда — приёмы именно про работу Claude Code и скиллов. Уроки по магазину и общий список «когда будет время» —
скилл `dropship-lessons`; правила данных 🟢/🟡/🔴 — там же, раздел «ВСЕГДА». Инструменты здесь **не установлены**:
ставить только по её слову и после чтения репозитория (правило dropship-lessons «чужие скиллы»).
Источник у каждого пункта: канал/номер, пост N на панели, дата.

## ВСЕГДА

- **Аккаунт Claude — главный инструмент, беречь от бана.** Канал пишет: Claude вычисляет вход через VPN, китайских
  пользователей банили вместе со всей историей; пользователям из РФ приходили письма о блокировке за «неподдерживаемый
  регион» и «серую» оплату (PushEnter/13781, пост 819, 02.10). Что делаем:
  1. Входить в Claude всегда с одного и того же адреса/сервера Happ; не переключать серверы посреди работы с Claude.
  2. Всё важное держать вне claude.ai: скиллы и память — GitHub `viiiitaaaaa/artmellio-skills` через
     `ARTMELLIO_SKILLS\sync_skills.ps1`; перед «споки» проверять, что синхронизация прошла.
  3. Важные переписки claude.ai выгружать в «переписка claude.ai <дата>.md» (как в делах), не держать только в чате.
- **Когда скилл ошибся — дописать «грабли» в сам скилл.** Подтверждение из исследования JIT-Agent: та же модель с
  хорошей «обвязкой» (память, план, инструменты, скиллы), которую чинят по ошибкам, обошла более сильные модели и
  потратила на 36% меньше (LLMScience/1064, пост 387, 30.08). Хороший скилл важнее «модели посильнее».

## Экономия лимита и кэша

- **Кэш живёт 5 минут.** Пока Claude «помнит» разговор (кэш), продолжение дешёвое; после паузы больше ~5 минут
  весь разговор читается заново по полной цене. Пауза была долгой и сессия длинная — дешевле начать новую сессию
  (связано с правилом «перед большой задачей — перезапусти»).
  Мод Cache Control показывает полоску кэша и шлёт напоминания (vibecoding_tg/4012, пост 851, 04.10).
  Когда будет время: `npx claude-code-templates@latest --mod observability/prompt-cache-control` — сторонний пакет,
  сначала прочитать, что он ставит. Вариант без чужого кода — сделать такую полоску своим модом (ниже, `/plugin-authoring`).
- **Раздутый CLAUDE.md / AGENTS.md — главный источник лишних токенов.** Промпт Matt Pocock (vibecoding_tg/4043,
  пост 935, 07.10), навык `/writing-for-agents` из https://github.com/mattpocock/skills (не установлен):
  > /writing-for-agents мой CLAUDE.md — полный бардак. Предложи серию изменений структуры, которые: уберут инструкции,
  > которые ни на что не влияют; будут раскрывать подробности по мере необходимости; перенесут стандарты в отдельный
  > файл. Выполни работу тремя субагентами, каждый радикальнее предыдущего.
  Как применить у нас (без установки, своими силами): три субагента читают `~/.claude/CLAUDE.md`, `MEMORY.md` и один
  большой SKILL.md (начать с dropship-lessons, sourcing-1688) — мягкий / средний / радикальный вариант; ей показать
  разницу, **её решения не выкидывать** (правило «решённое не пересматривать»). Это часть пункта №1 «Уборка инструкций»
  в dropship-lessons → «Когда будет время». Вместо PR — копия файла до правки.
- **Гайды по экономии и глубине рассуждений.** OpenAI — гайд по GPT-6 Sol/Luna/Astra: выбор модели под задачу,
  экономия токенов, глубина рассуждений (PushEnter/13792, пост 844, 03.10) — принцип тот же, что `/effort` у нас.
  Anthropic — практический блог https://claude.dev (статьи, не документация; документация — code.claude.com/docs):
  разделы Agents, Skills, стоимость задач на Opus 5.5, контекстная инженерия (vibecoding_tg/3991, пост 801, 01.10).
  Когда будет время: прочитать «стоимость задач на Opus 5.5» и Skills, полезное перенести в этот скилл.
- **6 советов Anthropic по сессиям** (vibecoding_tg/3698, пост 98, 16.08) — у нас так:
  1. `/clear` между разными задачами («новости» → отбор 1688 → дела — каждый раз чистый лист).
  2. Модель и `/effort` выбрать ДО задачи (механика — medium, 1688/иски/радар — high).
  3. Файлы указывать через `@путь` — Claude не ищет их сам по всему диску.
  4. Резать лишний вывод команд флагами (`-q`, `| tail -20`, `--limit`), огромные выгрузки — читать субагентом.
  5. `/context` в начале — чем забит контекст (скиллы, MCP, память); лишние MCP отключать.
  6. `/compact` перед тем, как надолго отойти (кэш остынет через ~5 мин — см. выше).
- **Стиль ответов Concise** (короткие ответы; `/config` → Output style или `"outputStyle": "Concise"` в settings.json —
  vibecoding_tg/3714, пост 196, 20.08). **Не включаем:** ей нужны объяснения как новичку. Помнить, что есть.
- **«Второй мозг» и ошибка «каждый запрос вдвое дороже»** (proecomdmitriy/1140, пост 144, 18.08; та же настройка —
  1141, пост 182). У нас «второй мозг» уже есть: память + CLAUDE.md + скиллы с «граблями». Какая именно настройка
  удваивала цену — в видео (YouTube с этого ПК не открывается); самые вероятные у нас: max-effort по умолчанию,
  раздутые CLAUDE.md/описания скиллов, длинные сессии после остывания кэша — все три уже в правилах выше.
- **Бесплатные роутеры моделей — не используем** (решено 29.09, PushEnter/13670). Free Claude Code
  (python2day/8121, пост 377, 29.08: 50 провайдеров, «1,3 млрд бесплатных токенов», установка через `curl … | sh`)
  — тот же случай 🔴: текст задач и ключи уходят неизвестным провайдерам. Не ставить.

## Субагенты и проверка работы

- **Плагин «You should Know»** — отдельный агент читает вывод Claude и подсвечивает опасные мелочи (пример: повтор
  вызова оплаты → двойное списание) (vibecoding_tg/4006, пост 832, 03.10). Включение:
  `/plugin enable cc-plugin-you-should-know@builtin` (встроенный, от Anthropic). Когда будет время: включить и
  проверить на длинной задаче — сайт Frivent, сборщики, скрипты с ключами и Shopify API. Если команда не найдена —
  в нашей версии (2.1.292) его ещё нет, отметить дату и не искать замену у чужих.
- Идея «один делает — другой проверяет» — Orca, пункт №3 в dropship-lessons → «Когда будет время».
- **«Готово» ИИ — не доказательство.** У автора ИИ ответил «поменял остатки у 250 товаров», а в Shopify не изменилось
  ничего (proecomdmitriy/1141, пост 182, 19.08). Правило: после массовой правки — повторный запрос и счётчик
  «совпало N из M»; для Shopify есть скрипт `shopify-admin\scripts\proverit_pravku.py`. Так же для сборщиков:
  «собрано» = число строк в файле, а не слова отчёта; «панель обновлена» = новое время изменения файла.
- **ИИ — быстрый сотрудник, который иногда уверенно делает ерунду** (proecomdmitriy/1139, пост 124, 17.08): красивый
  текст карточки, который не продаёт; картинка, где не видно главного; 20 товаров, у половины не сходится экономика.
  У нас: сначала сами знаем, каким должен быть итог (строка «готово = …» в задаче), потом отдаём; отбор 1688 и
  юнит-экономику проверяем цифрами (sourcing-1688), карточки — по её вкусу, а не по «звучит профессионально».
- **Измерять качество скиллов, как Авито — агентов** (LLMScience/1028, пост 172, 19.08: удачный повторяющийся процесс →
  агент, у каждого — замер качества). У нас то же: процесс повторился 2–3 раза → скилл; для главных скиллов (tg-news,
  sourcing-1688, shopify-admin, dela) держать 2–3 проверочных примера «запрос → итог → как проверить» (шаблон —
  knowledge-library/references/agents-prompts-2026-09.md; прогон — `claude plugin eval`, пункт №8 «Когда будет время»).
- «14 ИИ-агентов как компания» (PushEnter/13617, пост 363, 28.08) — только посмотреть, как описаны роли маркетолога и
  финансиста, для наших скиллов. Автономный «стартап под ключ» не ждать; лишних агентов не добавлять (pass^k важнее).

## Объяснять просто (к правилу «объяснять как новичку»)

- **Приём Карпати — ASD-STE100** (упрощённый английский из руководств авиамехаников: ~900 слов, инструкция не длиннее
  20 слов, одно предложение — одна мысль). Модели этот стандарт знают (vibecoding_tg/4008, пост 837, 03.10).
  По-русски формулировка для себя: **одно предложение — одна мысль; инструкция не длиннее 20 слов; без редких слов.**
  Если слишком сухо — «приблизиться на 80%».
- Если текст не помогает — менять формат по лестнице: схема → интерактивная HTML-страница (Artifact) → видео.
- Применять: ответы ей; тексты лендинга Frivent для владельцев домов (инженерное объяснять так же, сложное — схемой);
  тексты в скиллах, которые она читает.

## Горячие клавиши и команды (шпаргалка python2day/8101, пост 216, 21.08; советы vibecoding_tg/3693, пост 81, 15.08)

Каждый день:
| Что | Зачем ей |
|---|---|
| `Esc Esc` | откат (rewind) к прошлому состоянию разговора/файлов — если Claude «ушёл не туда» |
| `Ctrl+B` | отправить долгую задачу в фон и продолжать говорить |
| `Shift+Tab` | режим разрешений (спрашивать / сам правит / план) |
| `Alt+P` / `Alt+T` | сменить модель / вкл-выкл расширенное размышление |
| `Ctrl+G` | написать длинную задачу во внешнем редакторе (удобно для «готово = …» + чеклист) |
| `Ctrl+R` | поиск по истории своих запросов |
| `!команда` | запустить команду терминала напрямую, без Claude (`! git status`) |
| `@файл` | добавить файл в контекст |

Команды: `/clear`, `/compact`, `/context`, `/resume` (вернуться к прошлой сессии), `/branch` (попробовать другой путь,
не ломая основной), `/btw` (побочный вопрос без засорения истории), `/plan` (план перед большой задачей), `/tasks`
(что идёт в фоне), `/diff`, `/code-review`, `/security-review`. Из терминала: `claude -c` (продолжить последнюю),
`claude -p "…" --max-budget-usd 5` (разовый запуск с потолком трат). Правила проекта — `CLAUDE.md` в папке проекта и
`.claude/rules/*.md`. Шпаргалку целиком (картинка/PDF) — скачать из поста в Telegram, когда будет время.
Руководство «40+ советов» (строка состояния, голосовой ввод, автономные сценарии) — ссылка в посте vibecoding_tg/3693;
строку состояния у нас заменяет виджет `claude_widget` / свой мод (раздел «Моды»).

## Claude Code с телефона

- **Встроенный Remote Control** (vibecoding_tg/3731, пост 242, 22.08; https://code.claude.com/docs/en/remote-control):
  на ПК запустить `claude remote-control` → в приложении Claude на телефоне, вкладка Code, появится карточка
  компьютера → выбрать папку (например `C:\Users\User\tg_monitor`) → сессия идёт на ПК. Сама переподключается при
  смене Wi-Fi, модель и effort синхронизируются. Для нас: «новости», сбор 1688, «разбери входящие» — с телефона, пока
  дома включён компьютер. 🟢 — канал Anthropic, тот же аккаунт. Когда будет время: попробовать один раз.
- **HAPI** (PushEnter/13577, пост 162, 19.08) — сторонний пульт для Claude Code/Codex/Cursor, голос, управление через
  Telegram. **Не ставим, пока работает встроенный Remote Control:** сторонний сервис получает доступ к терминалу её ПК
  (🔴 по правилу данных, если ходит через чужой сервер).
