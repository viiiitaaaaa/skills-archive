## Проверка реквизитов — `scripts/check_rekvizity.py`

Проверяет контрольную сумму — ловит опечатки (лишняя/потерянная цифра, переставленные соседние цифры —
~98 % перестановок). Тип определяет сам по числу цифр: ИНН 10 (организация) и 12 (физлицо/ИП),
СНИЛС 11, ОГРН 13, ОГРНИП 15. Пробелы и дефисы можно оставлять.

```
python "C:\Users\User\.claude\skills\knowledge-library\scripts\check_rekvizity.py" 7707083893
python ...\check_rekvizity.py 7707083893 1027700132195 "112-233-445 95"   # несколько сразу
python ...\check_rekvizity.py ИНН 770708389                               # слово-подсказка перед номером
python ...\check_rekvizity.py --text "ИНН 7707083893, ОГРН 1027700132195"  # найти номера в тексте
python ...\check_rekvizity.py --file "путь\к\документу.txt"               # все номера в файле
python ...\check_rekvizity.py --test                                      # самопроверка (21 тест)
```

Ответ: `ВЕРНО: …` или `ОШИБКА контрольной суммы: … в конце стоит X, а по расчёту должно быть Y`.
Код выхода 0 — всё верно, 1 — есть ошибка. Из Python: `from check_rekvizity import check; check('7707083893')['ok']`.

Важно помнить и говорить пользователю:
- «Верно» = номер без опечатки, но **не** доказательство, что организация существует. Существование и
  название — только по реестру (egrul.nalog.ru).
- Для скилла **dela**: перед отправкой иска/обращения прогнать документ через `--file`/`--text`.
- Номера хранить строками: Excel срезает ведущие нули (ИНН из 9 или 11 цифр — частый признак).
