asyncio – это библиотека для написания конкурентного кода с использованием
синтаксиса async/await .

asyncio используется как основа для множества асинхронных фреймворков Python,
которые обеспечивают высокопроизводительные сетевые и веб-серверы,
библиотеки для подключения к базам данных, распределенные очереди задач и т.д.

asyncio часто идеально подходит для IO-зависимого и высокоуровневого структурированного сетевого кода.
