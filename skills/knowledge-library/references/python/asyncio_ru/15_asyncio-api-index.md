# High-level API Index Индекс высокоуровневого API ​

На этой странице перечислены все высокоуровневые API asyncio, поддерживающие async/await.

## Tasks Задачи ​

Утилиты для запуска программ asyncio, создания задач и ожидания нескольких событий с тайм-аутами.

run()

Создать цикл событий, запустить корутину, закрыть цикл.

Runner

Менеджер контекста, упрощающий несколько асинхронных вызовов функций.

Task

Объект задачи.

TaskGroup

Менеджер контекста, содержащий группу задач. Предоставляет удобный и надёжный способ ожидания завершения всех задач в группе.

create_task()

Запускает задачу asyncio и возвращает её.

current_task()

Возвращает текущую задачу.

all_tasks()

Возвращает все ещё не завершённые задачи для цикла событий.

await sleep()

Приостановить выполнение на заданное количество секунд.

await gather()

Планировать и ожидать выполнения нескольких задач одновременно.

await wait_for()

Запуск с тайм-аутом.

await shield()

Защита от отмены.

await wait()

Мониторинг завершения.

timeout()

Запуск с тайм-аутом. Полезно в случаях, когда wait_for не подходит.

to_thread()

Асинхронный запуск функции в отдельном системном потоке.

run_coroutine_threadsafe()

Запланировать корутину из другого системного потока.

for in as_completed()

Мониторинг завершения с циклом for .
