# 13. Что дальше?

После прочтения этого руководства у вас, вероятно, ещё больше укрепился интерес к использованию Python — хочется применить его для решения реальных задач. Куда обращаться, чтобы узнать больше?

Это руководство является частью документации Python. В этот комплект также входят:

- Python built-ins reference : подробное описание встроенных типов и функций Python.

- The Python standard library : полный (хотя и сжатый) справочный материал о типах, функциях и модулях стандартной библиотеки. Стандартный дистрибутив Python включает в себя огромное количество дополнительного кода. В нём есть модули для чтения почтовых ящиков Unix, получения документов по HTTP, генерации случайных чисел, разбора параметров командной строки, сжатия данных и многих других задач. Беглый просмотр справочника по библиотеке даст вам представление о доступных возможностях.

- Installing Python modules объясняет, как устанавливать дополнительные модули, написанные другими пользователями Python.

- Справочник по языку Python : Подробное описание синтаксиса и семантики Python. Чтение может показаться столь же непростым, сколь и полезным, это полный справочник по самому языку.

Другие ресурсы по Python:

- https://www.python.org : Основной сайт Python. Здесь находятся код, документация и ссылки на другие ресурсы по Python в сети.

- https://docs.python.org : Быстрый доступ к документации Python.

- https://pypi.org : Каталог пакетов Python, ранее известный под шутливым именем the Cheese Shop [ 1 ] . Здесь собраны доступные для загрузки модули, созданные пользователями. Когда вы начнёте публиковать свой код, вы сможете зарегистрировать его здесь, чтобы другие могли его найти.

- https://code.activestate.com/recipes/langs/python/ : Книга рецептов Python — это обширная коллекция примеров кода, крупных модулей и полезных скриптов. Особенно удачные материалы собраны в одноимённой книге Python Cookbook (O’Reilly & Associates, ISBN 0-596-00797-3), которая издана на русском под названием “Бизли Д., Джонс Б. К. Python. Книга рецептов” (ДМК Пресс, 2019, ISBN 978-5-97060-751-0).

- https://pyvideo.org собирает ссылки на видео, связанные с Python, с конференций и встреч групп пользователей.

- https://scipy.org : Проект Scientific Python, включающий модули для быстрых операций над массивами и множество пакетов для линейной алгебры, преобразований Фурье, нелинейных решателей, распределений случайных чисел, статистического анализа и многого другого.

По вопросам, связанным с Python, и сообщениям об ошибках можно писать в группу новостей comp.lang.python или в почтовую рассылку python-list @ python . org . Между ними настроен шлюз: сообщения, отправленные в одну, автоматически появляются в другой. Ежедневно там публикуются сотни сообщений: вопросы (и ответы на них), предложения по улучшению и анонсы новых модулей. Архив рассылки доступен по адресу https://mail.python.org/pipermail/ .

Прежде чем задать вопрос, убедитесь, что изучили список Часто задаваемых вопросов (также называемый ЧаВо). ЧаВо отвечает на многие вопросы, которые возникают вновь и вновь, и, возможно, уже содержит решение вашей проблемы.

Примечания

“Сырная лавка” (англ. “Cheese Shop”) — это скетч комедийной группы Monty Python: покупатель зашёл в сырную лавку, но какой бы сорт сыра он не попросил, продавец отвечает, что его нет.
