## amazon_fba_shopify (1)


### Магазин одежды

- **Не занижать цену из неуверенности.** Цена должна соответствовать обещанию и позиционированию; слишком дешёвая «премиальная» юбка вызывает недоверие. Зачем: цена = сигнал качества. Когда: ценообразование. (стр. 201–202) → knowledge-library

## bierut_graphic_design (3)


### Магазин одежды

- **Имя — просто и честно.** При выборе имени магазина рассмотреть «скромное честное» имя (The Good Diner — «просто хороший») и проверить, не слишком ли умное для аудитории (Robin Hood: каламбуры отвергнуты). (стр. 81, 308) → knowledge-library
- **Имя, спрятанное в имеющемся.** Поискать имя/знак внутри уже имеющихся слов (Ted из UniTED, «Nuts.com» вместо «Nuts Online»); короткий домен, совпадающий с именем, — сильный актив. (стр. 205, 230) → knowledge-library
- **Убрать лишнее из названия.** Как United без «Airlines» — сократить название до сути (без «Shop», «Store», «Online»). (стр. 198, 205) → knowledge-library

## dropshipping_affiliate (1)


### Магазин одежды

- **Не демпинговать.** Не снижать цену «чтобы продать» — часть покупателей считает «дороже = лучше»; для аудитории 28+ держать цену и поднимать ценность (фото, описание); при установке цен. (гл. 10, стр. 73; гл. 13, стр. 84) → knowledge-library

## high_priced_products (5)


### Магазин одежды

- **Не демпинговать до неправдоподобия.** Не ставить цену, которая выглядит «слишком дёшево, чтобы быть хорошим» для аудитории 28+. Зачем — эффект Джулиани: низкая цена = «наверное, плохо». Когда — при выборе цены. (гл. 6, стр. 42–43) → скилл knowledge-library
- **Мини-размер дороже за грамм — бывает.** Если появляется «пробная» версия (например, мини-аксессуар в подарочной коробке), её можно продавать не дешевле пропорции, если она решает задачу (подарок, проба). Зачем — Coca-Cola: меньше ≠ дешевле. Когда — при допродажах. (гл. 7, стр. 47) → скилл knowledge-library

### Новости, данные, Claude Code

- **Тексты по 8 элементам — как шаблон для агента.** При генерации описаний/писем Claude давать структуру: заголовок, выгоды, доказательство, гарантия, бонус, призыв, способ заказа, P.S. Зачем — один «скелет» адаптируется под любой канал. Когда — в промптах для текстов магазина и Frivent. (гл. 17, стр. 101–102) → скилл knowledge-library
- **Чек-лист вычитки текста.** Перед публикацией прогонять текст по «мини-советам» (35 пунктов) — можно скриптом/агентом. Зачем — быстро ловить слабые места. Когда — финальная проверка текстов. (гл. 21, стр. 137–139) → скилл knowledge-library
- **Моделирование, а не копирование.** Брать удачное письмо/лендинг-образец и построчно перекладывать на свой продукт, меняя слова. Зачем — быстрый старт и законность. Когда — когда «не идёт» текст. (гл. 25, стр. 168–170) → скилл knowledge-library
