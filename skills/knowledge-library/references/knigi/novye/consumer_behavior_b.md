## p154-160 (кн.133-139)
- Exhibit 6.1 уровни: класс (фастфуд) → форма (пицца/бургеры) → бренд → модель (точка) → общая ситуация → конкретная ситуация.
- Brand equity: Marriott имя на Fairfield Inn → загрузка +15%; Hitachi и GE одинаковые ТВ с одного завода — Hitachi на $75 дороже.
- Brand equity для потребителя = сильная позитивная установка + благоприятные значения/убеждения + доступность в памяти → отношения «потребитель–бренд». Build / borrow (расширения: Coca-Cola, Tide) / buy (Philip Morris→Kraft). Успех расширения — зависит от того, подходят ли ключевые значения бренда новому товару.
- Highlight 6.2 Building brands (Interbrand 2000: 4 из 5 ценнейших — техника). Тактики: 1) раздавай бесплатно (AOL диски, пробный период); 2) PR как война (Sun разослал журналистам кофе «Why is Microsoft so jittery?» перед презентацией MS, семинар рядом — 250+ чел.); 3) работай с вебом — партнёрка Amazon Associates 5–15% комиссии, >40 000 к 1998; 4) смешно (Sun комикс с маскотом Duke, Priceline с Шатнером, «Do you Yahoo!?»).
- Tracking studies — регулярные опросы установок; Howard Johnson's не отслеживал (только карточки отзывов на столах), конкуренты делали тесты → упадок, купил Marriott.
- Salient beliefs: из всех убеждений активируются немногие (Crest: фтор, мята, гель, помпа, тартар). Только они формируют установку. Могут быть о свойствах, последствиях, ценностях, стране происхождения, тактильных/визуальных образах, эмоциях.
- Что делает убеждение salient: стимулы рядом (POS, реклама, упаковка), недавние события, настроение, активные цели/ценности. Пример: табличка скидки на ботинки делает цену salient. После стоматолога — кариес. Реклама Tums «smooth as silk» — создать новые salient убеждения.
- Fishbein: Ao = Σ bi·ei (b — сила убеждения 0..10 / вероятность, e — оценка свойства -3..+3). Пример 7UP: без кофеина b10 e+3, натуральное b5 e+1, лимон-лайм b8 e-1 → 27; Diet Pepsi: без калорий 7×2, кофеин 6×(-3), кола 10×1 → 6. Модель предсказывает, не описывает реальный подсчёт в голове.
## p161-167 (кн.140-146)
- bi измеряется «Насколько вероятно, что 7UP без кофеина?» 1..10; ei «7UP без кофеина» Very bad -3..+3 Very good.
- Убеждения из личного опыта сильнее, чем из рекламы/продавца → давать пробовать: бесплатные образцы, маленькие пробные размеры, купоны, пробный период без обязательств.
- Обычно salient убеждений не больше 7–9; для малововлечённых товаров — 1–2; для значимых — несколько.
- Exhibit 6.4: оценка свойства «стекает» с конечной ценности по цепочке средства–цели (без кофеина → не нервничаю → расслабление). Ситуация меняет ei (утром нужен кофеин → минус).
- Применения: понять важные атрибуты — авиапассажиры ругают еду, но важной её считают 40%; расписание >90%, быстрая регистрация ~80%, удобные кресла ~80%, пунктуальность ~85%; на еду тратят $4,25/пасс. Сегменты по частоте: редкие (1–2 поездки) — безопасность и багаж, частые (10+) — расписание и мили.
- Диагностика стратегий: 90-е — ценность/выгодная покупка модно (Walmart «Always Low Prices», Southwest, Taco Bell меню ~$1).
- Ситуации: снеки — для десерта/ТВ/обеда детям важны экономия и вкус; для детского праздника — питательность и удобство.
- 4 стратегии изменения установки: 1) добавить новое salient убеждение (с позитивной e) — «crunchy» везде (Honey Crunch Corn Flakes, Yoplait Crunchy) — хрустящее = свежесть, веселье, снятие стресса; 2) усилить силу позитивного убеждения (Papa John's «Better ingredients, better pizza» — дороже Little Caesars, не быстрее Domino's, но вкус); 3) изменить оценку сильного убеждения — новая цепочка к ценности (Kellogg клетчатка → профилактика рака; жир был «плюс», стал «минус»; Sealtest Free, Kraft обезжиренное → здоровье, долгая жизнь); 4) сделать существующее позитивное убеждение более salient (Hawaiian Tropic — солнцезащита → рак кожи и преждевременные морщины).
- Highlight 6.3 The Truth (антикурение подростки 12–17): дерзкая подача, 1200 мешков для тел = смертей в день у штаб-квартиры Philip Morris; 150 000 кепок/футболок; курение старшеклассников 36,4% (1997) → 21,9% (2005). Табак убил ~430 000 за год.

## p168-174 (кн.147-153)
- Ao связана с общей картиной поведения, но не с конкретным поступком (любят Porsche — но один читает тесты, другой ходит в салон, третий мечтает).
- Теория обоснованного действия (Fishbein): B ~ BI = Aact(w1) + SN(w2). Aact = Σ bi·ei по последствиям действия; SN = Σ NBj·MCj (нормативные убеждения «близкие хотят, чтобы я…» × мотивация подчиниться). Внешние факторы (среда, ценности, личность, демография) влияют только через эти компоненты. Не для автоматических действий.
- Поведение = действие + объект + ситуация + время (купить купальник в этом магазине на этой неделе).
- BI измеряют: «Учитывая всё, насколько вероятно, что вы ... на этой/след. неделе?» 1..10.
- Пример Chevrolet: Ao + (недорогой, надёжный), Aact «купить в этом году» − (финансовые трудности, содержание, страховка, дешевле потом).
- Highlight 6.4 JetBlue: 6000 сотр., ~100 самолётов, высшая заполняемость и маржа; один класс, больше места, кожа, ТВ DirecTV; «crewmembers»; CEO летает сам и собирает отзывы; клиенты попросили low-carb снеки — добавили миндаль; «story booth» — клиенты записывают истории; на сайте истории (предложение руки на борту, iPod вернули). В NY-журнале — один из 5 вещей, без которых не может жить.
- Информация о магазине влияла на Aact (купить), но не на Ao товара — проверять, что именно меняем.
- Rick и Linda любят шопинг, но не по субботам (толпы).
- SN измеряют: «Семья хочет, чтобы я пользовался купонами» 1..10; «Насколько хотите делать то, что хочет семья» -3..+3.
- Одежда на вечеринку/работу — сильнее SN («вписаться»), чем Aact. Лекарство Contac — Aact.
- Брайан 26 лет: дома с ТВ — дешёвое местное пиво (Aact); в баре с коллегами — дорогое импортное (SN).
- Если SN главное — показывать в рекламе одобрение друзей/семьи/коллег; если Aact — показывать позитивные последствия.
- Намерения→поведение: из намеревавшихся купить авто купили в течение года ~60%; из не намеревавшихся 17% купили. Бытовая техника: назвали бренд на входе — только 20% вышли с ним. United Airlines опрос каждые 3 мес.
- Exhibit 6.7 факторы, ослабляющие связь: время между замером и поступком; разный уровень специфичности; непредвиденное событие (чипсов нет); непредвиденная ситуация (пунш на 8 бутылок → дешёвое шампанское Andre); степень волевого контроля (болезнь); стабильность намерений; новая информация.

## p182-188 (кн.161-167)
- Меган: план $300/мес на 3 года для машин <3 лет, ≤$250 для старше; иначе 4 года макс. Смотрела по объявлениям; Mustang — стук; Pontiac G6 продан, предложили Vibe — продавцу не доверяла; Malibu «как у папы» — не понравился вид; Cobalt $280 на 4 года; в итоге Mitsubishi Eclipse красный (её любимый цвет) $270/3 года — купила, не досмотрев весь список, т.к. экзамен и «сделка выгодная». Решения не линейны, оценка по ходу.
- Decision = выбор между действиями (поведениями), не между объектами. Ключевой процесс — интеграция → выбор = BI (план решения).
- Exhibit 7.1 когнитивная модель: воздействие → интерпретация (внимание, понимание) → новые знания ↔ память → интеграция → установки/намерения → поведение → обратно на среду.
- Привычные покупки — без нового решения (намерения из памяти); непроизвольное — выкладка/расстановка в магазине задаёт маршрут.
- Highlight 7.1 Фэды (fads): Live Strong браслеты, Ugg, мешковатые джинсы; самокат Razor — с 1999 Япония→Австралия→Гавайи→Калифорния; янв–июль 2000 в США 600 000 шт на $20 млн, продажи почти удваивались каждый месяц с марта. Теория 1992: в неопределённости люди копируют других (викарное научение) → «каскад подражания»; несколько «да» перекрывают своё сомнение; несколько «нет» — фэд быстро умирает. SUV — фэд стал трендом. Одежда, музыка, мебель — высокая неопределённость.
- Exhibit 7.2 общая модель: осознание проблемы (разрыв идеал/факт) → поиск альтернатив → оценка → покупка → использование и переоценка. Реально: не линейно, постоянные взаимодействия, много задач и решений.
- Элементы: представление проблемы (problem representation = decision frame): конечная цель, иерархия подцелей, знания, эвристики. Маркетинг влияет на фрейм: в рекламе показать, как решать; продавец подсказывает цель (страховка → колледж детей), знание (вспышка без красных глаз), правило выбора («дороже пальто — лучше качество»).
- Конечные цели: от конкретных (лампочка горит) до психосоциальных (вино показывает вкус гостям) и ценностей (машина — сила/самооценка); позитивные и негативные (избежать). Иерархия целей — разбиение на подзадачи (какой салон, когда ехать).
## p189-195 (кн.168-174)
- Знания: альтернативы выбора и критерии выбора. Consideration set (набор рассмотрения) — подмножество. Exhibit 7.3: все бренды → неизвестные (никогда не найдены / найдены случайно / найдены намеренным поиском) + знакомые (evoked set — всплывают из памяти / не вспомнились) → consideration set.
- Кали Клена (Kellogg) летала Милуоки–Чикаго $64–186 до 3 ч, поезд Amtrak вдвое быстрее и $39 — но поезд никогда не входил в её набор.
- Top-of-mind awareness: использованные раньше бренды вспоминаются чаще → у крупных преимущество (спираль). Повторяющаяся дорогая реклама (сигареты, пиво, газировка, паста). Дистрибуция: 65% решений по еде принимаются в магазине → всегда быть на полке. Упаковка ловит внимание и передаёт ингредиенты/удобство/ценность.
- Choice criteria — последствия (функциональные, психосоциальные, ценностные). Подарок vs себе: свитер себе — модный дизайн; в подарок — «дорого выглядит» (щедрость).
- Стимулы активируют критерии: ценники скидок → цена; «без сахара/мало натрия» → здоровье; продавцы делают выгоды критериями.
- Только различающие (discriminant) последствия — критерии. Если у всех одинаково — не критерий. Критерии зависят от набора альтернатив.
- Реклама GM Goodwrench «Lifetime guarantee?» — простая реклама для top-of-mind.
- Highlight 7.2 Отзывы и онлайн-помощники: rateyourprofessor, Amazon отзывы, eBay рейтинги продавцов (заменяют атмосферу магазина как сигнал доверия), word-of-Web; recommendation agent (подборка под атрибуты) и comparison matrix (сравнение бок-о-бок, edmunds.com: кабриолеты $15–25 тыс.). Люди — «когнитивные скупердяи» (cognitive misers): помощники снижают усилие и часто улучшают решение.
- Негативные критерии (цена, риск) — снижать воспринимаемый риск гарантиями. 7UP «Never had it, never will» — кофеин как негатив. Реклама «Lean beef is nearly as lean as chicken» — снижение риска.
- Интеграция: компенсаторная (Σbe, минус компенсируется плюсом; реально 1–2 критерия одновременно) vs некомпенсаторная. Exhibit 7.4 (Bettman 1979): мультиатрибутная; конъюнктивная (минимум по каждому критерию; Эди отвергла Reebok из-за цены); дизъюнктивная (достаточно превысить минимум по одному); лексикографическая (лучший по самому важному, при равенстве — по второму; Тина выбрала туфли по цвету под наряд); исключение по аспектам (порог по критерию, отсеивать по одному, пока не останется одна); комбинация (Билл: сначала отсечь рестораны без салат-бара, потом компенсаторно 2–3 по цене/разнообразию/атмосфере).
- Интеграция конструируется на месте. Эвристики «если…то»: поисковые (купить мелкую технику — прочитать тесты Consumer Reports), оценочные (на диете — главное калории), выбора (купить то же, что в прошлый раз, если устроило; совет эксперта).
- Decision plan — конкретный («сегодня в Penney's купить голубой хлопковый свитер к новым брюкам») или общий; одно действие или серия (Val в Bloomingdale's и Macy's — смотреть лёгкую куртку).
