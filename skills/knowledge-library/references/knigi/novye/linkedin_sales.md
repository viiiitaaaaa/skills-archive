## Конспект по главам (черновые заметки, гл. 1–12)
- Гл.1 история LinkedIn; гл.2 бесплатный vs Sales Navigator (95 % результатов автора — на бесплатном); гл.3 пять столпов:
  профиль → сеть → сообщения → контент → личный бренд (порядок важен: вирусный пост на пустой профиль = «ведро с дырками»).
- Гл.4 «кто смотрел профиль» — 5 шагов, сообщение «Спасибо, что заглянули… как вы сейчас используете X?» → шестизначная сделка.
- Гл.5–7 профиль: чек-лист 9 пунктов, фото 400×400 (21× просмотров, 36× сообщений), баннер 1584×396, заголовок 3 стиля,
  саммари 2000 знаков: кому/как/чего достигают/кому помог/как поможем/как связаться; рекомендации + рефералы (91 %/11 %).
- Гл.8 поиск: идеальный профиль клиента, булев поиск, поиск по контенту, «призрачный» поиск через Google.
- Гл.9–10 сеть: 20–25 запросов/день, отзыв запроса через 2–3 недели, follow + вовлечение, шаблоны запросов.
- Гл.11–12 сообщения: цель — разговор, не продажа; анти-примеры; шаблоны «как поможем», «кейс», «комплимент контенту», «мнение эксперта».
