# Учебник → цены интернет-магазина одежды (ARTMELLIO)

Конспект своими словами по учебнику Emerson «Intermediate Microeconomics» (CC BY-NC-SA 4.0).
Номер в скобках — глава/раздел; полный текст — файл `NN_*.md` в этой папке.

## 1. Эластичность: насколько покупатель чувствителен к цене (гл. 5, раздел 5.5)

**Эластичность спроса по цене** ε = (% изменения продаж) / (% изменения цены). Всегда отрицательная.
- |ε| > 1 — **эластичный** спрос: подняли цену на 10 % → продажи упали больше чем на 10 %, выручка падает.
  Типично для базовых вещей, у которых много одинаковых аналогов (белая футболка, простая юбка).
- |ε| < 1 — **неэластичный**: цену можно поднять, выручка вырастет. Типично для вещи «с изюминкой»,
  которую не найти рядом.
- **Перекрёстная эластичность** (5.5): как продажи вещи А зависят от цены вещи Б. Положительная —
  заменители (две похожие юбки), отрицательная — дополнения (юбка и подходящий к ней свитер → повод для набора).

Как измерить у нас: меняем цену одного товара на 10–15 % на 1–2 недели при одинаковом трафике,
сравниваем конверсию. ε ≈ (ΔQ/Q) / (ΔP/P).

## 2. Какую наценку ставить: индекс Лернера (гл. 15, раздел 15.3)

Фирма с «своей» кривой спроса (а магазин с уникальным ассортиментом — такая) максимизирует прибыль, когда
**(P − MC) / P = −1/ε**, где MC — предельные издержки (себестоимость ещё одной проданной вещи).
Отсюда **P = MC · ε / (ε + 1)**:

| ε | Наценка сверх MC | Пример: MC = $15 |
|---|---|---|
| −1.5 | ×3.0 | $45 |
| −2 | ×2.0 | $30 |
| −3 | ×1.5 | $22.5 |
| −5 | ×1.25 | $18.75 |

Выводы: чем больше у вещи прямых аналогов (эластичнее спрос), тем тоньше наценка;
работать на неэластичном участке (|ε| < 1) никогда не выгодно — значит, цену можно поднимать (15.2).
Для дропшиппинга MC = закупка на 1688 + посредник + доставка в США + комиссия платёжки + реклама на одну продажу.

## 3. Разные цены для разных покупателей (гл. 16 — самая полезная для нас)

- **Первая степень** (16.2) — у каждого своя цена. Нам недоступно; ближе всего — персональные промокоды
  в брошенной корзине.
- **Третья степень, групповая** (16.3) — разные цены для групп: первый заказ со скидкой, подписчики рассылки,
  разные рынки/валюты. Правило: группе с более эластичным спросом — ниже цена. Условие: группы нельзя
  «перепродать» друг другу (скидка должна быть привязана к почте/первому заказу).
- **Вторая степень, скидки за объём** (16.4) — «1 шт — $30, 2 шт — $50». Покупатель сам выбирает
  (самоотбор), знать его заранее не нужно. Нелинейные цены: цена за единицу падает с количеством.
- **Двухчастный тариф и связанные продажи** (16.5) — плата за вход + цена за единицу (клуб/подписка);
  «товар + обязательный расходник». Для одежды — редко.
- **Наборы (bundling)** (16.6) — продавать вместе дешевле суммы. *Чистый* набор — только комплектом;
  *смешанный* — и по отдельности, и набором со скидкой (наш случай: «сет» из юбки и свитера + каждая вещь
  отдельно). Работает, когда покупатели по-разному ценят вещи (одна больше хочет юбку, другая — свитер):
  набор «усредняет» готовность платить и забирает больше выручки.
  Связано с решением «не мини/комплекты» — это про ассортимент поставщика, а смешанный набор из наших
  отдельных вещей ему не противоречит.
- **Версии (versioning)** (16.6) — «люкс»-версия без реальной разницы в себестоимости
  (упаковка, лимитированный цвет, «коллекционный» ярлык).
- **Барьеры (hurdles)** (16.6) — скидка тем, кто готов потрудиться: распродажа в конкретный день,
  код из рассылки. Чувствительные к цене пройдут барьер, остальные купят по полной.

## 4. Издержки: что считать (гл. 7–9)

- **Постоянные** (не зависят от продаж: Shopify, приложения, домен) и **переменные**
  (растут с каждой продажей: товар, доставка, комиссии, реклама) — гл. 8, 8.1.
- Решение «продавать ли товар» — по переменным: если цена выше средних переменных издержек, продажа
  покрывает часть постоянных (гл. 9, 9.1–9.2, правило закрытия).
- **Кривая обучения** (8.4): со временем издержки на единицу падают (дешевле реклама, лучше посредник) —
  стартовая цена может быть ниже «идеальной», пока собираются отзывы.
- Минимизация издержек (гл. 7): при выборе посредника/способа доставки сравниваем «цена за результат»
  (стоимость доставленной вещи), а не одну тарифную ставку.

## 5. Наш рынок: монополистическая конкуренция (гл. 19)

Одежда онлайн — учебный пример этой модели (сама глава разбирает Nike и школьную форму): войти легко,
продавцов много, но каждый немного отличается (стиль, фото, подборки) и поэтому имеет **свою** наклонную
кривую спроса и может ставить цену выше себестоимости (19.1). Но пока есть прибыль, приходят новые
продавцы с похожим товаром, и в долгом периоде прибыль стремится к нулю (19.2).
Практически: прибыль живёт, пока есть **отличие** — изюминка товара, единый стиль витрины,
ранний вход в тренд (радар). Как только товар начинают продавать все — спрос становится эластичным
(п. 1–2), цену придётся снижать; пора менять ассортимент.

## 6. Ещё пригодится

- **Асимметричная информация** (гл. 22, 22.1–22.2, «рынок лимонов»): покупатель не видит качество вещи
  до покупки → не доверяет новому магазину → ждёт низкой цены. Лечится сигналами: отзывы с фото,
  понятный возврат, реальные замеры, гарантия.
- **Теория игр, Бертран** (гл. 17–18): если товар одинаковый, ценовая война с конкурентом ведёт цену
  к себестоимости. Не соревноваться ценой на одинаковом товаре — отличаться.
- **Сравнительная статика** (гл. 11): как сдвигается спрос при изменении сезона, моды, доходов —
  отличать «сдвиг кривой» (тренд вырос) от «движения по кривой» (мы снизили цену) — гл. 5, 5.4.
