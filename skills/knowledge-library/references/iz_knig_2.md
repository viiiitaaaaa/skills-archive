- **Поиск медленного места по списку.** Сложность хуже линейной (двойной цикл по таблице); лишние проходы по данным; повторные запросы по одному товару; нет кэша; блокирующие операции — и просить «оценку ожидаемого ускорения». (стр. 99) → `knowledge-library`

## Котлер «10 смертных грехов» (2)


### Магазин одежды

- **Проверка разброса цен до назначения цены.** Найти ту же или похожую модель у 5–10 продавцов в США (поиск по фото) и записать минимум, медиану и максимум; нашу цену ставить с пониманием, где мы в этом разбросе и чем оправдана разница. Зачем: у Котлера одна камера у 25 продавцов стоила от $339 до $449; покупатель онлайн это видит. Когда: расчёт цены в юнит-экономике. (Предисловие, стр. 14) → `sourcing-1688`, `knowledge-library`

### Новости, данные, Claude Code

- **Скиллы = «панель процессов».** Каждый повторяющийся процесс (проверка кандидата, выбор поставщика, подготовка КП) держать как пошаговую инструкцию с примером в скилле. При разборе работы проверять: есть ли скилл для процесса, который мы делали уже 3+ раза. Зачем: P&G сделала такие панели для всех маркетинговых процессов, а новый менеджер набирает «проверка концепции» и видит 4-этапный тест с примером. Когда: после каждой новой повторяющейся задачи. (гл. 10, стр. 150–151) → `knowledge-library`

### Магазин одежды
