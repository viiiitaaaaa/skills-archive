## «8-Figure Ecommerce Engine» (12)


### Магазин одежды

- **Набор «2 шт. −10%».** Протестировать двойку той же вещи со скидкой 10% (в кейсе половина взяла двойку, AOV +25%, ROAS 1,7→2,2) — поднимает чек и окупаемость рекламы — когда реклама в нуле. (гл. 1) → shopify-collections
- **Набор из двух цветов со скидкой 15%.** Смотреть, какие цвета берут вместе, и сделать «2 цвета −15%» — +чек, в кейсе рост ×15 вместе с УТП — после первых заказов. (гл. 3) → shopify-collections
- **Допродажа количеством.** «Возьмите 2 / 3 со скидкой» на карточке и в корзине (в кейсе +39% AOV) — самый работающий вид допродажи — при запуске карточки. (гл. 3) → shopify-collections
- **Линейка 3–12 моделей в коллекции.** Держать в каждой теме/коллекции 3–12 вещей, чтобы были наборы и разные сообщения для разных сегментов — масштабирование без хаоса — при сборке коллекций. (гл. 5) → shopify-collections
- **«Якорный» дорогой набор.** Поставить рядом с отдельными вещами дорогой образ-набор: на его фоне отдельная вещь выглядит выгодной и чаще покупается — рост конверсии средних цен — при оформлении коллекции. (гл. 5) → shopify-collections
- **Три уровня цены.** Где можно — давать «1 шт / 2 шт / 3 шт» или «базовый / с аксессуаром / полный образ» — выбор тянется к среднему — при настройке оффера. (гл. 5) → shopify-collections
- **«Купи 2 — третья бесплатно» для одежды.** Для неповторяемых товаров вместо подписки — 2+1 (работает заметно, хоть и слабее подписки) — тест после первых продаж. (гл. 6) → shopify-collections
- **Новая капсула раз в квартал.** Запускать новую мини-коллекцию (3–12 вещей) раз в квартал по сезону радара, с 2–4-недельным анонсом/предзаказом — новинка оживляет продажи на ~30 дней — по календарю. (гл. 9) → shopify-collections
- **Не запускать новинки каждую неделю.** Ритм — месяц-квартал; еженедельно — слишком часто, теряется эффект — при планировании контента. (гл. 9) → shopify-collections
- **Входные товары и товары для допродажи.** Разделить ассортимент: 2–3 «входные» вещи по привлекательной цене для рекламы + остальное для допродаж/повторных покупок — дешевле привлечение, выше LTV — при структуре каталога. (гл. 10) → shopify-collections
- **Набор «по назначению» на отдельной посадочной.** 2–5 вещей как единый «образ» (например, «Офисная капсула»): −15–35%, или «3 вещи + подарок», плюс бесплатная доставка только для наборов; несколько наборов на разных ценах и один дорогой — AOV — при оформлении коллекций. (Ресурсы, хак 1) → shopify-collections
- **Допродажа количеством с подсветкой.** 1 / 2 / 3 шт: средний — «Самый популярный», верхний — «Лучшая выгода», экономия в % и $, цена за штуку, если сумма > $70, бесплатная доставка на больших пакетах; для одежды — «купи 3 — 4-я в подарок» (40–60% берут больший вариант без потери конверсии) — при настройке карточки. (Ресурсы, хак 2) → shopify-collections

## Miller «Amazon FBA and E-commerce With Shopify» (3)


### Магазин одежды

- **Характеристики полностью — ради фильтров.** Цвет, размер, ткань, длина, посадка — как поля/метаполя, чтобы работали фильтры коллекций. Зачем: книга — фильтры приводят «точных» покупателей. Когда: заведение каталога. (стр. 34) → shopify-collections
- **Линейка из трёх цен в коллекции.** В каждой коллекции держать базовую, среднюю и «премиальную» позицию (например, юбка $39 / $59 / $89). Зачем: дорогая делает среднюю «разумной», и кто-то купит дорогую. Когда: сборка коллекций. (стр. 205–207) → shopify-collections
- **Товары доступны с главной + посадочные страницы.** С главной — прямые ссылки на хиты и коллекции; под каждую категорию и стиль — своя посадочная страница со своим текстом и ключами. Зачем: поисковик и покупатель находят товар быстрее. Когда: сборка главной и коллекций. (стр. 160–161) → shopify-collections

## Belch «Advertising and Promotion», ч. A (2)


### Магазин одежды

- **Сегментация по выгодам и поведению.** Делить не только «женщины 28–45», а по искомой выгоде (для работы / для отпуска / подарок себе) и по поведению (новички, повторные, «тяжёлые» 20% дающие 80% выручки); покупательница подарка и носящая ищут разное. Когда: коллекции и аудитории рекламы. (гл.7, с. 206–208) → shopify-collections
- **Коллекции «по поведению» (Red Balloon).** Разделы сайта по ситуации/занятию: «в офис», «на выходные», «в отпуск», «на праздник» — покупательница видит себя. Когда: структура меню. (гл.7, с. 208) → shopify-collections

## Belch «Advertising and Promotion», ч. B (1)


### Магазин одежды

- **Кросс-продажа по базе.** Купила юбку → письмо с подходящим топом/кардиганом (как Amazon «с этим покупают»). (гл. 15, стр. 502) → скилл shopify-collections

## Bierut «How to Use Graphic Design to Sell Things» (3)


### Магазин одежды

- **Антидот к штампу — конкретика.** Перед дизайном коллекции выписать: чем особенна именно эта коллекция/модель (ткань, посадка, история), а не «женская мода вообще»; штампы (розовое, сердечки, «sale») — вычеркнуть. (стр. 101) → shopify-collections
- **Знак коллекции на общей сетке.** Логотипы/иконки коллекций строить на одной сетке с главным знаком (MIT: 7×7, 23 группы) — семья узнаётся целиком, а каждая коллекция своя. Совпадает с нашей двухслойной системой: оболочка + токены. (стр. 293–294) → shopify-collections
- **Две аудитории — два языка.** Если появятся две линейки (например, повседневная и «премиальная»), давать им разные графические языки, как Burger Palace и Gato. (стр. 275–278) → shopify-collections

## consumer_behavior_b (4)


### Магазин одежды

- **Коллекция у входа = деловое.** На главной первым блоком — универсальные вещи для работы (как Allegory у входа), модное глубже. (гл. 6, стр. 128) → shopify-collections
- **Подстроить фильтры под «пороги».** Покупательница отсекает по порогам (цена до $X, размер, цвет) — в коллекциях Shopify дать фильтры именно по цене, размеру, цвету, длине. (гл. 7, стр. 172–173, Exhibit 7.4) → shopify-collections
- **Меньше вариантов — больше продаж.** Не выкладывать 30 похожих юбок: 1 модель — 3–5 цветов, лишнее убрать (урок P&G). (гл. 7, Highlight 7.3) → shopify-collections
- **Акция рядом с маржинальным.** Как Kmart: акционный товар ставить в коллекцию/рекомендации рядом с высокомаржинальными вещами. (гл. 8, стр. 206) → shopify-collections

## consumer_behavior_d (3)


### Магазин одежды

- **«Больше за ту же цену».** Как Tyco против Lego: в наборе-допродаже больше вещей за ту же цену («юбка + аксессуар»). (стр. 463) → скилл shopify-collections
- **История к товару (метод American Girl).** К коллекции — короткая история/героиня, «как носить», аксессуары к образу: повышает готовность платить больше. (стр. 467) → скилл shopify-collections
- **«Собери образ» в карточке.** Блок «дополни образ» (юбка + блузка + сумка) — как продавец в бутике ведёт к комплекту; растит средний чек. (стр. 477) → скилл shopify-collections

## Cloud «E-Commerce Business: 3 in 1» (2)


### Магазин одежды

- **Допродажа «тихим продавцом».** Блок «с этим носят» и всплывающие предложения на карточке и в корзине (юбка → топ/ремень); наборы со скидкой — только как допродажа, не как основной товар; при настройке темы/приложений. (Кн.2 гл.12, гл.15) → скилл shopify-collections
- **Соседняя ниша тестом по 2–3 товара.** Добавлять из смежной категории то, что купит та же женщина (юбка → кардиган/блуза), по паре моделей, и смотреть статистику продаж до вложений в рекламу; при расширении каталога. (Кн.2 гл.14) → скилл shopify-collections

## Grewal «Marketing» 8e (США), ч. A (8)


### Магазин одежды

- **Коллекции по мотиву покупательницы, а не по типу вещи.** Как у Hertz (Adrenaline, Prestige, Green Traveler): «В офис без скуки», «Выходные за городом», «Ужин в ресторане» — у каждой своё сообщение и свой баннер. Зачем: женщина ищет решение для повода, а не «юбку». Когда: при пересборке коллекций. (гл. 2, стр. 41–42) → shopify-collections
- **Новая категория — из той же «ДНК».** Как Hermès брал 24 оттенка помады из архива тканей своих платков: при добавлении новой категории (шарфы, сумки, топы к юбкам) брать палитру и фактуры из уже продающихся моделей. Зачем: магазин выглядит одним брендом, вещи сочетаются между собой. Когда: при выборе новой категории. (гл. 1, стр. 15) → shopify-collections
- **Ядро каталога одно, добавки — по климату.** McDonald's держит основное меню одинаковым по всей стране, а по регионам добавляет местное (Юг — бисквиты с подливой, Гавайи — Spam, Новая Англия — роллы с лобстером). Для нас: основной каталог для всех США, а в рекламе разбить штаты на климатические группы (тёплый Юг: FL, TX, AZ, южная CA — лёгкие ткани зимой; холодный Север — шерсть, плотная клетка) и показывать каждой группе свою подборку — зачем: в январе во Флориде шерстяная юбка не продаётся — когда: при запуске рекламы Meta/Google и сезонных коллекций. (гл. 5, стр. 160; дополняет dop/grewal_b №31 про баннер по штату) → shopify-collections
- **Коллекции по «племени», а не по типу вещи.** Sun Basket расширился планами под «пищевые племена» (палео, кето, веган), через которые люди выражают образ себя. Для нас: кроме «юбки / блузки» — подборки по образу: «Dark Academia», «Quiet Luxury Office», «Preppy Weekend» — зачем: покупательница выбирает «кто я», а вещь — способ это показать — когда: когда наберётся 3+ моделей на образ. (гл. 6, стр. 187) → shopify-collections
- **«Хиты из-за границы» как капсула-тест.** McDonald's по просьбам американцев завёл «Flavors from Abroad»: сначала 4 позиции в 50 ресторанах Южной Флориды, потом шире; Kit Kat делает в Японии ~40 вкусов. У нас: модели, популярные в Корее/Японии/Китае, но ещё редкие в США, выпускать маленькой капсулой «Seoul edit / Tokyo edit» на тест, расширять только при продажах. Когда: при планировании коллекций (если вещь проходит радар). (гл. 8, стр. 265–266) → shopify-collections
- **Один неизменный фирменный элемент в любой коллекции.** KFC меняет меню в каждой стране, но в каждой новинке обязательно «11 трав и специй». У нас: один постоянный признак во всех коллекциях и сценах (например, тон фона, фирменная бирка, одна поза/кадр), чтобы при разных стилях магазин узнавался. Когда: при заведении новой коллекции или серии сцен. (гл. 8, стр. 273) → shopify-collections
- **Эксклюзив «только здесь» с покупкой нескольких штук.** Bacardi продавал лимитированный скотч за $400 только в аэропортах, люди брали по 3 бутылки. У нас: модель или цвет, которого нет на Amazon/Shein, с пометкой «only at our store» и скидкой на вторую штуку другого цвета. Когда: при запуске удачной модели. (гл. 8, стр. 268) → shopify-collections
- **Три типа покупательниц на оси «деньги ↔ время» (по Walmart).** Для каждого типа — свой вход на сайте и своё письмо: «охотница за выгодой» — блок «лучшая цена / набор со скидкой»; «занятая» — быстрый подбор «образ за 2 клика», готовые сочетания; «премиум за удобство» — точная размерная сетка, быстрый обмен, без лишних шагов в оформлении — зачем: одна и та же юбка продаётся разным людям за разное — когда: при проектировании главной и сегментов в Shopify Email. (гл. 9, стр. 289–290) → shopify-collections

## Grewal «Marketing» 8e (США), ч. B (4)


### Магазин одежды

- **Старую модель — дешевле, а не в архив.** Прошлогодний бестселлер оставлять в каталоге по сниженной цене для более экономных покупательниц (как Apple со старыми айфонами). (гл. 12, стр. 452) → shopify-collections
- **Одна «витринная» вещь на коллекцию.** Добавить в коллекцию 1 заметно более дорогую модель (лучше ткань/отделка) — она поднимает восприятие остальных, даже если её мало покупают (Paradigm). (гл. 14, стр. 498) → shopify-collections
- **Дешёвая линия — под другим именем.** Если появится очень дешёвый ассортимент, продавать его отдельной суб-маркой, чтобы не «размыть» основной магазин (Fender → Squier). (гл. 14, стр. 501; дополняет dop) → shopify-collections
- **Своя марка магазина.** Хиты с 1688 продавать под своей маркой и общим слоганом (Target: Cat & Jack, A New Day, «More in Store»), с 360°-фото; молодые меньше держатся за бренды — своя марка работает, если вещь хорошая. (гл. 17, стр. 589) → shopify-collections

## «How To Successfully Market High-Priced Products» (4)


### Магазин одежды

- **Поднимать средний чек «системой», а не ценой вещи.** Юбка + подходящий топ/пояс + гид по образам «5 способов носить» как единый «образ» с собственным названием. Зачем — один заказ даёт больше маржи на ту же рекламу. Когда — при оформлении карточки и допродаже (наборы для допродажи — можно). (гл. 2, стр. 17; гл. 7, стр. 50) → скилл shopify-collections
- **Название набора как продукта.** Не «товар 1 + товар 2», а «Капсула Autumn Plaid: 3 образа на неделю». Зачем — оформленная «коллекция» воспринимается дороже набора отдельных вещей. Когда — при создании наборов/сетов. (гл. 7, стр. 49–50) → скилл shopify-collections
- **Раздел «Идеи для подарка».** Подборки «подарок маме / подруге / себе» с готовыми ссылками. Зачем — покупатели «удобства/роскоши» часто покупают подарки. Когда — перед праздниками (Q4, День матери). (гл. 5, стр. 36) → скилл shopify-collections
- **Не смешивать премиум-линию с распродажей.** Дорогие «изюминки» — в отдельной коллекции, без соседства с дешёвыми; скидки — в отдельном разделе. Зачем — «не удешевлять бренд». Когда — при раскладке коллекций. (гл. 26, стр. 179–180) → скилл shopify-collections

## Hill «International Business», ч. B (3)


### Магазин одежды

- **Премиальный «проверенный» уровень, как Airbnb Plus.** Выделить коллекцию «проверено лично»: модели, которые заказали и проверили образец (фото живьём, замеры) — для женщин 28+, которые боятся покупать одежду из Китая вслепую — когда будут образцы. (гл. 18, с. 535) → скилл shopify-collections
- **Фирменный знак — дозированно.** Если появится свой узнаваемый принт/деталь, ставить его на ограниченную часть ассортимента (Burberry оставила клетку на 10% товаров), чтобы не «дешевить» знак. (гл. 18, с. 552) → скилл shopify-collections
- **Продавать «опыт», а не вещь.** Как Starbucks продаёт «третье место», карточка и коллекция должны продавать образ/ситуацию (в чём пойти, какое ощущение), а не «юбку из полиэстера». (кейс Starbucks, стр. 646) → скилл shopify-collections

## «Home-Based Business University» (1)


### Магазин одежды

- **Силос для коллекций.** Строить меню магазина деревом: главная → разделы (юбки, платья…) → подколлекции по стилю/поводу, и со страницы раздела ссылаться на подколлекции — сила ссылок с главной расходится вниз, покупательница быстрее находит нужное. (Affiliate, ч. 36, 39) → shopify-collections

## Flowers «The Naming Book» (6)


### Магазин одежды

- **Твёрдая первая согласная.** При прочих равных выбирать название магазина/коллекции, которое начинается на t, k, p, d, g, v (или C/K-звук) — запоминается лучше. (часть 8, Memorability) → shopify-collections
- **Штурм «мы + глагол + объект».** 5 фраз о магазине с разными глаголами («мы подбираем юбки на сезон», «мы находим вещи с изюминкой», «мы доставляем из мастерских»), по каждому глаголу и объекту — 15–20 свободных ассоциаций. Сырьё для имени магазина и коллекций. (часть 9) → shopify-collections
- **3 метафоры и 3 сравнения о магазине.** «Мы — как подруга со вкусом», «как гардероб, где всё сочетается», «как утренний рынок в Провансе» → 5–10 предметных слов на каждую → сырьё для имён капсул. (часть 9, Make it abstract) → shopify-collections
- **Имена коллекций по 7 типам.** Для каждой капсулы (например, «юбки в клетку осень») генерировать варианты всех типов: настоящее слово, иностранное, составное, фраза, сращение, выдуманное, место/человек — и только потом выбирать. (часть 10) → shopify-collections
- **Места как имена коллекций.** Называть капсулы по местам с нужной ассоциацией (Patagonia, California Pizza Kitchen): «Highlands» для клетки/тартана, «Amalfi» для летнего льна, «Kyoto» для japandi-минимализма. (часть 10, People and Place Names) → shopify-collections

## Lindsay «Sewing to Sell» (7)


### Магазин одежды

- **Один покупатель на витрине.** На главной и в коллекциях показывать только вещи для женщины 28+, не смешивать с чужими категориями (детское, мужское, «на всякий случай») — смешение отталкивает обе группы. Проверять при каждом добавлении товара. (стр. 13) → shopify-collections
- **Линейка вокруг хита.** Когда одна модель (например, юбка) продаётся лучше других — добавлять к ней 2–4 вещи той же темы (другой цвет, длина, верх в пару), а не новую категорию. После первых продаж. (стр. 15) → shopify-collections
- **Категории и теги — тщательно.** Ставить точную категорию Shopify и теги, по которым её найдут (стиль, длина, ткань, сезон) — это фильтры и SEO. При заведении товара. (стр. 45) → shopify-collections
- **Набор «используют вместе» — для допродажи.** Предлагать рядом вещи, которые носят вместе (юбка + подходящий топ/ремень) со скидкой за пару; в поиске товаров наборы не берём, а для допродажи можно. При настройке upsell. (стр. 79, 95, 142) → shopify-collections
- **Лестница цен внутри темы.** В коллекции держать вещи нескольких ценовых ступеней (аксессуар-дешёвый вход → основная юбка → «звёздная» дорогая вещь, привлекающая внимание), но всё в одном стиле. При сборке коллекций. (стр. 50, 145) → shopify-collections
- **«Звезда» коллекции для внимания.** Одна яркая дорогая вещь в первом ряду коллекции/на баннере привлекает, а продают средние — не убирать её из-за редких продаж. (стр. 50) → shopify-collections
- **Мини-коллекция для теста.** Новую тему (например, клетка осени) заводить 3–5 моделями как мини-коллекцию, смотреть продажи, масштабировать только продавшееся. При каждом новом направлении. (стр. 33, 146) → shopify-collections

## Dahlström «Storytelling in Design» (4)


### Магазин одежды
