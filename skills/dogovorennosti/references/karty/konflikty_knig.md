# Реестр конфликтов между книгами (ПРЕДЛОЖЕНИЕ, ждёт «да/поправь» от Виты, 19.10.2026)
Источники конфликтов: weiss\02_priyomy, klaff\02_priyomy, mom_test\02_priyomy, voss\02_priyomy (поля conflicts). Всё — ИИ-гипотеза до проверки по текстам книг.

Общий принцип предложения: книги не спорят, если разложить по ФАЗАМ разговора.
- Фаза 1 «узнать правду / проверить идею» — Mom Test.
- Фаза 2 «питч, первая встреча» — Klaff (только устная часть, без давления).
- Фаза 3 «ценность и предложение» — Weiss (ценность до цены, варианты условий).
- Фаза 4 «торг, эмоции, возражения, конфликт» — Voss.
- Всегда сверху: правило Виты — условия письменно ДО работы; «правда + реальный выбор»; блеф/ложный дефицит/давление запрещены.
