# Дорогой объёмный сайт — рецепты (палитра и шрифт НАШИ из site/DESIGN.md: беж, синий, бордо, Vela Sans)
Перед правкой: прочесть site/DESIGN.md и site/UX.md; новые значения — токенами в :root, не россыпью по файлу. Показать ей «до/после» скрином, дизайн — только с её «да».
Её правило 10.10: движение на сайте — ТОЛЬКО слайдеры. Рецепты ниже статичные (тени, слои, шрифт); анимации из apple-design/emil-design-eng без её слова не добавлять.

## Почему сейчас плоско (проверено по styles.css 27.10): тени почти нет (28 box-shadow, почти все — линии и рамки), стекла 5 мест, заголовки без balance, ступеней «высоты» нет.

## 1. Система высоты (4 ступени) — одна на весь сайт
Тень — всегда из 2–3 слоёв: близкая резкая + далёкая мягкая, цвет тени — оттенок фона (тёмно-синий), не серый/чёрный; смещение вниз, не halo.
```css
:root{
  --sh-1: 0 1px 2px rgb(34 41 71/.08), 0 4px 12px rgb(34 41 71/.06);                    /* плашка */
  --sh-2: 0 2px 4px rgb(34 41 71/.08), 0 12px 28px rgb(34 41 71/.10);                   /* карточка */
  --sh-3: 0 4px 8px rgb(34 41 71/.10), 0 24px 56px rgb(34 41 71/.16);                   /* выдвинутая / наведение */
  --edge: inset 0 1px 0 rgb(255 255 255/.55);                                           /* свет на верхней кромке */
}
```
Правило: чем больше или важнее блок — тем выше ступень. Не ставить всем одну и ту же тень. Запрещено: жёсткая тень без размытия (4px 4px 0), цветное свечение, цветная полоска слева >1px.

## 2. Слои и материал
- Карточка = фон чуть светлее страницы (не белый) + тонкая рамка 1px (--sand темнее) + --edge + --sh-2. При наведении (только ПК): --sh-3 и подъём 2px — если она разрешит движение.
- Шапка и плашки поверх фото: `backdrop-filter: blur(16px) saturate(160%)` + полупрозрачный фон + верхняя светлая кромка. Не класть светлое стекло на светлое стекло. Вместо линии под шапкой — мягкий градиент-переход (у нас есть .top.scrolled).
- Тёмные блоки (--deep): мягкий радиальный блик сверху (rgba света .08) и внутренняя кромка — получается «шёлк», а не плоская заливка.
- Фото: скругление и тень --sh-2; крупные фото — лёгкая внутренняя виньетка. Фото не «наклеены» на фон, а лежат на нём.
- Разделители секций — чередование фона (paper → sand → deep), а не линии.

## 3. Красивые тексты
- Заголовки: `text-wrap: balance`; основной текст: `text-wrap: pretty`. Строка 45–75 знаков (max-width в ch). Межстрочный: заголовок 1.05–1.15, текст 1.5–1.65 (на тёмном фоне чуть больше и вес на ступень тяжелее).
- Иерархия работает размером + весом + цветом + воздухом вместе. Между роль-ступенями разница не меньше ×1.25. Не выделять одно слово в заголовке цветом/курсивом, не писать подписи капсом, не лепить подпись над каждым заголовком — это выдаёт нейросеть.
- Цифры: `font-variant-numeric: tabular-nums` в таблицах и счётчиках. Неразрывные пробелы уже делает typograf() в build.py.
- Абзац: либо отступ между абзацами, либо красная строка — не оба. Цитаты и «вводные» — крупнее, с большим воздухом, без рамок.
- Тексты на сайте (содержание): конкретика вместо общих слов, короткие предложения; прогонять через скиллы ru-editor и slopotron.

## 4. Слаженность (ритм)
- Шаг отступов — ряд из :root (8·16·24·40·64·96), никаких «случайных» 37px. Радиус — 2–3 значения на роль (кнопка, карточка, фото), не один на всё.
- Одна «звезда» на экран: один крупный элемент (первый экран, один большой номер/фото), остальное тише. Сетка и выравнивание по левому краю, без центра везде.
- Состояния: наведение, нажатие (scale .98), фокус (виден), отключено — у каждой кнопки и карточки.
- Иконки — линейные SVG одного стиля и толщины; эмодзи как иконки не использовать.

## 5. Как работать
1) Снять скрин «до» (ПК 1440 и телефон 390). 2) Завести токены --sh-*, --edge, радиусы в :root. 3) Пройти по группам: шапка → первый экран → карточки «Я — …» → фото-полосы → форма → подвал. 4) После каждой группы: python site/build.py, check_gaps.py, qa_site.py, скрин «после». 5) Показать ей до/после; принимает — дальше, нет — откат (git).
Проверка «дороговизны»: сузить глаза — видно ли 3 уровня высоты и один главный элемент? Читается ли заголовок на 2 строки ровно? Нет ли одинаковых теней у всего?
