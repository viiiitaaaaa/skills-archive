## Grewal «Marketing», гл. 9–13 (1)


### Frivent / B2B

- **Комиссия агенту — только договором.** Сценарий 2: взятки проводили как «комиссии» и «спецскидки». Агентское вознаграждение платить по договору, на юрлицо или ИП агента, с актом за услугу. Проверять, что агент не сотрудник или закупщик заказчика: иначе это откат. (прил. 1) → b2b-sbor, dela

## Dickey «Mastering Claude AI» (6)


### Новости, данные, Claude Code

- **Разбор большого документа в 4 прохода.** Сначала задать фокус, приоритет и цель («для иска», «для выбора поставщика»). Потом четыре прохода: общий разбор → углубиться в то, что зацепило → конкретные вопросы по узнанному → практические выводы. Для решений суда, договоров, длинных отчётов. (гл. 11, стр. 196–197) → dela, knowledge-library
- **Шаблоны запросов с заглушками для дел (дополняет dop №41).** Пункт книги «сделать шаблоны запросов без персональных данных». Заранее подготовить шаблоны, где вместо данных стоят метки [ИСТЕЦ], [ОТВЕТЧИК], [АДРЕС], [СУММА], [ДАТА]. Реальные значения подставлять только в итоговый документ на ПК. По книге «обычно безопасно» передавать публичные сведения, общие сценарии и выдуманные примеры. (гл. 17, стр. 288, 294) → dela
- **Возражения другой стороны (дополняет №4 первого конспекта).** Из списка допустимых учебных запросов («найди дыры в моей аргументации») сделать запрос для дел: «какие 5 возражений вероятнее всего напишет ответчик, и что у меня есть на каждое?». (гл. 14, стр. 241) → dela
- **Указывать дату в вопросах о правилах (дополняет dop №38).** Писать явно: «нужна актуальная информация на октябрь 2026», «изменения за 2025–2026». Тогда модель ищет свежее или честно говорит о сроке своих знаний. (гл. 3, стр. 31, 35) → dropship-lessons, dela
- **Когда модель не знает свежих правил — три шага вместо отказа.** Пример книги: «санитарные требования в Портленде». Шаг 1: «до какой даты твои знания по этой теме и что здесь часто меняется?». Шаг 2: «составь общий чек-лист по типичным требованиям, конкретику я сверю сама». Шаг 3: «какие официальные источники смотреть и **какими поисковыми словами** их найти; какие детали обязательно проверить по месту». У нас: пошлины и правила ввоза в США для одежды, требования Shopify Payments, процессуальные нормы для дел (точные названия статей и формулировки для поиска в КонсультантПлюс или на сайте суда). Зачем: вместо выдуманной нормы получаем список того, что проверить, и готовые слова для поиска. (гл. 16, стр. 275) → dela, dropship-lessons
- **Запас времени в важных процессах + «кажется сложным — значит, сложно».** Из принципов построения процесса: (а) в процессах со сроком (подача в суд, ответ поставщику, сбор перед решением) закладывать запас на случай, когда Claude или API тормозит или упирается в лимит, и держать ручной путь; (б) процесс начинать с 3–5 шагов, а если схема «кажется сложной, то она и есть сложная», и её надо резать. Зачем: срок не должен зависеть от того, работает ли сегодня сервис. (гл. 12, стр. 207) → claude-code-priemy, dela
