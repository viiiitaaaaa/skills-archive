# Вакансии (США) и резюме

## Её условия — не переспрашивать

- **Преимущественно США.** Вакансии, которые можно вести из России, ставим в самый конец списка
  или не рассматриваем. Жёсткие стопы называть прямо: требование жить в штате, а у SpaceX
  и подобных подрядчиков — **ITAR** (нужно гражданство или постоянный вид на жительство США).
- **От 75 000 $ в год.** Ниже не показываем.
- **Английский A2 (pre-intermediate).** Не завышать нигде. В сверке английский стоит в столбце
  «не совпадает» у каждой вакансии: почти везде нужны переписка и созвоны. Подходят роли, где
  работа письменная и асинхронная.
- **LinkedIn под её аккаунтом не парсить** — аккаунт уже ограничивали за автосбор. Только
  открытые API и чтение глазами.
- **В резюме ничего не выдумывать:** ни лет, ни инструментов, ни сумм заработка. Усиливать можно
  только подачей — порядок блоков, формулировки, язык вакансий. Счётчиков про ИИ («N агентов»)
  не писать.

## Сбор: `scripts/sbor_vakansiy.py`

Девять источников, все открытые, ключи не нужны:
Himalayas, Remotive (общий список **и поиск по словам** — выдача каждый раз другая),
RemoteOK, Jobicy (в том числе `geo=usa`), Arbeitnow (8 страниц), Working Nomads,
The Muse (только нужные разделы). Итог — `vakansii_sbor_<дата>.json`.

Запуск: `cd C:\Users\User\knigi_kupleno && python -I sbor_vakansiy.py`

**Грабли, на которые уже наступили:**

- **Зарплату из текста брать осторожно.** Первая версия выдала «960 000 $ в год» у менеджера
  поддержки — это была выручка компании. Поэтому сумма принимается только если рядом (±120 знаков)
  стоят слова про оплату (salary, compensation, per year, OTE…), и отбрасывается, если рядом
  ARR, revenue, funding, GMV, budget, quota. Диапазон 40–400 тыс. $.
- **Валюты вне USD/EUR/GBP/CAD/AUD/CHF игнорируем** — поля API врут (филиппинские песо
  превращались в сотни тысяч долларов).
- **Himalayas отдаёт около 200 свежих вакансий**, запрос по разделам (`&category=`) новых
  почти не приносит — возвращает те же. У половины зарплаты нет вовсе.
- **The Muse — 20 000 страниц**, в основном медицина, склады и производство. Для него проверяем
  совпадение **только по названию** вакансии (не по разделу) и держим длинный список запретных
  слов, иначе приходят медсёстры и «пошив космических костюмов» в SpaceX.
- **Jobicy отвечает 400** на часть разделов — это нормально, скрипт идёт дальше.
- Поле `salary_sure` = `false` значит «сумма вытащена из текста, проверить при отклике».

## Сверка: `scripts/build_sravnenie.py` + `sravnenie_dannye.json`

`sravnenie_dannye.json` — разбор руками (это не автоматизируется): по каждой вакансии три списка
`match` / `partial` / `gap` и строка `vyvod`. Процент = совпадения плюс половина частичных.
Правь текстом, страница пересобирается командой:

`cd C:\Users\User\knigi_kupleno && python -I build_sravnenie.py`

Страница группирует вакансии: **США → другие страны → можно из России**, открывается сразу
на американских. Сопоставление разбора с данными сбора идёт **по компании и по названию** —
у Walmart и NetBox Labs по две вакансии, иначе они склеиваются.

Как писать столбцы, чтобы это помогало решать:

- В `gap` отдельной строкой — то, что закрывает дорогу совсем (страна, ITAR, диплом, английский).
- Различать «слово совпало» и «работа совпала»: вакансии со словом «сорсинг» у ИТ-компаний —
  это корпоративные закупки лицензий и договорное право, а не Китай; «RevOps» у Roboflow —
  это разработчик Salesforce.
- В `vyvod` — одна фраза, что делать: «брать первой», «нужен год практики в Google Ads», «нет».

## Резюме

Файл `rezyume_pro.html` (русский + английский кнопкой). Правила, по которым оно собрано, —
из разбора 18 живых и образцовых резюме (`knigi_kupleno\primery_rezyume_linkedin.md`):

1. Заголовок = роль + область + метод через «|».
2. Достижения первым блоком, формула «с A до B за срок + способ». Цифра без способа выглядит
   выдуманной.
3. Пара метрик: что выросло и что подешевело. Маржа и прибыль сильнее оборота.
4. Автоматизацию мерить снятыми часами и отсутствием ошибок, а не числом агентов.
5. Закупку в Китае подавать как систему проверки (фабрика или перекупщик, повторные закупки,
   минимальная партия), а не «знаю поставщиков». Китайский ставить рядом — это преимущество.
6. Для 4 лет опыта работодатели ждут «старшего»: показывать переход от исполнителя
   к ответственному за результат.
7. Перед отправкой в конкретную вакансию менять только первую строку и порядок достижений.

**Что наверх под какую роль:** закупка и цепочка поставок — для Walmart, Sunrun, Cox, SpaceX;
автоматизация и Claude Code — для Zuora, Karbon, Mozilla; реклама и юнит-экономика — для
Herewith, Boldin, Wpromote.
