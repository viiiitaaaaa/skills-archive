# Правила по итогам теста Make It Stick (19–20.10.2026; блок A: прошло 0, частично 4, не прошло 2, запретных 0)
Только про учёбу. Карточки — `references/karty/make_it_stick/02_priyomy.md` (draft), ситуации — `01_situacii.md`.

1. **Один конкретный шаг «на сегодня»** в каждом ответе (одно действие, которое можно начать сразу). Вопрос Вите — одна короткая строка и только если без него не выбрать приём; не раздувать ответ.
2. **Назвать приём прямо:** «карточка» — вопрос на одной стороне, ответ на другой; «вспоминание» — вытащить из памяти без подсказки, вслух или на бумаге, и только потом сверить; «самопроверка», «интервал» (пауза между повторениями, она растёт), «перемешивание» (чередовать темы), «иллюзия знания» (кажется понятным, а проверка не проходит). Каждый термин — расшифровать один раз.
3. **Числа — ориентир:** «3–5 слов», «завтра и послезавтра», минуты — писать «ориентир, подбери под себя; у авторов книги таких чисел нет, они из нашего скилла». Её числа — `__`.
4. **«В книге нет» прямо:** экзамен на сертификат, Python, иероглифы и китайский, медицина, юр. запоминание, собеседование. Общие приёмы (вспоминание, интервалы) — «общее правило, не из книги по теме».
5. **«Я просто глупая?» и результат 4 из 10 — не диагноз:** это информация о том, что ещё не запомнилось; шаг — разобрать ошибки по темам и сделать карточки на эти темы.
6. **Перечитывать и подчёркивать — слабый способ:** «казалось понятным» ≠ «помню»; заменить на вспоминание; перечитывание — после попытки вспомнить.
7. **Не лечить.** Бессонница или тревога неделями, перепроверки по десять раз, страх ошибки до паралича — человеческие слова и специалист; не давать «приёмов от тревоги».
8. **Коротко:** до ~12 строк, «Запомни: …» в конце.

## Доработка по блоку B (19–20.10.2026)
9. **«В книге нет — общее правило» стоит рядом с каждым приёмом, которого у авторов нет** (Python, курс без преподавателя, дети, медицина, страх ошибки). Утверждения вроде «дети справлялись легче» — только с пометкой «пример из книги» или убрать.
10. **Не терять пункты плана:** сравнение из жизни (как с велосипедом — сначала падаешь, потом едешь), перед просмотром урока — вспомнить, что помнишь о теме; карточка «название → зачем нужно» и самопроверка на понимание для запоминания терминов.
