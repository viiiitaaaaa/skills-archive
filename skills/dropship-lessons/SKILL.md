## ВСЕГДА: кому можно отдавать данные, а кому нельзя (её правило 29.09: «предупреждать всегда»)

Перед тем как отправить что-то во внешний сервис, ИИ-модель, бот, чат, форму или «помощника» — **сказать ей одной
строкой, в какую корзину это попадает** (vibecoding_community/225811):

| Корзина | Что это | Куда можно |
|---|---|---|
| 🟢 Можно облаку | Тексты товаров, фото товаров, публичные ссылки, тренды, новости | Claude, официальные сервисы с её аккаунтом |
| 🟡 Только на компьютере | Ключи API и токены (`.env`, переменные окружения), пароли, данные аккаунтов, документы дел, паспорта, реквизиты | Никуда не отправлять; скрипты читают сами, модель значения не видит |
| 🔴 Никому | Ключи/пароли в чужие сервисы-посредники («роутеры», перекупленные токены, FunPay), чужие ИИ-клиенты, публичные туннели | Не делать вообще |

- Сервисы-посредники (роутеры моделей, дешёвые «токены») могут читать и продавать содержимое сессий — не пользоваться.
- **Агентам в авто-режиме не давать боевые ключи и доступ к серверам/магазину напрямую** — только через скрипты с
  ограничениями (случай: агент сам записал облачные ключи и по своей выдуманной «команде» зашёл по SSH на боевой
  сервер — vibecoding_community/232171).
- Нужна своя система (CRM, учёт) — брать готовую базу и настраивать, а не писать с нуля (vibecoding_community/231493);
  для поставщиков нам пока хватает таблицы.
- **Малоизвестные ИИ-клиенты не запускать в папках с ключами (.env) и документами дел** — десктопный ZCode (Zhipu)
  перед запросом упаковывал всю рабочую папку с историей git и отправлял в облако (vibecoding_tg/3968).
- **Наши инструменты — монолит, не микросервисы**: маленькие скрипты проще держать одним куском; микросервисы, по оценке
  автора, в 3,75–6 раз дороже по инфраструктуре (python_tg/4011).
- **Длинные сессии Claude дорожают сами** — почти вся стоимость в повторно читаемом кэше (vibecoding_community/224602).
  Перед большой задачей (новости, радар, 1688) в уже длинной сессии — заранее сказать ей перезапустить сессию
  (её просьба 29.09).
- **Бесплатные «роутеры» моделей — не пользоваться** (Free Router, 25 бесплатных провайдеров, «миллиард токенов» —
  PushEnter/13670): это тот же сервис-посредник из 🔴, текст задачи уходит неизвестно кому. То же — Free Claude Code
  (python2day/8121, пост 377): не ставить.
- **Одноразовая почта — для сервисов-пробников** (PushEnter/13621, пост 390, 30.08): регистрироваться в незнакомых
  сервисах и пробных доступах на временный ящик, чтобы не светить основную почту. Для Shopify, банка, посредников
  (BuckyDrop/HyperSKU), Claude, Google, рекламных кабинетов — **никогда**: туда нужен её постоянный ящик для
  восстановления доступа. Ссылка на сервис — в посте https://t.me/PushEnter/13621.
  **Поправка по первоисточнику (07.10):** ссылка из поста — mailmeteor.com/tools/email-generator — это НЕ одноразовый
  ящик: он только придумывает 20–30 вариантов имени адреса по образцу, а ящик всё равно надо регистрировать самой.
  Для временной почты нужен настоящий сервис временных ящиков (их выбирает она); пост канал описал неверно.
- **Аккаунт Claude — не рисковать** (PushEnter/13781, пост 819): входить с одного адреса, не менять сервер Happ во время
  работы, всё важное — в GitHub. Подробно — скилл `claude-code-priemy`, раздел «ВСЕГДА».
- **Фото и видео, сделанные ИИ, несут скрытую метку** (Anthropic проверяет файлы на следы Claude; C2PA/EXIF —
  PushEnter/13640). В рекламе Meta такие креативы честно помечаем «сделано ИИ»; метки и метаданные **не стираем**
  утилитами «удаления водяных знаков» — если Meta это найдёт, рискуем рекламным аккаунтом.

## ВСЕГДА: как тратить лимит Claude (её отметки 29.09)

- **Уровень усилий по задаче.** Fable 5.1 и Opus 5.5: в Claude Code по умолчанию High. Простое (карточку в очередь,
  разложить входящие, пересобрать панель) — можно ниже; трудное (отбор 1688, иски, радар) — `/effort high`. Max у
  Fable 5.1 дал +46% к цене и +0,5% к результату — **max по умолчанию не держать** (vibecoding_tg/3786, 3829).
- **Чистить старые инструкции при смене модели.** «Отвечай максимально подробно» заставляло делать десятки лишних
  поисков; после чистки −14,6% к цене, +5,3% к точности (vibecoding_tg/3829). Официальные гайды: Anthropic — промпты
  для Fable 5.1 (PushEnter/13633); OpenAI — готовый запрос «проверь скиллы на лишнюю работу, конфликты инструкций и
  ненужные ожидания, предложи минимальные изменения» (PushEnter/13691). Это пункт №1 списка «Когда будет время».
- **Большие файлы читает дешёвый помощник.** Схема Spotify: главная модель думает, а огромные выгрузки (1688, логи,
  дампы постов) читает субагент на лёгкой модели (Haiku/Sonnet) и возвращает выжимку; шаблонный код он же пишет сразу
  в файл (vibecoding_tg/3819). Применять в sourcing-1688, tg-news, disk-hygiene, когда файл больше нескольких тысяч строк.
- **Скилл должен работать каждый раз, а не «повезло».** pass@k — получится хоть раз из k попыток; pass^k — получится
  каждый раз подряд. Нам нужен pass^k. Для главных скиллов держать 2–3 коротких проверочных примера «запрос → каким
  должен быть итог»; мультиагентность без нужды не добавлять — чаще ломается на координации (курсы Stanford CS329Z
  — LLMScience/1083; CMU 11-768 — LLMScience/1098; граф-курс Google — PushEnter/13694). Проверка: `claude plugin eval`
  (vibecoding_tg/3843) — пункт «Когда будет время».

## Экономика товара и теста

**Потолок цены покупателя (CAC — сколько можно отдать рекламе за одну покупку).**
Цена − себестоимость − доставка − комиссии = сколько остаётся до рекламы. Пример: $39.99 − $12 − $6 − $2 ≈ $20.
Покупатель за $10–15 — интересно; $18–20 — работа в ноль; $25+ — дорабатывать оффер или рекламу.
Считать потолок ЗАРАНЕЕ, до запуска рекламы, для каждого товара (shopify_offstudzent/948).

**Бюджет на тест товара — $150–300, не $20–30.** Например, 5 креативов × $30–50. На 10–20 кликах выводов не делать.
Цель теста — понять потенциал связки «товар + креатив + оффер», а не сразу заработать (shopify_offstudzent/948).

**Когда остановить тест раньше и что менять.** Слабый CTR (доля кликов по объявлению), дорогие клики,
заходят, но не добавляют в корзину, или есть checkout без покупок → менять креатив, оффер, цену или страницу товара,
а не доливать деньги. Пошли продажи и экономика близка к нужной → поднимать бюджет постепенно (shopify_offstudzent/948).

**ROAS врёт.** ROAS = выручка ÷ реклама; $100 рекламы → $300 выручки = ROAS 3.0, но это не прибыль.
Товар $50: себестоимость + доставка $22, комиссии $3, реклама $20 → остаётся $5. Считать каждый заказ:
выручка − товар − доставка − комиссии − возвраты/чарджбэки − скидки − реклама (shopify_offstudzent/946).

**Формула старта с $500 (оценка ниши).** Товар $75 − себестоимость с доставкой $17 − эквайринг $3 = $55 с продажи;
$1000 в месяц = 19 продаж. Ориентир органики: 1 млн просмотров ≈ $3000 продаж, то есть ~20 тыс. просмотров на продажу.
Расходы первого месяца: телефон под ролики $100–150, нейросеть $35, Shopify $39 (первый месяц $1), домен $10,
20 роликов по $5 (tkachevshopify/2881).

**Реальные ориентиры по дню и заказу (отметки 29.09).**
- День магазина в США только на Google Ads: выручка $4461, реклама $989, ROAS 4,51 → прибыль $1700 без возвратов,
  35% с продаж (akuliabuhta/1132). То есть при марже до рекламы ~60% и ROAS 4,5 чистыми остаётся около трети.
- Заказ на 13 вещей (платья, туфли, блейзеры): маржа ~$500, **66% до рекламы** с учётом эквайринга — их норма
  (akuliabuhta/1129).
- **Средний чек fashion в США — $75–120:** у автора $75–79 (Великобритания чуть меньше), сейчас >$80; у знакомого
  на платьях $110–120 (akuliabuhta/1114, 1120). Закупка на 1688 за 25–65 ¥ ($3,5–9) даёт большой запас наценки —
  считать потолок цены по формуле выше, а не ставить «дёшево».
- **Запас маржи 65–70% до рекламы бывает только на своём сайте (D2C** — продажа напрямую покупателю); на WB и Amazon
  это нереально (akuliabuhta/1082, пост 233, 22.08). Свои вещи на сайте можно продавать в разы дороже маркетплейса —
  если есть апселл, кросс-селл и дожим письмами (akuliabuhta/1069, пост 207, 21.08).
- **Масштаб съедает маржу, это нормально:** USA-магазин одежды шёл к $5000/день с чистой маржой ~25% (на старте ~30–35%)
  (akuliabuhta/1074, пост 212); ROAS 2,8 при $1500/день; $1000 рекламы → ждут >$2500 выручки (ROAS ~2,5); $1750/день →
  ждут >$5000 (akuliabuhta/1071, 1078, 1108 — посты 208, 219, 396, 21–30.08).
- **Конверсия: норма нового магазина ~1–2%, 3,5% — очень хорошо** (ученик: $1147 за день, 5 заказов, чек ~$230 —
  proecomdmitriy/1150, пост 329, 26.08). К Black Friday готовиться с августа–сентября: магазин собран, реклама проверена.
- **Скидочное давление в США растёт:** власти вернули ритейлу ~$100 млрд пошлин (Target $994 млн, Walmart ~$2,9 млрд),
  деньги уйдут в снижение цен и промо (world_ecom/993, пост 385, 30.08). В юнит-экономике держать запас на скидки;
  у посредника (BuckyDrop/HyperSKU) уточнить, как сейчас считается пошлина на посылки из Китая.
- **Главный конкурент в одежде США — Amazon:** 17% расходов на одежду, $109 млрд в 2025, втрое больше Walmart,

  разрыв максимальный в Q4 ($23,9 млрд) — в сезон одежду ищут на Amazon ещё сильнее, наш козырь в Q4 — сеты-подарки
  и своя база, а не цена. Онлайн в США растёт вдвое быстрее розницы (+12,2% против +6,7%, II кв. 2026). Walmart
  отвечает «более дорогим» ассортиментом (бренды Scoop, Free Assembly — рост в сотни процентов) — нишу «стильно,
  но недорого» занимают и крупные.
- **Пошлины могут вернуть.** Walmart во II кв. получил ~$2,9 млрд возвратов таможенных пошлин (Retail Dive, прочитан
  07.10) — после отмены части тарифов импортёры подают на возврат. У посредника спросить: кто импортёр в США по нашим
  посылкам и положен ли нам возврат уже уплаченных пошлин.

## Перед тем как поднять бюджет (чек-лист, proecomdmitriy/1145, пост 235, 22.08)

Хороший день — не повод сразу ×10. Сначала ответить:
1. Какой именно товар дал продажи?
2. Сколько стоил покупатель (CAC) — ниже ли он «потолка» из юнит-экономики?
3. Какая конверсия (норма 1–2%)?
4. Повторяется ли результат 3–5 дней подряд?
5. Что докрутить (креатив, оффер, страница)?
Только потом поднимать — шагами (у akuliabuhta: $1000 → $1500 → $1750 в день при стабильном ROAS; рекомендации Google
«поднимите бюджет» выполнять, только когда ROAS держится — akuliabuhta/1071).
Отдельно смотреть в Shopify **долю возвращающихся покупателей (returning customer rate)**: 16,7% у ученика — хороший
сигнал, магазин живёт не только рекламой.

**Время в США:** основные продажи — вечером по американскому времени, то есть ночью по Москве (akuliabuhta/1108,
пост 396). Бюджеты и расписание объявлений ставить по времени США; автоответы поддержки с трек-номером — круглосуточно.

## Безубыточный ROAS, маржа 65%, реальный ROAS (отметки 07.10)

Скрипт: `python C:\Users\User\.claude\skills\dropship-lessons\roas_calc.py ber --price 65 --cost 9 --ship 7.5`
(товар) и `... roas_calc.py real [--shopify]` (по дням из `C:\Users\User\store3\real_roas.csv`). Данные 🟡 только ПК.
- **BER (Break Even ROAS)** = цена ÷ (цена − товар − доставка − эквайринг). При таком ROAS заказ в ноль; у автора
  1,4–1,7 (akuliabuhta/1065, пост 185, 19.08). Поэтому у них даже ROAS 1,7 «тяжело уйти в минус» (akuliabuhta/1063,
  пост 179) — только при очень высокой наценке. Считать BER для КАЖДОГО товара до рекламы.
- **Маржа до рекламы ≥ 65%, иначе сразу поднимать цену** (их правило после первого заказа — akuliabuhta/1065).
  Скрипт считает строже (с возвратами, чарджбэками, налогом 6%) — при цене $65 и закупке $9 выходит ~54%:
  значит, цену поднимать или искать закупку дешевле.
- **Маржа в двух колонках — до рекламы и после** (akuliabuhta/1047, пост 142). В таблице 1688 так и вести.
- **ДРР ≤ 30% (= ROAS ≥ 3,3); ДРР 70% — работа в ноль** (akuliabuhta/1048, пост 143). ДРР — доля рекламных
  расходов от выручки.
- **ROAS кабинета врёт — вести свою таблицу реального ROAS с первого дня:** выручка Shopify ÷ расход по дням.
  У автора кабинет показал 2,2 ($377 → $828), реальный — больше 3 (akuliabuhta/1042, пост 134). Решения о бюджете —
  по своей таблице (`roas_calc.py real`), не по цифрам Google/Meta.
- **Ориентиры прибыли:** fashion США на Google — >30% чистыми у опытных, цель $1000 → $5000 в день
  (akuliabuhta/1043, пост 135); на больших оборотах (€1 млн/мес) реально 15–20% чистыми, команда 4–7 человек —
  поддержка, закупщики, споры; Claude Code сокращает команду (akuliabuhta/1033, пост 112). **В план закладывать
  15–20%, не 50% «сладких» заказов.** Поддержку и споры автоматизировать Claude (автоответы с треком, черновики
  ответов на диспуты).
- **Не гнаться за оборотом при низком ROAS:** можно разогнать до $10 000/день на ROAS 1,8–1,9 за неделю, но они
  идут медленно ради маржи (akuliabuhta/1044, пост 136).
- **Бюджет:** со 100 тыс. ₽ в международку не идти (akuliabuhta/1031, пост 110) — до запуска посчитать запас
  на тест рекламы ($150–300 на товар) плюс оборот 1–3 недели до первых выплат.

## Средний чек: как поднимать (отметки 29.09)

- **Продавать образами:** платье + туфли + блейзер в одной карточке/подборке — так и получился заказ на 13 вещей
  (akuliabuhta/1129). У нас это сеты (shopify-collections).
- **Приложения «купи 2–3 — скидка»**; **дешёвые товары из рекламы убирать** — они тянут чек вниз; **сезон — по
  полушарию покупателя**: запуск курток в мае–июне на Австралию, где тогда осень–зима (akuliabuhta/1120). Для США
  сейчас (осень–зима) — тёплое верхнее.
- **Дропы вместо постоянной полки:** Sephora с 19.09 делает ежемесячные эксклюзивные дропы в TikTok Shop — тизеры,
  креаторы, старт продаж в эфире (world_ecom/997). Для одежды: ограниченная партия новинок с анонсом в соцсетях и
  письмом своей базе.
- **Зачёркнутая цена — только настоящая.** Amazon в Германии скрывает скидку, если «старая» цена не подтверждена
  продажами за 90 дней (world_ecom/1006). В Shopify (поле compare-at price) не ставить выдуманную «было $99» —
  регуляторы США считают это обманом.
  Точные правила Amazon (ChannelX, прочитан 07.10): «старая» цена подтверждается, только если товар продавался по ней
  как Featured Offer «значимое число дней» за последние 90 (раньше хватало 9 дней), либо её недавно держал другой
  крупный магазин; допуск — чуть выше цены ($29,49 → $29,99 ок, $40 нет). В UK с 23.06.2026, в Германии с 09.09.
  Наш ориентир для compare-at: держали эту цену хотя бы несколько недель из последних 90 дней — иначе поле пустое.
- **Заказов по 2 штуки больше → чек выше → ROAS выше → быстрее масштабирование** (akuliabuhta/1066, пост 189,
  20.08: что именно подкрутили — не раскрыто). У нас до запуска рекламы: «купи 2 — скидка», сеты, «с этим берут».
- **Блок «соберите образ» поднимает чек:** у Albertsons ИИ-ассистент даёт +10% к чеку с разговорным поиском и +26%
  с полным подбором (world_ecom/981, пост 145). Для нас — блок сочетаний в карточке (сеты shopify-collections),
  позже ИИ-консультант по образу. Tesco собирает корзину ИИ по рецептам; 69% готовы доверить покупки ИИ-агенту
  (world_ecom/983, пост 165) — для кругозора.

## Поддержка и возвраты (отметки 29.09)

- **Без «бэкенда» магазин не масштабировать:** на своём сайте, в отличие от WB, нужны поддержка клиентов, быстрые
  ответы, трек-номера, понятная политика возвратов — иначе жалобы и споры, и платёжка (Shopify Payments, PayPal)
  «говорит до свидания» (akuliabuhta/1127).
- **Refund no return:** в дропшиппинге деньги возвращают, а товар остаётся у клиента — отправлять обратно в Китай
  дороже вещи; делают так только для сложных клиентов, при мелкой проблеме — частичная компенсация (akuliabuhta/1121,
  Австралия: 44 тыс. AUD за полмесяца на Facebook Ads + Shopify). Вписать в нашу политику возвратов.
- **Кто отвечает покупателям при росте:** у akuliabuhta к сезону Q4 — 3 медиабайера, 3 человека поддержки (Филиппины
  и Россия), 1 партнёр на два магазина (akuliabuhta/1109, пост 397, 30.08). Филиппины — английский и недорого.
  **У нас:** пока поддержку закрывает ИИ-ассистент + автоответ с трек-номером; человека с Филиппин — когда заказов
  станет больше, чем она успевает разбирать.
- **Три корзины задач поддержки** (курс Anthropic Academy, AI Fluency — kursy-konspekty): ответы по FAQ (доставка,
  трек, размеры) — ИИ сам; персональные — черновик ИИ + она; жалобы, возвраты, споры — только она. В ИИ-чаты не
  класть закупочные цены и данные покупателей без нужды.

## Покупки через ИИ-агентов (отметки 29.09)

Покупать начинают не только люди: Meta Muse сам оформляет заказ через Stripe Link или одноразовую карту, спрашивая
подтверждение (world_ecom/1004); ChatGPT становится витриной предложений, у Klarna ИИ-трафик на праздники +700% при
конверсии на 31% выше (world_ecom/995); Kohl's с ИИ-ассистентом на Gemini — онлайн +2,8% при общей выручке −0,9%
(world_ecom/996).
**У нас:** карточка товара должна читаться машиной — цена, размеры (таблица текстом, не картинкой), материал, цвет,
сроки и цена доставки, условия возврата; чекаут без обязательной регистрации. Позже, после запуска продаж —
ИИ-консультант по размерам и сочетанию вещей: пример «розница» в Claude Commerce Agents
(claude.com/blog/claude-for-commerce-agents — vibecoding_tg/3796).
**Длинный хвост через ИИ-поиск (отметка 07.10):** у Shopify 75% покупок из ИИ-поиска — вне топ-100 категорий,
ИИ-трафик и заказы за год утроились; нишевый запрос находит товар точнее обычного поиска, если в карточке точные
атрибуты, наличие и срок доставки (world_ecom/979, пост 104). Наши вещи «с изюминкой» — как раз хвост: в описании
и метаполях писать ткань, фасон, длину, посадку, повод, стиль («plaid pleated midi skirt, wool blend, for office»).

**Q4 — главный сезон (отметка 07.10).** Октябрь–декабрь (Black Friday, праздники) — опытные покупают магазины под
запуск в Q4 (akuliabuhta/1056, пост 155). У нас: магазин и реклама — до ноября, товары к Black Friday отобрать
заранее, в сезоне — тёплое верхнее.
**ИИ-поиск поднимает нишевые магазины, а не гигантов:** в топ-5 по ИИ-выдаче (Digital Commerce 360, II кв. 2026) —
Nixon, Online Labels, Everlane (одежда!), Fashionphile, CustomInk, все вне топ-100 ритейлеров (world_ecom/986, пост 236,
22.08). Награждается структурированный каталог и точное совпадение с запросом — шанс для маленького магазина одежды:
точные названия («plaid pleated midi skirt wool blend»), заполненные поля категории/цвета/материала, таблица размеров текстом.

**Из первоисточников (прочитаны 07.10, сверх пересказов каналов):**
- PYMNTS 13.08 (long tail): ИИ-агент смотрит на 4 вещи — **структурированные данные товара, сведения о доставке
  (fulfillment), сигналы доверия (отзывы, рейтинг), наличие**. Отзывы с первого заказа — тоже «для ИИ». Термин AEO

## После запуска: конверсия и воронка

Нормальная конверсия магазина — около 2% (у автора 2,22% при 90 тыс. сессий и €143 тыс. продаж за месяц).
Не судить по одной цифре: продажи могут расти при падающей конверсии за счёт трафика. Когда появится трафик —
смотреть, где люди отваливаются: корзина → checkout → покупка (proecomdmitriy/1193).

## Платежи

Подключать **Shopify Payments** на компанию (LLC). На Basic — от 2,9% + $0,30; со сторонней платёжкой Shopify
берёт ещё 2% сверху. Средняя чистая маржа дропшиппинга ~21%, DTC-брендов ~28% (TrueProfit, январь–июль 2026) —
против 3–8% у селлеров Ozon (proecomdmitriy/1192).

**Схема денег (отметки 07.10).** Выручка → счёт компании → виртуальные карты этого счёта платят за рекламу; с того же
счёта пополняется баланс фулфилмента/поставщиков (akuliabuhta/1052, пост 150). **У нас:** Shopify Payments →
банк LLC → отдельная виртуальная карта под Google/Meta (лимит = бюджет теста) и оплата BuckyDrop/HyperSKU.
Проверить, выпускает ли банк LLC виртуальные карты.
- Компания на паспорт РФ (пример — UK через EasyPayments) = проблемы со счетами в банках; запасные платёжки, которые
  упоминает автор, — **OceanPayments** и **PayPal HK** (akuliabuhta/1029, пост 107). Ученики открывают компании США и
  Гонконга на номинальных директоров ради приёма оплаты из 100+ стран (akuliabuhta/1054, пост 154) — у нас база
  уже есть (LLC); номиналов не рассматриваем без её решения.
- Почему своя Shopify-схема, а не маркетплейсы РФ: нет валютных, налоговых рисков, неликвида (дропшиппинг без склада),
  большого ФОТ, роста комиссий площадки; быстрая оборачиваемость (akuliabuhta/1053, пост 153) — подтверждение модели.

**EIN — сразу в пакете регистрации LLC.** EIN — налоговый номер компании в США (выдаёт IRS); без него не открыть Stripe
и банковский счёт на LLC. Нерезидентам агент отправляет форму SS-4 в IRS по факсу: ответ до недели, вся регистрация
через Northwest с EIN — около 3 недель (shopify_chat/166588). **Наш опыт:** LLC открыли без EIN — пришлось за немалые
деньги открывать ИП в Грузии. При следующей регистрации требовать EIN в пакете, иначе LLC бесполезна для Stripe и банков.

**Выплаты Shopify Payments: первые деньги — через 1–3 недели.** На новом магазине обычно 7–8 рабочих дней, но первый
раз бывает холд до 21 дня, потом ~3 дня (shopify_chat/165596). Закладывать в оборотные деньги: закупку и рекламу
оплачиваем сразу, выручка придёт позже.

**Курс конвертации выплат — скрытая потеря ~1% оборота.** Автор провёл через Payoneer $331 000 за полгода (30
переводов): комиссии в выписке почти нет, но курс 7,95 HKD за $1 против 7,87 у Airwallex — ~1%, то есть ~$500 в месяц
и ~$6 000 в год; он перевёл выплаты на Airwallex (proecomdmitriy/1207, пост 914, 06.10). **У нас:** при подключении
выплат (и при оплате посреднику в ¥) сравнить сервисы (Payoneer, Airwallex, Wise, банк) на ОДНОМ переводе по реальным
выпискам и посчитать скриптом:
`python C:\Users\User\.claude\skills\dropship-lessons\vyplaty_kurs.py --oborot 5000 --perevodov 4 --napravlenie pokupaem --servis "Payoneer:7.95:0" --servis "Airwallex:7.87:0"`
(🟡 выписки — только на компьютере; в скрипт вводим только курсы и суммы). Потерю внести строкой «конвертация, %»
в юнит-экономику (sourcing-1688 → «Параметры»).

**Заморозка выплат — держать запас.** У автора одна за другой слетели Shopify Payments и Stripe, $50 000 заморозили;
причина оказалась «не той, о которой он думал» — видео «платёжки без серых схем» (proecomdmitriy/1151, пост 354,
28.08, youtu.be/plzOVuAAZb0). **Причина (разобрано по субтитрам 07.10): чарджбэки 4,6%** — порог Shopify Payments
~1,5% (у Visa/Mastercard норма 0,9%); выше — удержание (холд 30%) или отключение, деньги заморожены на 120–180 дней.
Откуда чарджбэки: заказы уходили не за обещанные 48 ч, а за 7 дней и дольше; на письма покупателей не отвечали;
сайт обещал доставку 4–7 дней. Каждый спор — ещё $15 сверху. Что он исправил: честный срок на сайте («10–25 дней»),
письма-предупреждения о задержке со скидкой, человек на поддержке каждый день + бот «список неотвеченных писем».
**У нас:** держать деньги на 1–2 месяца закупки и рекламы вне платёжки; не держать весь оборот в одной системе;
считать долю чарджбэков раз в неделю (порог тревоги — 0,9%); срок доставки на сайте = реальный срок посредника, а не
«как у всех»; ни одно письмо покупателя без ответа > 24 ч (при запуске поддержки — скрипт-напоминание о неотвеченных).
Ещё из видео: Shopify сам денег не принимает — проверяет подключённая платёжка; компания — только на своё имя, не на
«друга» (уведёт по паспорту и селфи); способ оплаты — по стране покупателя: США — карты (≈8 из 10), Германия — PayPal,
Скандинавия — Klarna, Нидерланды — iDEAL, Бельгия — Bancontact. **Klarna на старте не включать** (рассрочка → много
возвратов и чарджбэков, споры чаще выигрывает покупатель, комиссия ~5,8% против ~2,9% по карте). Комиссия по карте
2,9% на бумаге → у автора 3,8% фактически и ~5,8% с конвертацией валют (компания в Гонконге): **одна страна, одна
валюта** (US-компания, продажи в $, счёт в $) — комиссии вдвое меньше. Чистая прибыль его зрелого магазина — 13%
(реклама 55% выручки), так что «50–70% маржи» в рекламе курсов — миф.

**Гражданство владельца = «высокий риск» для банков.** Компании на граждан России, Беларуси, СНГ, Китая, Филиппин
банки считают рисковыми — вопросы будут всегда (akuliabuhta/1104, пост 349, 28.08; автор рекламирует «номиналов»-
европейцев — это НЕ наш путь: номинал = чужой человек формально владеет компанией, риск потерять деньги и нарушить
KYC). **У нас:** если банк LLC или Shopify Payments начнут задавать вопросы — понимать причину; держать KYC (проверку
личности: паспорт, адрес, документы LLC, EIN, счета посредника и поставщиков) в одной папке 🟡 и отвечать быстро и честно.

## Корзина: наборы и допродажа

Средний чек поднимать до того, как лить больше рекламы: 100 покупателей × $50 = $5000, а при $60 — уже $6000.
Бандл по смыслу (к товару — то, что с ним реально нужно), допродажа в карточке, корзине и после оплаты;
повторные покупки. Скидки не должны съесть прибыль (proecomdmitriy/1191).

**Почему бросают корзину (Baymard).** 39% уходят из-за неожиданных доплат на кассе — доставка, налоги, сборы;
19% — из-за обязательной регистрации. Доставку и её цену показывать заранее (в карточке и корзине), оформление —
без обязательного аккаунта. Перед запуском рекламы самой пройти весь путь до оплаты **с телефона**: понятно ли, что
покупаешь, вызывает ли магазин доверие, видны ли условия доставки и возврата (proecomdmitriy/1195).
**Дырка в ведре — доставка на последнем шаге.** Человеку понравились реклама, товар и цена, а на оформлении он видит
долгую, неожиданно дорогую или непонятную доставку — и закрывает вкладку; владелец же винит креатив или товар
(proecomdmitriy/1199, пост 796, 30.09). Сам владелец дырку не видит — знает сайт наизусть. **Перед рекламой:** срок
(«7–15 дней в США») и цену доставки показать в карточке товара и в корзине; пройти путь до оплаты с телефона глазами
нового человека (лучше — попросить знакомого, который сайт не видел). Другие частые дырки: мобильная версия, первый
экран, карточка товара, отзывы.
**У нас:** сет = бандл (shopify-collections). В старом магазине ARTMELLIO в корзине уже стоят «Complete the set»
и лестница скидок (shopify-admin → «Корзина: набор и лестница скидок») — **при запуске нового магазина перенести**.

## Реклама в Google

Реально запускают только **Performance Max** и **Shopping Ads** — обе на товарном фиде (каталог магазина, который
Shopify отдаёт в Google Merchant Center). Иногда — **брендовый поиск** по названию магазина, чтобы конкуренты не
перехватывали эти запросы (akuliabuhta/1155). Значит, сначала — одобренный Merchant Center и аккуратный фид:
названия, фото, цены, доставка.

**Google Ads — первым каналом, Facebook позже (отметки 07.10).** «Вам нужна выручка или прибыль? Прибыль скорее
увидите с Google Ads, чем с Facebook» (akuliabuhta/1051, пост 149); Google-магазины растут медленнее, но гораздо
прибыльнее, маржа ~30% на США (akuliabuhta/1044, пост 136). Google-магазин — «цифровая недвижимость»: 15 000
товаров и реклама три года — прибыль каждый день (akuliabuhta/1050, пост 147) → **каталог наращивать постепенно**,
не держать магазин из 20 товаров; аккаунт GMC/Ads беречь — он ценен возрастом.
**Медиабайер** (ведёт рекламу за процент) — только когда расход дойдёт до ~$150 в день; до этого ведём сами. У
медиабайеров сотни магазинов — у них можно узнать, что масштабируется у других (akuliabuhta/1035, пост 117; 1044).
«Три магазина сразу» — совет автора на будущее, не сейчас (akuliabuhta/1035).
**Главный актив — связка GMC + прокачанный Google Ads + Shopify;** блокируют именно GMC. У автора год блокировок,
пока не показали ошибки, потом — ни одной (akuliabuhta/1032, пост 111). Причины ошибок в посте не раскрыты (курс) —
наш чек-лист ниже.

**Merchant Center (GMC): попытки не тратить.** Часто одобряет, а через неделю банит; после трёх отказов восстановить
нельзя — только новый аккаунт. За «помощь с апрувом» просят 1500 € (shopify_chat/165794). Перед подачей магазин
готов полностью: политики (возврат, доставка, конфиденциальность, условия), контакты, реальные сроки и цены доставки,
цены в фиде = цены на сайте.

## Каналы продаж и цены

**TikTok Shop США открыт и через китайскую компанию.** На выставке в Шэньчжэне TikTok Shop сам регистрирует
продавцов и обещает помощь со складами, сотрудниками и эфирами; для китайских компаний открыты Amazon, Temu, Shein,
TikTok Shop, Walmart, eBay (anita_bold/5963). Язык не барьер: китайцы предлагают ИИ-решение для общения с покупателями
США на английском вместо найма сотрудника (anita_bold/5995).

Если реклама Google/Facebook/Instagram ведёт в магазин — цена на сайте должна совпадать с объявлением.
В каналах со своей оплатой (TikTok Shop, Temu) можно задать отдельный ассортимент, цены и валюту и поднять цену
на комиссию площадки, не трогая сайт; каталог канала дополняет товары родительского рынка, а не заменяет
(world_ecom/1028).
Из справки Shopify (help.shopify.com → channel-markets, прочитана 07.10): каналы делятся на «приводящие трафик»
(Google, Facebook — цена обязана совпадать с сайтом, иначе предупреждение) и «оформляющие заказ» (TikTok Shop, Temu —
свои цены и наличие). Валюта канального рынка должна быть «предпочтительной для канала», регион — поддерживаться
каналом. **Agentic storefronts (продажа через ИИ-агентов Shopify) channel markets не поддерживают** — для ИИ-покупателей
действует цена основного рынка. Настройка: Settings → Markets → создать рынок для канала → свой каталог (разделы
справки «Creating and activating markets», «Creating catalogs for markets»).

## Доставка

**Цифры Landmark Global (пресс-релиз прочитан 12.10, world_ecom/1025):** 43% покупателей США и Канады отказываются от
покупки в зарубежном магазине из-за скрытых платежей — пошлину и полную цену («landed cost») показывать ДО оплаты;
68% американцев доплатят за гарантированную доставку к 24 декабря — к праздникам дать честную дату «успеет к Рождеству»
и последний день заказа. Само приложение Landmark — отправка из страны продавца, нам только при стоке в США.

**Платная доставка + порог бесплатной** («бесплатно от $75») лучше, чем бесплатная всем: порог подталкивает к большему
чеку (shopify_chat/164850). Для нашего магазина одежды — порог чуть выше среднего чека, цену доставки показывать заранее
(см. Baymard выше).

**Планка скорости посредника (отметки 07.10):** хороший фулфилмент в Шэньчжэне — до двери в США **4 дня**, ЕС/UK —
5 дней; менеджеры делают 300 запросов к фабрикам (фото, размерная сетка) в день, у обычных агентов ~5 в сутки;
12 складов возвратов (akuliabuhta/1037, пост 119). Доставка Китай → США сейчас быстрее, чем WB по России
(akuliabuhta/1060, пост 170). **У нас:** у BuckyDrop/HyperSKU спросить срок до двери в США (норма 4–7 дней) и
сколько запросов к фабрикам они делают в день; это критерий выбора посредника.

(akuliabuhta/1062, пост 173). Остаёмся в одежде — контроль проще.

## Поставщики и посредники

«Поставщик точно подведёт» — план на этот случай нужен заранее. Автор разбирает живой счёт от своего агента
(в нём есть строка, на которой спотыкаются даже опытные), как написать агенту, чтобы ответил, как торговаться,
чтобы цена реально менялась, и что делать при срыве (proecomdmitriy/1184, видео youtu.be/oBM1aXBxN-k — **разобрано
по субтитрам 07.10**):
- **Три уровня поставщика:** AliExpress (проверить гипотезу сразу, но доставка 15–25 дней) → сервисы для дропшиппинга
  (свои склады, приложение к Shopify, дороже) → **агент-посредник** — переходить после первых **20–30 заказов**.
- **Та самая строка в счёте — пошлина:** с лета 2026 в ЕС ~€3 за посылку (два товара одной категории — €3, разных —
  может быть €6). Агенты прячут её в общую сумму «$15 за заказ». Требовать счёт **отдельными строками**: товар,
  доставка, НДС, пошлина, комиссия агента. Общая сумма без разбивки — не работать. Наценка — **минимум ×4** от
  (закупка + доставка + все сборы). (Для США — своя пошлина; строка «пошлина» уже есть в юнит-экономике sourcing-1688.)
- **Первое письмо агенту — 4 вещи:** ссылка на товар; сколько заказов в месяц сейчас; в какую страну; просьба дать
  цену закупки + доставки + прочие расходы отдельными строками. И два вопроса: кто платит за брак; можно ли свои
  вкладыши/упаковку (вкладыш 1–10 ¢, коробка < $1). Писать сразу 5–10 агентам одно и то же и сравнить.
- **Торг:** не «дайте скидку» (скажут «да» и тихо ухудшат качество), а **ценовая сетка**: «сейчас N заказов — какая
  цена при 100 и при 300?»; спросить канал доставки быстрее за те же деньги; цель — понять, из чего цена, а не
  «у кого дешевле».
- **Когда подвёл (подведёт точно):** 1) запасной продавец на тот же товар заранее (у автора — AliExpress на крайний
  случай); 2) **первый заказ — себе**, не клиенту (~$10 — увидеть упаковку, срок, качество); 3) при браке — просить
  **переотправку, а не деньги**; 4) сроки с агентом — письменно, с датами. Отвечает перед покупателем, Trustpilot,
  платёжкой и Merchant Center — магазин, а не поставщик.
**У нас:** счёт посредника (BuckyDrop №1, HyperSKU №2, ZQ №3) разбирать построчно до оплаты (правило «отдельными
строками»); первое письмо посреднику — по шаблону из 4 пунктов выше + сетка цен; первый заказ каждой модели — на
себя/на свой адрес у посредника с фото; на каждый товар держать запасного поставщика из базы
(cj\postavshchiki_baza.tsv) — от 1 шт со скидкой на опт.

## Из книг (09.10.2026)

Полный список — `references/iz_knig.md`: 58 приёмов из 15 купленных книг, разложены по моментам работы. Там же
раздел «Расходится с нашими решениями»: эти приёмы не применяем. Главное:
- **Перед закупкой:** сначала цена, которую примет покупательница, потом предельная закупка в ¥ (target costing).
  Стартовать с честной полной цены, а не с «дешёвой» (French; Grewal).
- **Перед скидкой:** нужный рост продаж = маржа ÷ (маржа − скидка). При марже 65% скидка −20% требует ×1,44 продаж.
  Одна акция за раз, sale только на части ассортимента. Первую покупку «покупать» бесплатной доставкой или подарком,
  а не −35% (Котлер EM, Котлер MM).
- **Цены:** 3 уровня «хорошо / лучше / лучшее» на фиксированной сетке. Окончание .99 — не рычаг (Grewal; Котлер MM).
- **Карточка:** одна выгода + один страх и чем его снимаем (таблица в дюймах, фото ткани, возврат). Язык — словами
  самих покупательниц из отзывов (Tracy; Котлер DA).
- **Тест:** цель «фокус + цифра + срок» и заранее записанный «допустимый убыток» со стоп-правилом
  (Котлер MM; Котлер EM).
- **Разбор:** воронка по 5 шагам 5A. Чинить одно узкое горлышко: клик → креатив, «расспрос» → отзывы,
  покупка → цена, доставка, размер (Котлер DA; Котлер 4.0).
- **Креативы:** лоу-фай и UGC важнее глянца. На товар 3 идеи разной смелости. ИИ-модель в одежде — только рядом
  с реальным фото посадки (Котлер 7.0).
- **Экономика клиента:** CAC сравнивать с CLV. Возвраты 10–20% закладывать как норму. После 20–50 заказов модели
  считать её «прямую прибыльность» (Котлер MM; Tracy).
- **После ~100 заказов:** когорты и RFM. Рассылки 2–3 письма в месяц, не чаще. Лояльность — бонусами за частоту,
  а не постоянной скидкой (Мукминов; Котлер MM).
