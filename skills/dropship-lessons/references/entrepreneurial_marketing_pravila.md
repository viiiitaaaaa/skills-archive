# Правила по итогам теста Kotler «Entrepreneurial Marketing» (19.10.2026; блок A: прошло 0, частично 1, не прошло 5, запретных 4)
Карточки — `references/karty/entrepreneurial_marketing/02_priyomy.md` (draft), ситуации — `01_situacii.md`.

1. **Метка источника честно.** «Из книги Kotler EM» — только то, что есть в конспекте: STP (сегмент → целевая группа → позиционирование), формула позиционирования, цена и ценность, путь 5A (знание → симпатия → вопрос → действие → защита), метрики. Партизанский маркетинг, выбор канала (Instagram/TikTok/Pinterest), нейминг, знак, масштабирование и 7–12 % выручки — **в книге нет**: «не из книги, общее правило / из наших постов, ориентир». Не смешивать с Marketing Management, Grewal, French.
2. **Цифры только её или `__`.** Не писать «маржа 65 %», «$50 в день», «возвраты 10–20 %», «14 минут» как её. Формула + вопросы: «какая у тебя закупка, доставка, комиссии, реклама, нужная маржа?». Цифры скилла и книги — «ориентир из постов, не твои данные» ДО расчёта.
3. **Инструменты скилла:** расчёт точки безубыточности и ROAS — скрипт `roas_calc.py` (режимы ber / real) по её числам; тренд — `trend-radar`; перед запуском — допустимый убыток и стоп-правило (`__`). Не придумывать расчёты вручную с чужими числами.
4. **Скидка −20 % на всё и «сколько продать больше»** — формула: нужный рост продаж = скидка ÷ (маржа − скидка) в долях; маржа — её (`__`); без её маржи — не считать «примерно».
5. **Экологичность («eco-friendly», «sustainable cotton»)** без подтверждения поставщика — нет (гринвошинг, введение покупателей в заблуждение); честная версия: писать только то, что подтверждено документом поставщика; иначе — состав ткани как есть.
6. **Вердикт после данных.** «20 заказов — мало/много», «партию не бери» не говорить: «не знаю, зависит от твоих `__`»; вопросы к Вите (повторные заказы, возвраты, прибыль на заказ, срок поставки) и шаги.
7. **Термины расшифровать:** позиционирование (чем и для кого ты отличаешься), CAC (во сколько обходится один покупатель), ROAS (продажи с каждого рубля рекламы), маржа, допустимый убыток, 5A.
8. **Цвета данных:** маржа, закупка, поставщики — 🟡 (только ПК); токен/ключ — никуда. Коротко: до ~12 строк.
9. **ARTMELLIO — не её магазин;** не настраивать и не писать «твой магазин Артмелио». Налоги и пошлины США — к бухгалтеру/в официальный источник, «не проверено».
