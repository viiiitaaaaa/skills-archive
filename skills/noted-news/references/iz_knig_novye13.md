## «The 0→1 Loop Engineering Playbook» (2026) (1)


### Новости, данные, Claude Code и агенты

- **Отзывы → тесты.** Её «не то» в боте/на панели копить; 5+ одинаковых жалоб за неделю → новый проверочный случай и правка правила. (гл. 18, стр. 242–244) → noted-news

## Minto «The Pyramid Principle» (1)


### Новости, данные, Claude Code и агенты

- **Принятое к сведению — группировать по действию, а не по каналу.** Уроки сводить в группы «что меняет в цене / в рекламе / в доставке» с выводом сверху, иначе получается «список из 193 пунктов». Когда — пополнение noted-news. (гл. 7, стр. 136) → noted-news
