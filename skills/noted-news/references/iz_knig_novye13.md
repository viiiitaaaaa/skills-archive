## Chip Huyen «AI Engineering» (2)


### Новости, данные, Claude Code и агенты

- **Каждая метрика — вопрос «что мы сделаем иначе».** Метрика — не цель, а индикатор «что-то идёт не так»; если от значения ничего не зависит — не собирать. (гл.10, стр. 881) → noted-news
- **Перед внедрением нового инструмента — вопрос «фундаментальная это проблема или решит модель посильнее».** Закон Линди: что живёт давно, проживёт ещё; быстро стареют обёртки и фреймворки — отсюда «принятое к сведению» оценивать на долговечность. (Предисловие, стр. 15) → noted-news

## Dixon, Adamson «The Challenger Sale» (1)


### Новости, данные, Claude Code и агенты

- **Новости: фильтр «опыт продажи ≠ продукт».** При разборе постов про рекламу/продажи искать идеи, которые меняют **разговор с клиентом** (инсайт, порядок аргументов), а не слова про «лучшие инструменты» — отнести к тому, что вписывается в её правило «в дашборд только то, что меняет действие». → noted-news

## Whalen «Design for How People Think» (1)


### Новости, данные, Claude Code и агенты

- **Единичное — не шаблон.** Если пожелание встретилось у одного человека из многих, записать, но не переделывать продукт, пока не повторится. (гл. 12, стр. 139) → noted-news

## Gabriel Wyner «Fluent Forever» (1)


### Новости, данные, Claude Code и агенты

- **Принятое из новостей — карточки «вопрос–ответ».** Новость → вопрос «что мы сделаем иначе?» + скриншот; повтор интервалами. «Rote repetition is boring, and it doesn't work for long-term memorization.» (перевод: механическое повторение скучно и не работает для долгой памяти). (гл. 2, стр. 36) → noted-news

## Croll, Yoskovitz «Lean Analytics» (2)


### Новости, данные, Claude Code и агенты

- **«Хорошие данные лучше больших» (EMI).** Вместо добывания всего подряд — маленький набор, собранный под вопрос (1 млн интервью в EMI); это аргумент против «собрать всё» без вопроса. Совместить с её правилом «собрать всё = досье»: сначала формулировка вопроса. Когда: запуск сбора по новой теме. (гл. 30, стр. 383) → noted-news
- **Метрики для «принятого к сведению».** Принятое из новостей считать не по числу, а по тому, сколько превратилось в рабочий скилл и сколько применено к делу и дало эффект; остальное — шум. Когда: отчёт по noted. (гл. 2, стр. 12–15; гл. 16) → noted-news

## «The 0→1 Loop Engineering Playbook» (2026) (1)


### Новости, данные, Claude Code и агенты

- **Отзывы → тесты.** Её «не то» в боте/на панели копить; 5+ одинаковых жалоб за неделю → новый проверочный случай и правка правила. (гл. 18, стр. 242–244) → noted-news

## Brown, Roediger, McDaniel «Make It Stick» (1)


### Новости, данные, Claude Code и агенты

- **Каждое «принятое к сведению» — вопрос на самопроверку.** После прочтения поста: что взять, зачем, что не нужно — на память, потом сверить. Это совпадает с её правилом «отвечать разбором». Через неделю — те же три вопроса без подсказок. (стр. 220, 228) → noted-news

## Minto «The Pyramid Principle» (1)


### Новости, данные, Claude Code и агенты

- **Принятое к сведению — группировать по действию, а не по каналу.** Уроки сводить в группы «что меняет в цене / в рекламе / в доставке» с выводом сверху, иначе получается «список из 193 пунктов». Когда — пополнение noted-news. (гл. 7, стр. 136) → noted-news

## Voss «Never Split the Difference» (1)


### Новости, данные, Claude Code и агенты

- **Признаки «Pinocchio» в текстах новостей и пресс-релизов.** Много слов, обобщений, «они/мы», усложнённые фразы вокруг простого факта — сигнал, что нужно искать цифры. Применять осторожно как эвристику (в книге — про устную речь). (гл.8, стр. 146–147) → noted-news

## April Dunford «Obviously Awesome» (2)


### Магазин одежды

- **Не прикручивать горячее слово без связи с товаром.** Урок Long Blockchain: не писать «AI-стиль» и т.п. для модности; тренд только при реальной связи. (ч.14) → noted-news

### Новости, данные, Claude Code и агенты

- **Вопрос «и что?» для каждой возможности.** После пункта в новости или инструмента для Claude Code спрашивать «и что это даёт нам?» до ценности в нашей цели (особенность → выгода → ценность). (ч.11) → noted-news

## Anders Ericsson «Peak» (1)


### Новости, данные, Claude Code и агенты

- **Источники новостей оценивать по результатам.** Не «приятный канал», а «были ли у автора проверяемые результаты»; харизма ≠ эффективность. (гл. 6, стр. 141) → noted-news

## Agrawal, Gans, Goldfarb «Prediction Machines» (2)


### Новости, данные, Claude Code и агенты

- **Искать её неосознанные критерии.** Lola нашла предпочтения, которые агенты сами не могли назвать (новые отели, отели на углу). Раз в месяц просить Claude сравнить её отмеченные и неотмеченные товары или посты и предложить 3 скрытых правила — показать ей; записывать только подтверждённые. Когда — после 50+ решений. (гл. 10, ч. 19) → noted-news
- **Не дообучать правила из потока без её «да».** Бот Tay «выучился» расизму у пользователей за день. Никакой агент не меняет скиллы и фильтры сам по пересланным постам или чужим текстам: только предложение → её подтверждение. Когда — бот «Дела», noted-news, автоРазбор. (гл. 20, ч. 31) → claude-code-priemy

## Tiago Forte «Building a Second Brain» (4)


### CODE и PARA для нашей системы (скиллы Claude, память, `znaniya`, Диск, бот «Дела», новости, конспекты)

- **Новости: `noted-news` = «Ресурсы» с входом по проекту.** Принятое к сведению не лежит «по теме»: при старте проекта (реклама, страна, платёж, цены) его достают и переносят в папку проекта — это шаги 2–4 kickoff-чек-листа. Зачем: «встретить идею в самый нужный момент». Когда: в начале каждого проекта по теме. (гл. 5, стр. 76; гл. 9, стр. 182–183) → noted-news
- **Фильтр «принято к сведению» дополнить четырьмя вопросами.** К её правилу «меняет наше действие» добавить: вдохновляет? полезно? лично? удивляет? (последнее — «информация это то, что вас удивляет», Шеннон; защита от подтверждения уже известного). Зачем: на панели не должно копиться то, что мы и так знали. Когда: при разборе пачки новостей. (гл. 4, стр. 58–60) → noted-news
- **Для карточек новостей — лимит «выписки ≤10% поста».** В `принятое.md` держать суть и ссылку, а не пересказ всего поста; для длинных — слои (жирным главное, подсветка одного действия). Зачем: будущей ей некогда читать длинное. Когда: при записи в `noted-news`. (гл. 4, стр. 57–58; гл. 6, стр. 124) → noted-news
- **Недельный просмотр новостей по «12 проблемам».** Раз в неделю: из принятого оставить то, что отвечает на её открытые вопросы (магазин, Frivent, дела), остальное — в архив. Зачем: чтобы принятое не превращалось в склад. Когда: по её слову. (гл. 4, стр. 52–57; гл. 9, стр. 190–191) → noted-news

## Dilts «Sleight of Mouth» (1)


### Новости, данные, Claude Code и агенты

- **Новости: «что меняет действие».** Рамка результата для разбора канала: что мы будем делать иначе? Согласуется с её правилом отбора новостей — при разборе постов. (стр. 35–36) → noted-news

## Rackham «The SPIN Selling Fieldbook» (2)


### Новости, данные, Claude Code и агенты

- **Не показывать инструмент раньше проблемы в уроках из новостей.** В записи «принято к сведению» всегда сначала проблема, потом инструмент, иначе завтра никто не поймёт, зачем это. → noted-news
- **Проверка тренингов/курсов/инструментов на «змеиное масло».** Красные флаги: «удвойте продажи», «новый драматический прорыв», «используют IBM/…» без проверки; требовать ссылки на реальных пользователей и тех, кто прошёл 100+ человек (чек-лист в «Моделях»). Когда: каждый новый курс/сервис в новостях. (стр. 226) → noted-news

## Scott Young «Ultralearning» (1)


### Новости, данные, Claude Code и агенты

## Bandler «Using Your Brain — for a Change» (1)


### Новости, данные, Claude Code и агенты
