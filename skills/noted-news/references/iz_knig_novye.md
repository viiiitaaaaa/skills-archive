### Новости, данные, Claude Code

### Новости, данные, Claude Code

- **Правила площадок — из первоисточника.** Для политик Shopify/Meta/Amazon сверяться с официальными страницами, а не с блогами; при спорных новостях. (Кн.3 гл.2) → скилл noted-news

## Grewal «Marketing» 8e (США), ч. A (2)


### Новости, данные, Claude Code

- **Пометка «правило устарело / закон изменился» при разборе новостей про FTC и рекламу у блогеров.** Если в новостях встречается FTC, раскрытие рекламы, фейковые отзывы или покупка подписчиков, сверять с этим конспектом и обновлять правило в dropship-lessons. Зачем: в книге 2022 года руководство FTC ещё было «необязательным», а с тех пор появились обязательные правила и штрафы. Когда: при разборе новостей. (гл. 3, стр. 112) → noted-news
- **Хэштег без продукта не работает.** Урок Нигерии (#BuyNaija): вирусная кампания без реального предложения ничего не меняет. При разборе новостей про «вирусные» механики спрашивать: есть ли за ними товар/предложение у нас — иначе skip. Когда: при отборе новостей о маркетинговых трюках. (гл. 8, стр. 254) → noted-news
