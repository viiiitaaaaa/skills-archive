# Интерьерная сцена одним кадром (Qwen Image 3 Edit, ComfyUI Cloud)

Конвейер: комната + листы товаров -> один прогон -> кадр. Дальше правки, каждая - тоже один прогон. Кредиты жжём только на подтверждённые шаги, не на угадывание.

Товары лежат в `C:\Users\User\Desktop\japandi_white\<номер комнаты>`, готовые кадры кладём в `C:\Users\User\Desktop\japandi_room`.

## Железные правила заказчика

1. **Не менять товар.** Цвет, материал, назначение, размер, форма - как на фото товара. Чёрный смеситель остаётся чёрным и смесителем, не перекрашивается и не масштабируется.
2. **Не трогать комнату.** Тот же ракурс, та же ширина кадра, та же планировка. `size: match input` обязателен. Обрезка и «зум» - брак, за них уже прилетало.
3. **Вся фурнитура матово-чёрная.** Смесители, душ, держатели. Хром и бронза - брак.
4. **Один прогон на задачу.** Не итерировать по мелочам, не переспрашивать по пустякам, выдавать результат сразу.
5. **Правки приходят картинкой.** Пользователь рисует поверх кадра - это ТЗ, см. ниже.

## Три сценария

### A. Собрать комнату с нуля
Входы: `@Image1` - комната, `@Image2` - лист сантехники, `@Image3` - лист декора.

### B. Перестановка предметов
Пользователь наклеивает поверх готового кадра куски: переставленные предметы, вторую копию светильника, белые прямоугольники на месте убранного (файл вида `л.png`).
Входы: `@Image1` - чистый предыдущий рендер, `@Image2` - коллаж-макет, `@Image3` - лист товаров.
Промт: «сделай чистую фотореалистичную версию @Image1 с раскладкой из @Image2», дальше словами перечислить каждую перестановку.

### C. Убрать деталь
Пользователь обводит красным то, что мешает (файл вида `000.PNG` - кроп с красными пометками).
Входы: `@Image1` - кадр, `@Image2` - кроп с пометками.
Промт: назвать деталь словами, сказать чем её заменить («цилиндр крепится прямо к стене, без деревянной накладки»), и обязательно `No red marks in the output`.

## Листы товаров

Больше 3 картинок Qwen не принимает, поэтому товары клеим в листы: белый фон, сетка, под каждой клеткой крупная подпись `A1 black tall bamboo tap`. В промте адресуем по этим кодам - модель их читает.

Готовый сборщик листов: `make_sheets.py` в папке скилла. Кропы обязательны - у товарных фото с AliExpress по краям логотипы, иероглифы, рекламный текст и размерные линии, их надо срезать, иначе они уедут в кадр.

Что уже в комнате - в лист не кладём, а пишем «B5 and B6 are already in the room - keep them where they are».

## Скелет промта

Порядок блоков менять нельзя, он выверен:

1. **Что есть что:** «@Image1 is the bathroom. @Image2 is a rough paste-up showing where things must move. @Image3 is a product sheet.»
2. **Что сохранить** - длинным перечислением через `same`: same camera, same full width, same tiles, same vanity, same mirror, same ladder, same bathtub... Чем подробнее список, тем меньше самодеятельности. Закрыть словами `Do not crop, do not zoom in, do not narrow the space, do not rebuild the room.`
3. **Правило товара:** «Every product keeps its own real colour, its own material, its own shape and its own real-world size - never recolour, never resize, never turn it into a different object.»
4. **Список задач** нумерованно, по одному предмету на пункт, с указанием места: «B1: the moss picture STANDS on its own black easel stand on the left countertop, leaning slightly back. It is not hanging on the wall, it is standing.» Спорные вещи дублировать заглавными и отрицанием - так `STANDS ... not hanging` наконец сработало.
5. **Сшивка:** «Blend everything naturally into the photo - no pasted rectangles, no visible collage edges, no white patches, correct perspective, correct shadows.»
6. **Хвост:** свет, чёрная фурнитура, `Photorealistic interior photograph, sharp, no text, no watermark.`

Негатив (у этой модели работает, в отличие от Flux):
```
collage edges, pasted rectangles, white patches, blank boxes, seams, duplicated objects,
chrome fittings, bronze fittings, green metal, dark room, cropped frame, narrow room,
text, letters, labels, watermark, distorted perspective
```
Для сценария C добавить `red marks, red lines`.

## Параметры ноды

| Параметр | Значение |
|---|---|
| Нода | `QwenImageEditApi` |
| model | `qwen-image-3.0-pro` |
| size | `match input` - иначе кадр поедет |
| n / seed | 1 / любое фиксированное |
| prompt_extend | `false` - иначе модель перепишет промт по-своему |
| watermark | `false` |

Ключи входов в API-графе: `model.images.image_1`, `model.images.image_2`, `model.images.image_3`, `model.prompt`, `model.negative_prompt`.

## Запуск

Полный рабочий код - `run_comfy.md` в папке скилла. Главное:

- **Токен.** `app.api.queuePrompt()` из консоли не подкладывает токен, нода отвечает `Unauthorized: Please login first to use this node`, и это **не** повод гонять пользователя перелогиниваться - проверено, четыре круга впустую. Брать токен из `localStorage['firebase:authUser:*'].stsTokenManager.accessToken` и слать свой POST на `/prompt` с `extra_data.auth_token_comfy_org`. Подробности в [[comfy-cloud-api-token]].
- **Загрузка файлов.** Создать скрытый `input[type=file]`, найти его через `find`, залить туда файлы инструментом `file_upload`, затем POST каждого файла на `/upload/image`. Сервер вернёт хеш-имя - его и подставлять в `LoadImage`. Файлы на сервере живут между сессиями, повторно заливать не нужно.
- **Ожидание.** `javascript_tool` рвётся на 45 с: цикл опроса `getJobDetail` резать на 10-12 итераций по 5 с и вызывать повторно. Генерация занимает 30-60 с.
- **Забрать результат.** `getJobAssets(id)` -> `/view?filename=<hash>` -> blob -> клик по `<a download>`. Падает в `C:\Users\User\Downloads`, оттуда копировать в `japandi_room` под осмысленным именем `FINAL_<комната>_<день|ночь>_v<N>.png`.
- **Не выводить токен в лог** - браузерный инструмент режет весь ответ, если внутри токен. Печатать только флаги (`typeof`, `hasToken`), не значения.

## Чтобы не жечь кредиты

- Перед запуском прочитать **все** картинки из папки товаров глазами. Половина правок берётся из того, что на фото товара есть лишнее - логотип, иероглифы, вторая расцветка в том же кадре.
- Уже готовый кадр - лучшая база для следующего шага. Не пересобирать сцену с нуля ради одной детали.
- Одна правка - один прогон, но правки копить: если пользователь прислал макет с четырьмя изменениями, все четыре идут в один промт.
- Смотреть результат самому и называть недочёты первым. По ванной так остался светлый карниз шторки - лучше сказать, чем ждать, пока заметят.
- Ночные сцены уходят в кашу: тёмный кадр съедает всё, кроме окна. Если нужна ночь - явно прописывать каждый источник света и что он освещает.
