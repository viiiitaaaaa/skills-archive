### Плавная типографика на `clamp()` без брейкпоинтов
- Источник: frontend_baza/2512
- Суть: Размер шрифта задаётся одной формулой через `clamp()` и viewport units. Только `vw` ломает масштабирование при zoom, поэтому добавляют фиксированную единицу: `h1 { font-size: clamp(16px, 15px + 0.2vw, 18px); }`. Container queries для типографики автор не советует.

### form.requestSubmit() вместо form.submit()
- Источник: tproger_web/6632
- Суть: `form.submit()` отправляет форму без проверки полей и без события `submit`. `form.requestSubmit()` запускает обычный сценарий через submit-кнопку: браузер проверяет ограничения полей и вызывает `submit`; можно передать конкретную кнопку. Оговорка: `novalidate` у формы и `formnovalidate` у кнопки меняют проверку, а клиентская валидация не заменяет серверную.
- Для нас: В формах сайта (подписка, заявка), которые Claude Code вёрстает, отправку из JS делать через `requestSubmit()`.

### scrollbar-gutter убирает сдвиг страницы при скроллбаре
- Источник: tproger_web/6633
- Суть: `scrollbar-gutter: stable` резервирует место под полосу прокрутки заранее, и контент не прыгает. `stable both-edges` добавляет такой же отступ с другой стороны. С overlay-скроллбарами резерв не создаётся.
- Для нас: Добавить `scrollbar-gutter: stable` в базовые стили нашего сайта и просить Claude Code так делать.

### Цикл в ResizeObserver и как его не получить
- Источник: tproger_web/6636
- Суть: Если в callback менять размер того же элемента, возникает цикл; браузер переносит уведомления и пишет `ResizeObserver loop completed with undelivered notifications`. `requestAnimationFrame()` лишь откладывает. Решение: хранить ожидаемый размер и не задавать его повторно.
- Для нас: При вёрстке сайта не менять размер наблюдаемого элемента в `ResizeObserver` без конечного состояния.

### Атрибут `inert` отключает целую панель
