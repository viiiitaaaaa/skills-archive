# Прокрутка как фильм — приёмы из scroll-craft (30.10.2026, черновик по чужому, код не берём)

Источник: github.com/nateherkai/scroll-craft (MIT, 4 209 ★, обновлён 30.09.2026). Файлы прочитаны в карантине
(`~\.claude\karantin\gh-scroll-craft`). Скилл целиком НЕ ставим: платная генерация картинок через kie.ai (нужен ключ) и скрипты Node.
Не проверено на практике. Применять только после согласованного каркаса сайта.

1. Колесо мыши — «ползунок по плёнке»: страница как фильм, текст поверх.
2. Разные блоки ведут себя по-разному: минимум четыре приёма, один и тот же — не два раза подряд.
3. Нет одного длинного пролёта камеры: он дорогой, ломкий и нужен только чтобы скрыть склейки.
4. Структура страницы и внешний вид — две разные оси: решать отдельно, иначе все сайты получатся одинаковыми.
5. Шапка «с глубиной»: фон, предмет, передний план и дымка двигаются с разной скоростью; заголовок читается всегда.
6. Один «пик» эмоций на всю страницу и одно фирменное движение.
7. Отдельная вёрстка для телефона и вариант для «без анимации» (reduced-motion).
8. Проверка: снимки экрана на разных местах прокрутки (компьютер, телефон).
9. Чего избегать: одинаковый счётчик «01 / 06», центрированный текст везде, подсказка «scroll to explore».
