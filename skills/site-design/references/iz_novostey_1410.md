# Из новостей 14.10.2026 — сайт: вёрстка, выкладка, безопасность

Источник — канал/номер. Полные карточки по дизайну design_to_skill.py уже сложил в скилл; здесь — что меняет наши действия.

## Как заказывать вёрстку у Claude
- Не скриншот референса, а его механика: сетка, анимация, порядок блоков из Inspo + сам скриншот (onlyfigma/6106).
- Схема «референс (Inspo) + ссылка в браузере + круг правок руками после каждой итерации» (vibecoding_community/247653);
  макет — с готовой базой продукта и 2–3 референсами, не одной командой (253224). Вёрстка — Opus на medium, дизайн тянуть скиллами (247461).
- Сразу рабочий прототип кодом и ссылкой, без отдельного статичного макета (designdealer/3520).
- Проверка готового лендинга на «пахнет вайбкодом»: шрифты не дефолтные, анимации умеренные (без головокружения), первый
  экран прямо говорит, что продаём, заголовки без пустых лозунгов (vibecoding_community/250107).
- Сначала то, что браузер умеет сам: `<dialog>` для окон (быстрый просмотр, размерная сетка) вместо библиотеки (tproger_web/6613).

## Выкладка (Cloudflare)
- Сначала на workers.dev → qa_site → перенос (не редирект) на боевой домен; скилл деплоя готовит команду (vibecoding_community/247123).
- Домен брать там, где бесплатное управление DNS; у нас Cloudflare — можно купить домен там же (252503).
- 5 защитных заголовков в `_headers`: `Strict-Transport-Security`, `Content-Security-Policy`, `X-Frame-Options: DENY`,
  `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin` (c/3493639787/800). CSP проверить,
  чтобы не сломать шрифты Google и форму. Ставить по её «делай» — это боевой сайт.

## Картинки, шрифты, ресурсы
- Фото: WebP/AVIF основными; JPEG XL (Chrome 155, Firefox 158) — только запасным в `<picture>`, сравнить размер на одном наборе
  (tproger_web/6604, webstandards_ru/7889).
- Пары шрифтов проверить на кириллицу и лицензию: Onest + Libre Caslon Condensed, Durik + Manrope (onlyfigma/6079).
- Тёплая премиальная палитра: `#E5DFD6` / `#B19061` / `#3C2418` — вариант к токенам (sitodel/3936).
- ~~Bento-плитки (bentogrids.com, fourdesign/6665)~~ — НЕ брать: bento в нашем списке анти-шаблона «сайт от вайбкодера» (12.10).
- Фоны и текстуры — rawpixel.com (лицензию на коммерцию проверить), звуки — freesound.org (у части нужна подпись автора).

  калькулятор с ползунками + агент-рецензент цифр по исходному документу (TochkiNadAI/2751).
- Модели в одежде без «пластика»: Nano Banana vs Seedream на 3–5 товарах по референсу, человек и фон — разными шагами (250321).
