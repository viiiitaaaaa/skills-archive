## Анти-шаблон «сайт от вайбкодера» — чек-лист для каждой страницы
- 30 признаков ИИ-сайта; конкретные запреты: кремовый фон «по умолчанию», курсив в заголовках, нумерация 01/02/03,
  кнопки-таблетки, Inter, bento-сетки, фиолетовый с чёрным (ii_papka/991, neurozeh/1843, ai_vibe/3280).
  В промпт писать именно список запретов, а не «не как нейросеть». Внимание: наш тёплый фон `#E5DFD6` — решение, а не
  шаблон; проверять, что он работает с фактурой и фото, а не пустой «кремовый».
- Сначала бриф и ОДИН главный визуальный приём страницы, потом код (NeuroLuv/1811).
- Моушн-промпт: inputs / direction / structure / build + запреты (никаких прыгучих анимаций, свечений, градиентов) (projplus/4902).
- Плакат-принцип для первого экрана и баннеров: один объект, смысл в заголовке, одно преимущество (glvrdru/6991).

## Дизайн-система для агента
- DESIGN.md — один файл: цвета, шрифты, отступы, кнопки. Снять с премиальных референсов: initium.sh
  (notboring_tech/4387), designmd.supply по адресу сайта (TochkiNadAI/2619), awesome-design-md (ai4svoi/143) → собрать
  DESIGN.md для lead-engine.
- Второй лендинг за 15 минут: «в стиле первого, переиспользуй блоки»; скилл вёрстки собран из всех прошлых ошибок
  агента (molyanov_blog/4982).
- Точные отступы: агент делает страничку с ползунками, двигает она сама; после правки агент снимает скриншоты, отдельный
  агент-критик проверяет (neurozeh/1790, 1802, 1784).

## Техника вёрстки
- `<meta name="viewport" content="width=device-width, initial-scale=1, interactive-widget=resizes-content">` — липкая
  кнопка «Оставить заявку» не прячется под клавиатурой телефона; проверить на iPhone (tproger_web/6596).
- Shopify теперь стримит начало страницы (первый байт на 29% быстрее): стили и `preload` шрифтов в `theme.liquid`
  поставить рядом с `content_for_header`, замерить PageSpeed (tproger_web/6597) — для её магазина.
- `<mermaid-element>` — схемы текстом в HTML («как идёт монтаж», питчи) (tproger_web/6594).
- Eruda — консоль на телефоне, только на тестовой копии (sitodel/3932); `python -m http.server 8000` — открыть вёрстку на
  телефоне по Wi-Fi (CodeGuard Python/1040).
- Анимации: motion + motion-dev-animations-skill, иконки LottieFiles (ai4svoi/163, free_republic_ai/560); 475 промптов
  анимаций (TochkiNadAI/2721), анимации текста (/2659).
- Colorblind Filter — проверить сайт и красно-зелёные статусы дашбордов (its_capitan/603).
- Иллюстрации интерфейсов для статей — верстать на React по образцу, не скриншоты (molyanov_blog/5107); видео и
  скринкасты кодом в Remotion + голос ElevenLabs (molyanov_blog/5076, 5059).
- Картинки установок без съёмки: слова cutaway, exploded view, x-ray, blueprint (ii_papka/999) — через AI Horde.

## Форма заявки и цели
- «Заявка принята» — только после ответа сервера; три состояния: отправляется / принято (когда перезвоним) / ошибка и
  запасной путь (TexterraBlog/12089).
- Цель «заявка» в Метрике — только после серверной проверки на бота (скрытое поле-ловушка, время заполнения), иначе боты
  портят обучение Директа (boringmarketer/1335).
- Мягкие следующие шаги в каждом разделе («расчёт под ваш объект», чек-лист по осушению бассейна) вместо одной агрессивной
  кнопки; замер в Метрике (TexterraBlog/12043).
- Если будет чат-бот — на виду кнопка «к инженеру» (TexterraBlog/12095).

## Тексты и структура

  «что потребуется от вас» (marketingmass/1319, 1337).

- Типограф Лебедева + Главред: «ёлочки», длинные тире, неразрывные пробелы, штампы — прогнать все тексты (copywritersdigest/4967);
  признаки ИИ-текста — Sepia (projplus/4837), промпты NeuroLuv/1763, 1781 → вместе с no-ai-slop.
