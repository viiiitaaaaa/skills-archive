# Product Style Curation

## Когда применять
Пользователь даёт папку/выгрузку с фото товаров (обычно десятки файлов без категорий) и просит собрать из них небольшой набор (4–5 шт.), который выглядит стильно и "органично" вместе — то есть по факту работу дизайнера-байера: увидеть материал, цвет, фактуру каждого товара и собрать композицию, а не идти по формальным категориям "кухня"/"ванная".

Если пользователь прикладывает PDF/текст с промтами для генерации интерьеров (например список стилей 2025–2026: Warm Minimalism, Organic Luxe, Color Drenching, Heritage Maximalism, Modern Mediterranean, Neo-Japandi, Quiet Luxury 2.0, Sculptural Contemporary, Dark Academia, Eclectic Collector's Interior) — используй описанную там палитру и материалы как словарь для оценки соответствия товаров стилю.

## Шаги

1. **Доступ к папке.** Если папка на компьютере пользователя не подключена — запросить через `device_request_folder_access`. Если инструмент отказывает (папка не в разрешённых точках), попросить пользователя подключить её через кнопку "Add folder" в приложении Claude.

2. **Собрать список файлов.** `device_list_dir` с `recursive: true`, чтобы увидеть все фото и вложенные папки.

3. **Стейджинг.** Загрузить все изображения в рабочее пространство через `device_stage_files` (до 50 файлов за вызов — для больших папок делать несколько вызовов).

4. **Контактные листы вместо поштучного просмотра.** Для папок из 20+ фото не читать каждое изображение по отдельности — это дорого по контексту. Собрать через Python/PIL сетку миниатюр (например 4 колонки × 3 строки на лист, подпись с именем файла под каждой миниатюрой) и сохранить как несколько PNG-листов. Прочитать эти листы через Read — так весь каталог просматривается за 2–3 обращения к инструменту вместо 70+.

5. **Определить язык материалов и цвета.** По контактным листам выписать (мысленно/в рассуждении) для каждого интересного товара: материал (дерево/камень/латунь/стекло/керамика/текстиль/мех), тон (тёплый ореховый, молочный, латунный, серо-оливковый и т.д.), фактуру (глянец/матовость/шероховатость). Цель — найти предметы, которые говорят на одном материально-цветовом языке, а не просто "все деревянные" или "все кухонные".

6. **Собрать сет из 4–5 предметов.** Приоритет — визуальная и материальная когерентность (одна палитра + 2–3 повторяющихся материала, например дерево+латунь+натуральный мех), а не единство категории товара. Разные типы предметов (аксессуар для ванной + зеркало + декор) часто дают более стильный и "насмотренный" результат, чем набор из одной категории.

7. **Определить комнату по результату, а не заранее.** Смотреть, какую функцию выполняет большинство выбранных предметов (гигиена/зеркало → ванная; посуда/подача → кухня-столовая; текстиль/светильники → гостиная и т.д.), и назвать комнату как вывод, а не как отправную точку подбора. Если в исходной папке количественно преобладает другая категория (например банки для кухни), явно отметить это отдельно от итогового набора — это не противоречие, просто в папке больше предложений одного типа, а не то, что этот тип лучше сочетается.

8. **Оформить результат.**
   - Скопировать выбранные файлы в новую подпапку с говорящим названием (например `Подборка — Ванная (Organic Luxe)`), с порядковыми префиксами и короткими описаниями в имени файла.
   - Отправить файлы через `SendUserFile`, получить `file_uuid` для каждого.
   - Записать их обратно на устройство пользователя в новую подпапку через `device_commit_files` (той же родительской папки, откуда взяты исходники).
   - В тексте ответа — короткое прозаическое обоснование (без длинных списков): почему предметы сочетаются по материалу/цвету, и явный вывод по комнате.

## Частые ошибки, которых нужно избегать
- Не собирать набор только по формальной категории ("все из кухни") — вместо этого искать предметы, которые реально стилистически резонируют.
- Не читать десятки отдельных изображений подряд — использовать контактные листы.
- Не выдавать длинный маркированный список с описанием каждого товара в финальном ответе — обосновывать выбор компактной прозой, как того требует стиль общения.
- Не забывать сохранить результат физически (новая подпапка + запись на устройство), если пользователь просит "сформировать в отдельную папку".
