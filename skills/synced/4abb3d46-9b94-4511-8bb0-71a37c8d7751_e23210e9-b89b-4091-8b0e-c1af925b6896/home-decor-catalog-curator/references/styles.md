# Финальный список стилей (тегов) и промты для генерации визуала

Утверждённый список из 17 стилевых тегов, сведённый из референсов заказчика на Pinterest (близкие/повторяющиеся варианты объединены в один тег с общей палитрой). Это закрытый список для тегирования товаров — **не придумывай новые стили с нуля**; если новый референс явно не подходит ни под один пункт, см. правило в конце файла.

По каждому стилю: название (RU/EN), палитра, материалы, подходящие комнаты, и три готовых промта для генерации изображений — под каждый из 3 типов сетов (комнатный / категорийная коллекция / мини-сет). Промты на английском (стабильнее работают генераторы изображений: Midjourney, DALL-E, Stable Diffusion и т.п.).

## Что делать с новыми референсами, которые не подходят ни под один из 17 стилей

Такое возможно — список закрыт, но не окончательно заморожен. Если новый Pinterest-референс явно не ложится ни в одну палитру/материал/настроение из списка выше (не просто "чуть другой оттенок", а другая эстетика в целом) — не пытайся насильно распихать его по существующим тегам. Предложи пользователю это как кандидата на 18-й тег: дай рабочее название, палитру и материалы по аналогии с форматом выше, и спроси подтверждение, прежде чем добавлять в этот файл.
