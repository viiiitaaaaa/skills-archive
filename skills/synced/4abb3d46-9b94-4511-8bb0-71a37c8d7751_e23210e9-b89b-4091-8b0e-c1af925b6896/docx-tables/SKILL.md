# Таблицы в .docx без «съезжания»

Применяется вместе со скиллом docx при создании любого Word-документа с таблицей: расчёты по ст. 395 / 823 ГК РФ, расчёт убытков, реестры, сметы и т.п.

## Обязательные правила (docx-js)

1. **Фиксированная раскладка таблицы**
   - `layout: TableLayoutType.FIXED`
   - явные `columnWidths: [...]` в DXA (1 см ≈ 567 DXA)
   - `width: { size: <сумма columnWidths>, type: WidthType.DXA }`
   - сумма ширин колонок = ширина текстовой области страницы (A4 с полями 3/1,5 см ≈ 9355 DXA) или меньше.

2. **Явная ширина каждой ячейки**
   - у каждой `TableCell`: `width: { size: <ширина её колонки>, type: WidthType.DXA }`
   - ширина ячейки должна совпадать с соответствующим значением в `columnWidths`. Без этого Word пересчитывает ширины сам, и таблица «съезжает».
   - для объединённых ячеек (`columnSpan`) ширина = сумма объединённых колонок.

3. **Строки не разрываются между страницами**
   - у каждой `TableRow`: `cantSplit: true`
   - у строки-шапки дополнительно `tableHeader: true` (повтор шапки на новой странице).

4. **Шапка не отрывается от тела**
   - если таблица не помещается целиком на текущей странице, ставить разрыв страницы перед заголовком таблицы (`pageBreakBefore: true` у абзаца-заголовка), либо `keepNext: true` у заголовка и абзацев перед таблицей.

5. **Числа и выравнивание**
   - суммы выравнивать по правому краю, формат `13 278 000,00` (неразрывный пробел между разрядами, запятая как десятичный разделитель).
   - итоговая строка — жирным.

## Чек-лист перед отправкой файла

- [ ] У таблицы есть `layout: FIXED`, `columnWidths` и общая `width` в DXA.
- [ ] У каждой ячейки есть `width`, и она совпадает с шириной колонки.
- [ ] У каждой строки есть `cantSplit: true`, у шапки — `tableHeader: true`.
- [ ] Шапка таблицы не оказывается одна внизу страницы (при необходимости стоит разрыв страницы).
- [ ] Сумма ширин колонок не больше ширины текстовой области.
- [ ] Арифметика в таблице пересчитана программно (суммы по строкам = итог).
- [ ] Файл сконвертирован в PDF (LibreOffice) и просмотрен постранично, чтобы проверить, что таблица не разъехалась и не разорвана.
