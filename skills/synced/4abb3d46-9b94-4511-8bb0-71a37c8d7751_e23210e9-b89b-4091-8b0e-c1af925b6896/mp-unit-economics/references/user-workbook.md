## Рабочий цикл пользователя

Так она закрывает период — понимать это важно, иначе можно сломать историю:

1. Вставляет четыре свежих отчёта в листы-приёмники
2. Лист `1` пересчитывается, итоги встают в **строку 166**
3. Копирует лист `1` и сохраняет как архив с именем периода (`01.07.2026-31.07.2026`), **вставляя только значения** — формул в архиве нет
4. Дашборд `Динамика финансы` тянет строку 166 из архивных листов и из листа `1`

Отсюда два жёстких требования:

- **Дашборд адресует строку итогов напрямую** (`='1'!$H$192`). Никаких `insert_rows` на листе `1` и на архивных листах: сдвиг обнулит дашборд. Если строки всё же нужно добавить — только по процедуре из SKILL.md, с последующей перенастройкой всех 18 формул дашборда.
- **Архивные листы не пересчитываются.** Там значения, а не формулы. Правки формул к ним не применяй — они уже закрытая история.
