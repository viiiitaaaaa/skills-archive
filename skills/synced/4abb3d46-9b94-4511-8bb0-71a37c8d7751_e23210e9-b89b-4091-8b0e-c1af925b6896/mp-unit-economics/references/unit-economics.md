# Формулы юнит-экономики

Колонки ниже — из реальных файлов пользователя. Если в конкретном файле раскладка другая, сохраняй его раскладку: пользователь на неё смотрит каждую неделю и мог настроить дашборд на конкретные адреса.

## Сводная (лист-агрегатор)

Столбец A — артикулы, дальше по одному столбцу на показатель. Все диапазоны через ДВССЫЛ.

### Wildberries

Источник — Sheet1: `F` артикул, `K` обоснование, `N` кол-во, `O` цена, `P` реализовано, `AH` к перечислению, `AK` логистика.

| Столбец | Показатель | Формула |
|---|---|---|
| B | КОЛ ПРОДАЖ | `СУММЕСЛИМН(ДВССЫЛ("Sheet1!N:N");ДВССЫЛ("Sheet1!F:F");$A4;ДВССЫЛ("Sheet1!K:K");"Продажа")` |
| C | КОЛ ВОЗВРАТ | то же, условие `"Возврат"` |
| D | ВЫРУЧКА ПРОДАЖ | сумма по `O`, условие `"Продажа"` |
| E | ВЫРУЧКА ВОЗВРАТ | сумма по `O`, условие `"Возврат"` |
| F | РЕАЛИЗ ПРОДАЖ | сумма по `P`, условие `"Продажа"` |
| G | РЕАЛИЗ ВОЗВРАТ | сумма по `P`, условие `"Возврат"` |
| H | К ПЕРЕЧИСЛ ПРОДАЖ | сумма по `AH`, условие `"Продажа"` |
| I | К ПЕРЕЧИСЛ ВОЗВРАТ | сумма по `AH`, условие `"Возврат"` |
| J | ЛОГИСТИКА | сумма по `AK`, **без условия на K** |

### Ozon

Источник — Начисления: `C` группа, `D` тип, `E` артикул, `H` кол-во, `I` цена, `P` сумма.

| Столбец | Показатель | Условия |
|---|---|---|
| B | КОЛ ПРОДАЖ | `H` где группа `Продажи` и тип `Выручка` |
| C | КОЛ ВОЗВРАТ | `H` где группа `Возвраты` и тип `Возврат выручки` |
| D | ВЫРУЧКА ПРОДАЖ | `I`, те же условия что B |
| E | ВЫРУЧКА ВОЗВРАТ | `I`, те же условия что C |
| F | РЕАЛИЗ ПРОДАЖ | `P`, те же условия что B |
| G | РЕАЛИЗ ВОЗВРАТ | `P`, те же условия что C |
| H | КОМИССИЯ | `P` где группа `Вознаграждение Ozon` |
| I | ЛОГИСТИКА | `P` где группа `Услуги доставки` |
| J | РЕКЛАМА | `F` из листа **Реклама** по `B` (название кампании = артикул) |
| K | ХРАНЕНИЕ | `L` из листа **Хранение** по `C` (артикул) |

Реклама и хранение приходят отдельными отчётами — в начислениях рекламы по артикулам нет.

## Юнит-экономика: Wildberries

Столбцы листа статистики (A — артикул):

```
B  Остатки              ← Export, ИНДЕКС/ПОИСКПОЗ по артикулу
C  Дней до обнуления    ← Export
D  Себестоимость 1 ед   ← лист Себестоимость
E  Кол продаж           ← сводная
F  Кол возвратов        ← сводная
G  Чистые продажи       = E - F
H  Выручка продаж       ← сводная
I  Выручка возвратов    ← сводная
J  Чистая выручка       = H - I
K  Реализ продажа       ← сводная
L  Реализ возврат       ← сводная
M  Реализ чистое        = K - L
N  К перечисл продажа   ← сводная
O  К перечисл возврат   ← сводная
P  К перечисл чистое    = N - O
Q  Себестоимость продаж = G * D
R  Комиссия, руб        = J - P
S  Комиссия, %          = R / J
T  Логистика            ← сводная
U  Хранение             ← Export
V  Реклама              ← Export
W  НДС 5%               = P * 0,05
X  База УСН             = P - W
Y  Налог 6%             = X * 0,06
Z  Налоги всего         = W + Y
AA ПРИБЫЛЬ              = J - Q - R - T - U - V - Z
```

Показатели на единицу (делить на `G`, чистые продажи):

```
AB Выручка на 1 ед      = J / G
AC Себестоимость 1 ед   = D
AD Комиссия на 1 ед     = R / G
AE Логистика на 1 ед    = T / G
AF Реклама на 1 ед      = V / G
AG Прибыль на 1 ед      = AA / G
AH Маржинальность, %    = AG / AB
AI Рентабельность, %    = AG / AC
AJ Себес остатков       = B * D
AK Прибыль остатков     = AG * B
```

Все деления оборачивай в ЕСЛИОШИБКА — у артикулов без продаж `G = 0`.

## Юнит-экономика: Ozon

```
B  Остатки              ← Остатки!J по Остатки!D
C  Дней до конца остатка← Остатки!X
D  Себестоимость 1 ед   ← лист Себестоимость
E  Кол продаж           ← сводная
F  Кол возвратов        ← сводная
G  Чистые продажи       = E - F
H  Выручка продаж       ← сводная
I  Выручка возвратов    ← сводная (отрицательная!)
J  Чистая выручка       = H + I      ← ПЛЮС, не минус
K  ОЗ реализ продажа    ← сводная
L  ОЗ реализ возврат    ← сводная
M  ОЗ реализ сумма      = K + L
N  Себестоимость продаж = G * D
O  Комиссия             ← сводная (отрицательная)
P  Комиссия, %          = O / J
Q  Логистика            ← сводная (отрицательная)
R  Хранение             ← сводная
S  Реклама              ← сводная (из ListExpense)
T  Доп услуги           = распределение по количеству
U  НДС 5%               = M * 5 / 105
V  База УСН             = J - U
W  Налог 6%             = V * 0,06
X  УСН + НДС            = U + W
Y  ПРИБЫЛЬ              = J - N + O + Q - R - S - T - X
```

Обрати внимание на знаки в формуле прибыли: комиссия и логистика приходят из Ozon **отрицательными**, поэтому они прибавляются. Хранение, реклама и доп услуги — положительные, вычитаются.

НДС у Ozon считается «изнутри» суммы реализации (`M * 5 / 105`), а не сверху, как у WB.

### Доп услуги

Всё, что не попало в пять основных групп: услуги партнёров, FBO, обработка отправлений, штрафы, эквайринг. К артикулам не привязано, поэтому считается общей суммой и распределяется по количеству:

```
T{строка} = (T{итог} / G{итог}) * G{строка}
```

Общая сумма (в строке итогов):

```
= -(СУММЕСЛИМН(P;P;"<>0")
    - СУММЕСЛИ(C;"Продажи";P)
    - СУММЕСЛИ(C;"Возвраты";P)
    - СУММЕСЛИ(C;"Вознаграждение Ozon";P)
    - СУММЕСЛИ(C;"Услуги доставки";P)
    - СУММЕСЛИ(C;"Продвижение и реклама";P))
```

### Двойной счёт хранения — проверяй обязательно

Хранение приходит **двумя путями**: отдельным отчётом о стоимости размещения и внутри начислений как `Услуги FBO | Размещение на складе`. Если тянуть его в свою колонку и при этом не исключить из доп услуг, оно вычтется из прибыли дважды.

Симптом: прибыль занижена ровно на сумму хранения, при этом ошибок формул нет и сводная сходится с отчётом — расхождение видно только при сверке прибыли с дашбордом.

Исключай его из формулы доп услуг по **типу начисления**:

```
- СУММЕСЛИМН(P; D; "Размещение на складе")
```

Та же логика для любого показателя, который выносится в отдельную колонку из отдельного отчёта: вынес — исключи из доп услуг. Проверить просто — разложи прочие группы по типам начисления и убедись, что ни один тип не учтён дважды:

```python
MAIN = {'Продажи','Возвраты','Вознаграждение Ozon','Услуги доставки','Продвижение и реклама'}
for r in range(3, ws.max_row+1):
    g, t = ws.cell(row=r, column=3).value, ws.cell(row=r, column=4).value
    if str(g) not in MAIN:
        buckets[f"{g} | {t}"] += ws.cell(row=r, column=16).value or 0
```

### Переменные расходы вне юнита

Часть начислений имеет смысл считать отдельно и **не включать в юнит по артикулам** — они не привязаны к товару и искажают экономику единицы: кросс-докинг, баллы за отзывы, ускоренный сбор отзывов.

Если пользователь просит их вынести — исключи соответствующий тип начисления из формулы доп услуг и покажи отдельным блоком со своей строкой итога, плюс строку «Прибыль с учётом переменных расходов». В юнит-экономику по артикулам они при этом не попадают.
