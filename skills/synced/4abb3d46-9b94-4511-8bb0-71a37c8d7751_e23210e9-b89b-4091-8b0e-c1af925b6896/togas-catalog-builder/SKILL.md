# Каталог по тональным коллекциям из выгрузок 1688

Превращает сырые выгрузки 1688采购助手 в готовый каталог: коллекции, собранные по материалу и тону, с фото внутри xlsx и экономикой на формулах.

## Железные правила

Каждое выведено из провала на реальном проекте. Нарушишь — переделывать всё.

**Названию товара на 1688 верить нельзя.** В заголовке будет «чёрный поднос», а на фото — кремовая салфетница или рекламный коллаж распродажи. Цвет в заголовках почти не указан: на 161 позиции постельного белья слово «серый» встретилось ноль раз, «белый» — один. Тон определяется **только по изображению**. Отбор по ключевым словам в названии — главная причина того, что коллекция разваливается.

**Картинки уже лежат внутри файла.** Выгрузки 采购助手 содержат `xl/media/*.png`, привязанные к строкам через `xl/drawings/drawing1.xml`. `pandas.read_excel` их не видит и молча пропускает — из-за этого легко решить, что фото нет, и полезть в сеть. Сеть не нужна и не сработает: CDN Alibaba (`cbu01.alicdn.com`) не в списке разрешённых доменов, отдаёт 403. Извлекай из архива, см. `scripts/extract_images.py`.

**Если в выгрузке нет `xl/media`, останавливайся.** Значит файл собран не через 采购助手, а вручную или другим экспортом — там только ссылки. Разложить по тону такое нельзя. Скажи пользователю прямо и попроси перевыгрузить через 采购助手, а не подбирай по названиям «пока что».

**`=IMAGE(url)` — не решение.** Работает только в Excel 365 и Google Sheets; в LibreOffice и Excel 2019 даёт `#NAME?` по всей колонке. Вставляй настоящие объекты через `openpyxl.drawing.image.Image`.

**Превью обязательно уменьшать.** 613 оригиналов из выгрузок весят 133 МБ. Ресайз до 110 px даёт файл на 300–500 КБ при том же виде на экране. Оригиналы сохраняй отдельно — пригодятся для карточек сайта.

**Проверяй результат глазами, а не цифрами.** После каждого отбора собирай контактный лист — все картинки коллекции в один ряд, коллекции друг под другом — и смотри на него через `view`. Средняя светлота может быть идеальной, а в ряду будет торчать красный чайник. Ожидай 3–5 итераций фильтров, это норма.

**Дели, а не растягивай.** Если после фильтров в коллекции осталось меньше 7 позиций — это ответ, а не проблема. Ослабление порога вернёт туда чужеродные вещи, и пользователь их заметит. Скажи, что материала не хватает, и предложи выбор: чистота ряда или его длина. Коллекцию, где подходящего меньше 7, честнее убрать целиком.

## Порядок работы

### 1. Извлечь и промерить

`scripts/extract_images.py` вытаскивает картинки и сопоставляет с 商品ID. `scripts/tone_metrics.py` считает по каждой четыре числа. Все — по **центральному кропу 25–75%**, потому что по краям фон, а не товар:

| Метрика | Что значит | Как применять |
|---|---|---|
| `clum` | светлота предмета, 0–255 | тёмная коллекция < 140, светлая > 175 |
| `cwarm` | теплота, R минус B | тёплая коллекция > 12, нейтральная от −8 до 10 |
| `csat` | насыщенность | > 25 — принт, роспись, цветной пластик |
| `banner` | доля кислотных пикселей на всём кадре | > 0.01 — рекламная плашка или коллаж |

`banner` — единственное, что считается по полному кадру: баннер обычно лепят по краю.

### 2. Отсеять мусор

По названию, до всякого тона:

```
清仓|特价|系列|多款|混批|批发价|款式随机|详情页|专拍|补差价|礼盒|定制
卡通|可爱|儿童|宝宝|动物|印花|彩绘|图案|花朵|波西米亚|民族|绣花|荷叶边|公主
```

Плюс `csat < 25` и `banner < 0.01`. На типичной выгрузке проходит 25–35% позиций — это нормально и правильно.

### 3. Набрать коллекции

Коллекция = **один материал + один тональный диапазон**, названная по камню или материалу: Обсидиан, Травертин, Каррара, Куойо (кожа), Ноче (дерево), Аурум (латунь), Люмен (свечи), Менса (сервировка). Внутри — 10–14 позиций, отсортированных по годовым продажам.

Товарные категории, которые ложатся в одну коллекцию: наборы для ванной, дозаторы, салфетницы, подносы, полотенца, постельное, подсвечники, бра из того же камня. Материал держит ряд, а не тип предмета.

### 4. Собрать xlsx

Три листа. **Параметры**: курс, логистика, прочие расходы, коэффициент розницы, комиссия — жёлтые редактируемые ячейки, всё остальное на них ссылается. **Ассортимент**: коллекция, артикул, фото, наименование, тип, материал, цена ¥, закупка ₽, себестоимость, розница, прибыль, маржа, продажи, повторные покупки, поставщик, город, ID, ссылка. **Коллекции**: свод через `SUMIF`.

Заливка строки = тон коллекции: Обсидиан `33302D` белым текстом, Травертин `EDE0CB`, Каррара `F1F1EE`, Куойо `C9AE93`, Ноче `B9A48C`, Аурум `EBD6A6`, Люмен `DAE2E0`, Менса `EFE6DA`. Та же заливка дублируется на листе «Коллекции».

Наименования — по-русски, с итальянским именем собственным в кавычках-ёлочках: «Дозатор для мыла „Кассий“» → `Дозатор для мыла «Кассий»`. Тип предмета определяется по китайскому заголовку, список соответствий в `references/naming.md`.

Только формулы, никаких посчитанных в Python чисел. После сборки обязательно `recalc.py`, ошибок должно быть ноль.

### 5. Показать и назвать риски

Всегда проговаривай:
- **регионы отгрузки** — считай города поставщиков; каждый новый регион это отдельная консолидация (аксессуары Чжуншань и Чаочжоу, постельное Наньтун, полотенца Гаоян, свет Чжуншань и Шэньчжэнь);
- **габариты** — плоская ставка логистики на позицию занижает себестоимость постельного и полотенец в разы против салфетниц;
- **что не влезло** — категории, где подходящего меньше 7 позиций, и почему.

## Чего в выгрузках 1688 обычно не хватает

Керамика Чаочжоу почти вся расписная. Светильники Чжуншаня — современный LED, к вещевой эстетике не идут; годятся только из камня и латуни, их единицы. Ищи не по типу предмета, а по материалу: 洞石 (травертин), 云石 (оникс), 全铜 (латунь), 长绒棉 (длинноволокнистый хлопок), 华夫格 (вафельное плетение).

## Ресурсы

- `scripts/extract_images.py` — картинки из выгрузок → папка + карта商品ID
- `scripts/tone_metrics.py` — четыре метрики по каждому фото
- `scripts/contact_sheet.py` — контактный лист коллекций для визуальной проверки
- `references/naming.md` — типы предметов по китайским заголовкам, имена для коллекций
- `references/workbook.md` — структура листов, формулы, палитра заливок
