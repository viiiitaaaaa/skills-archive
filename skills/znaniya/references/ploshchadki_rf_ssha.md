## Главное (читала сами статьи, WebFetch 23.10)
- Мысль источников: не «или-или». Площадка = быстрые покупатели, но 30–50% выручки уходит (Amazon) и правила чужие; свой сайт = маржа,
  бренд, база клиентов (Shopify 3,5–5,5% затрат, DTC валовая маржа 40–60% при недорогом трафике). Лучшие используют оба по этапам.
- РФ (INFOLine, I кв. 2025): маркетплейсы 64,5%, независимые 33,8% (прогноз 2030: 28–35%); 59% горожан покупали и в независимых;
  при равных условиях 34% выбрали бы независимый, 29% маркетплейс, 35% по ситуации (Data Insight + Яндекс Пэй). Свои сайты держатся на
  уникальном ассортименте и своей марке.
- США (eCommerce Fastlane, цифры самой статьи): онлайн 1,2 трлн $ (2025) → 1,38 трлн (2026); Amazon ~35,7%, Shopify 14% (было 12%),
  вместе ~50% (2021: 43%); Amazon-расходы продавца 30–50%; Amazon-реклама 68 млрд $; Nike вернулся на Amazon (май 2025).
- Marketplace Pulse (статья 2021 г.! Amazon-маркетплейс ~25%, Amazon 41% по eMarketer): Amazon сам задаёт правила — довод не зависеть от одной площадки.
- Для нас: РФ-юбки 1688 → площадки (комиссия Ozon 48–54%); США → свой сайт Shopify + реклама, Amazon вторым каналом позже; считать LTV/CAC.
- Агентная торговля (ИИ-помощники покупают): данные о товарах делать структурными. Shopify уже даёт UCP / Shop MCP / Checkout MCP (shopify.dev/changelog).
