# Новости из Telegram (команда «новости»)

Папка: `C:\Users\User\tg_monitor`. Python — системный `python` (C:\Python314), библиотеки requests/bs4/lxml стоят.
Панель: артефакт «Рабочая панель» https://claude.ai/artifact/9mbsDoDoHmQg5ZyXGK368R

## Правила пользователя

- Команда «новости» = весь цикл сразу, без лишних вопросов: сбор → разбор → панель → открыть.
- **Старые новости не удалять.** База `tg_monitor.db` только пополняется; панель показывает
  последние 45 дней (`WINDOW_DAYS`), минимум месяц. Пересказы в `notes.json` не стирать.
- Дата и время обновления — в шапке панели (ставится автоматически).
- Автосбор — только задача TG_Monitor раз в день (решение 23.09); других расписаний не ставить.
- Объяснять по-русски, просто.

## Шаги

1. `cd C:\Users\User\tg_monitor; $env:PYTHONIOENCODING='utf-8'; python news.py`
   — собирает новые посты (догоняет пропуски до 31 дня назад, листая страницы t.me/s/),
   строит `news_panel.html` и печатает «НУЖЕН РАЗБОР» — новые посты без пересказа.
   Вывод длинный: читать сохранённый файл целиком.
1б. **Дочитать через Telegram Web** (решение 23.09: API my.telegram.org не выдаёт ключ, «ERROR» двое суток).
   Сайт t.me/s прячет часть постов (статьи rich_message, опросы, кружки) и закрытые каналы anita_bold, moda_po_sprosu.
   - `python tg_web_import.py --plan` → список `[канал, minId]`;
   - в фоне `python tg_web_import.py --serve` (ждёт один POST на 127.0.0.1:8765 и выходит);
   - в Chrome (claude-in-chrome): `tabs_context_mcp` → новая вкладка `https://web.telegram.org/k/`, пользователь там
     уже вошёл. Вставить через `javascript_tool` текст `tg_web_reader.js` (функции объявлять как `window.имя = …`),
     затем `await tgWebSync(<план>, 31)` → «база: новых N, дочитано скрытых M». Больше 45 с — запускать без await,
     результат в `window.__sync`, проверять повторно.
   - Личные чаты не открывать и не читать — только история каналов из channels.txt.
   - Если Telegram Web не залогинен — сказать пользователю, вход делает только она.
1в. **Чат shopify_chat** (решение 23.09: важные вопросы сразу с ответами). Чат через t.me/s не читается —
   тем же Telegram Web: `--serve`, затем в вкладке вставить `readChat` из `tg_web_reader.js` и `await readChat("shopify_chat", 45)`
   → таблица `chat_msgs` (msg_id, date, text, reply_to). Разбор: собрать ветки «вопрос → ответы», важное для нас (LLC/EIN,
   платёжки, Shopify Payments, выплаты, баны GMC/магазина, реклама, поставщики/AutoDS) записать в notes.json ключом
   `shopify_chat/<id вопроса>`: `{"cat": "chat", "headline", "summary", "for_us", "replies": [id ответов], "extra_roots": [id похожих вопросов]}`.
   Спам «напишите в лс», копипаст из ChatGPT и рекламу услуг в replies не брать. Панель показывает блок «чат — важное с ответами».
1г. **Чат vibecoding_community** (решение 24.09: та же логика, тема — вайбкодинг). `await readChat("vibecoding_community", 45)`,
   ключи `vibecoding_community/<id вопроса>`, тот же формат `cat: "chat"`. Важное: Claude Code/агенты/скиллы/MCP, лимиты и
   тарифы, деплой, боты, автоматизация магазина и парсинга — то, что реально пригодится нам. Список чатов — `CHATS` в news.py.
2. Разобрать каждый новый пост в `notes.json` (ключ `"канал/номер"`), дописывая, не перезаписывая:
   - `biz` — Shopify, дропшиппинг, маркетплейсы, тренды, реклама, платёжки, поставщики;
   - `tool` — Claude Code, агенты, модели, инструменты, которые реально пригодятся;
   - `soft` — продажа услуг/партнёрств, фон, для сведения;
   - `skip` — реклама, пустые посты, дубли (в базе остаются, на панель не идут);
   - `course` — только для slivaker_it: курс пересекается с нашими задачами → зелёная карточка
     в «Свежих курсах», в `for_us` одна фраза «зачем». Остальные курсы канала показываются сами
     (разбор «Название / Размер: / Цена:»), их помечать `skip`.
   Ленты всех постов на панели нет (пользователь убрала 22.09) — только «Главное» и курсы.
   **Установленное из новостей помечать всегда** (просьба пользователя 22.09): когда ставим скилл,
   MCP или репозиторий с GitHub из поста — в notes.json этого поста дописать
   `"tool": "короткое имя", "installed": "дата — что и куда поставили, ссылка"`; если решили не ставить —
   `"declined": "причина"`. На карточке появится зелёная «✓ Установлено» / серая «Не ставили»,
   а в шапке панели — строка «Из новостей установлено: …» (берётся из всех заметок, не только за 45 дней).
   Формат: `{"cat", "headline", "summary": [абзацы], "for_us": "что это значит для нас"}`.
   В тексте `код` в обратных кавычках станет `<code>`. Одинаковый пост в двух каналах —
   пересказ одному, второму `skip`. Громкие заявления каналов (новые модели и т.п.) подавать как
   «канал пишет», не как факт.
   Удобно: python-скрипт в scratchpad, который грузит notes.json, делает `update(new)` и
   `setdefault(key, {"cat": "skip"})` для остальных новых постов (`scraped_at >= last_collect_started`
   из `panel_state.json`).
   **Модные каналы** (`TREND_CHANNELS` в news.py) идут НЕ в панель новостей, а в раздел
   «Мода — ориентиры» дашборда радара (решение 23.09: мода нужна только как ориентир для радара трендов, не смешивать
   с дропшиппингом и ИИ). В заметке модного поста дописывать `"radar": ["фраза, как ищут в США", …]`
   и `"themes": ["шоколадный", "мех", …]` — из них страница собирает «Что повторяется» и «Проверить в радаре».
   Реклама, розыгрыши, «оцените образ» — skip.
3. `python news.py --build` — пересобрать панель с пересказами (заодно пересобирается `fashion_panel.html`).
4. **Всегда** открыть свежую локальную копию `Start-Process C:\Users\User\tg_monitor\news_panel.html`
   (у пользователя просмотрщик claude.ai часто показывает старую копию — решение 23.09), затем опубликовать
   `news_panel.html` в Artifact с `url` панели (выше), без `icon`, и открыть его.
   **Мода — раздел «Мода — ориентиры» в дашборде радара трендов** (решение 23.09: соединить страницы).
   `news.py --build` пишет `fashion_data.json`; затем пересобрать и опубликовать радар:
   `cd C:\Users\User\fashion-trend-radar\fashion-trend-radar; .venv\Scripts\python.exe build_dashboard.py --open`
   → Artifact https://claude.ai/artifact/7XN5rKYANe4QX8HwRHKNZF. Отдельную страницу моды (YJuHzoABX1RT98tBBLzWSU)
   больше не публиковать.
5. Коротко в чате: сколько новых постов, 3–5 главных новостей одной строкой каждая, ссылка.
   В конце — **одно напоминание** из списка «Когда будет время» скилла dropship-lessons (по очереди, сверху вниз;
   сделанное там вычёркивается с датой). Если она отмечает на панели «Для нас: …» как урок — дописать его
   в dropship-lessons в нужный раздел с источником (решение 27.09).

Разбирать не слишком строго (замечание 27.09 «мало новостей»): skip — только реклама, розыгрыши, мемы, пустые посты
и дубли; ИИ, Python, научные посты и фон — хотя бы `soft` одной строкой. Из чатов — 5–10 содержательных веток за
каждый день, в том числе без ответов. Перед записью сверять с уже разобранным, чтобы не дублировать карточки.

## Грабли

- **В Планировщике Windows есть задача «TG_Monitor»** (`tg_monitor.py`; с 23.09 по просьбе пользователя — раз в день в 9:00,
  чаще не ставить) — она тоже пишет посты в базу.
  23.09 из-за неё 15 постов за день не попали в разбор. Исправлено в news.py: «нужен разбор» = любой пост за 45 дней
  без заметки в notes.json (кто бы его ни собрал); «новое» = в базе после прошлой команды «новости» (+15 мин).
  Всё старше 23.09 помечено skip как просмотренное.

- **Посты «пустые» на сайте часто на самом деле скрыты** («Please open Telegram to view this post»). 23.09 так потерялось
  руководство Anthropic по Opus 5.5 (vibecoding_tg/3930), а всего таких было 15 из 16 «пустых». Сборщик теперь пишет в текст
  такого поста `tm.HIDDEN`, панель показывает блок «Не прочитала — откройте в приложении». Такие посты НЕ помечать skip:
  спросить у пользователя текст или оставить ссылку в блоке.
- anita_bold и moda_po_sprosu закрыты для t.me/s — с 23.09 читаются только шагом 1б (Telegram Web).
- Telegram Web: номер поста = `data-mid − 2^32`; прокрутка через JS не подгружает историю — поэтому читалка
  берёт историю через встроенный клиент `rootScope.managers.apiManager.invokeApi("messages.getHistory")`.
  Части альбомов (`grouped_id` без текста) пропускаются. В первый раз Chrome спросил разрешение на доступ
  к локальной сети — пользователь его дала.
- `python -c "..."` с кавычками внутри ломается в PowerShell — писать скрипт в scratchpad.
- PowerShell 5.1 `Get-Content | Set-Content` портит кириллицу — файлы править только Edit/Write.
