## «8-Figure Ecommerce Engine» (1)


### Новости, данные, Claude Code

- **Слияния и поглощения как сигнал.** Отмечать в новостях сделки покупки e-commerce-брендов: что покупают и почему — понимать, что ценится рынком — при разборе новостей. (гл. 10) → tg-news

## Miller «Dropshipping and Affiliate Marketing» (1)


### Новости, данные, Claude Code

- **Не брать каждую новинку.** Новые тренды/инструменты оценивать — брать только подходящие нам (совпадает с правилом новостей «только то, что меняет действие»); при разборе новостей. (гл. 22, стр. 142–143) → tg-news

## Cloud «E-Commerce Business: 3 in 1» (1)


### Новости, данные, Claude Code

- **Фильтр «платные курсы из рекламы».** При разборе новостей пропускать рекламу платных обучений и «гуру» из соцсетей — книга считает их в основном пустыми; первоисточник (документация площадки) важнее; при tg-news. (Кн.3 гл.2) → скилл tg-news

## «How To Successfully Market High-Priced Products» (1)


### Новости, данные, Claude Code

- **Новости о премиуме — фильтр.** В разборе новостей отмечать посты про продажу дорогого (двухшаговые воронки, лидогенерация, работа с возражениями) как «меняющие действие» для Frivent. Зачем — сосредоточить внимание на том, что применимо. Когда — при разборе tg-news. (весь текст) → скилл tg-news

## «Home-Based Business University» (1)


### Новости, данные, Claude Code

- **Фильтр «это инструкция 2016 года?».** При разборе новостей о «секретных схемах» SEO (ссылки с форумов .edu, накрутка ссылок через Fiverr) помечать как устаревшее/опасное и skip. (Affiliate, ч. 45; YouTube, ч. 58) → tg-news

## Disney «The Ultimate LinkedIn Sales Guide» (1)


### Новости, данные, Claude Code

- **Отслеживание сменившихся форматов в новостях.** В разборе Telegram-новостей отмечать, какие форматы постов у конкурентов/каналов дают аномальный охват (как автор поймал видео-волну 2018 г.) — это действие, а не «интересно». (гл. 14, стр. ~163–164) → tg-news

## Moore «Persuasion: The Psychology of Selling» (1)


### Новости, данные, Claude Code

- **Фильтр «манипуляция/гипноз» для новостей.** Посты про «скрытые техники манипуляции, гипноз в продажах» — skip: ей нужны честные приёмы. (ч. 14–20) → tg-news

## Lindsay «Sewing to Sell» (1)


### Новости, данные, Claude Code

- **Следить за изменениями площадок.** Правила площадок меняются быстро — держать каналы/сообщества продавцов Shopify в мониторинге новостей. (стр. 150) → tg-news

## Dahlström «Storytelling in Design» (3)


### Новости, данные, Claude Code

- **Эмоциональная кривая отчёта L/M/H.** В длинных сводках (новости, радар) ставить сильный вывод в начале и в конце, чередуя с «нейтральными» блоками. (гл. 14) → скилл tg-news
- **Карточки контента.** Новости и выводы делать карточками (модуль: заголовок — вывод — действие), чтобы их можно было показать в панели, в боте и в письме без переделки. (гл. 12) → скилл tg-news
- **Подписи не «что», а «что делать».** В панели новостей у каждой карточки — CTA: «применить в …», «отложить», «пропустить». Зачем: «если не знаешь, какого действия ждёшь, — его не будет». (гл. 1, 14) → скилл tg-news
