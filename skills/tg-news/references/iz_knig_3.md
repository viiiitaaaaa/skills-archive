## Котлер «Marketing 4.0» (2)


### Новости, данные, Claude Code

- **Новости: ищем упоминания, а не только посты.** По аналогии с «обсуждают, не обращаясь к бренду»: для tg-news полезно иногда искать по нашим темам (Shopify, 1688, вентиляция бассейнов) не только в подписанных каналах, но и в общем поиске Telegram — там обсуждения, о которых каналы не пишут. Когда: при ревизии источников. (гл. 11, стр. 226) → tg-news
- **Сверка «до/после» источника по двум воронкам.** Для ревизии каналов tg-news считать две доли: сколько постов канала попало на панель (знают → интересно) и сколько — в «принято к сведению» (действие). Так видно «горлышко» канала, как в PAR/BAR. Когда: при ежемесячной ревизии каналов. (гл. 6, стр. 109–117) (дополняет dop №77) → tg-news, noted-news

## Dickey «Mastering Claude AI» (3)


### Тренд-радар и отбор 1688

- **Проверка сборщика на крайние случаи.** Для скриптов 1688, радара и новостей просить проверку: «что будет при пустой выдаче, 0 продаж, капче, обрыве сети, пустом списке?». Это вопрос из ревью кода в книге: «а если список пуст?». Зачем: сборщик не должен молча записывать нули как настоящие данные. (гл. 7, стр. 111, 119) → sourcing-1688, tg-news, claude-code-priemy

### Новости, данные, Claude Code

- **Учебная тревога «сервис лёг» (дополняет dop №45).** Пункт книги «проверить запасные процессы при имитации отказа ИИ». Раз в квартал на один день прогонять процесс по запасному пути: новости — через Telegram Web вместо API; 1688 — через браузер вместо treg. Записать, что сломалось. Зачем: запасной путь, который ни разу не проверяли, в нужный день обычно не работает. (гл. 12, стр. 215) → tg-news, sourcing-1688
- **Слить два шаблона в один свой.** Маркус соединил «матрицу синтеза» и «быструю историю данных» в свою «рамку маркетинговой разведки», лаборатория доктора Чен — в общий шаблон обзора литературы. У нас один шаблон отчёта радара и новостей: что точно известно / что спорно / чего не хватает / 3–5 ключевых чисел / выбросы / что удивило / что нельзя заключить / уверенность (высокая, средняя, низкая). (прил. C, стр. 367–370) → trend-radar, tg-news
