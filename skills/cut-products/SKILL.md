# Нарезка карточек товаров со скринов магазина

Готовый скрипт: `C:\Users\User\.claude\skills\cut-products\cut_products.py`
(рабочая копия лежит рядом со скринами: `C:\Users\User\Desktop\скрины магазинов\cut_products.py`).
**Не пиши нарезку заново — запускай этот скрипт.** Если правишь его, обнови обе копии.

Скрины снимаются скиллом `dolphin-shots`, он же раскладывает их по папкам магазинов.

## Запуск

```powershell
# один магазин
python "C:\Users\User\Desktop\скрины магазинов\cut_products.py" "C:\Users\User\Desktop\скрины магазинов\SANTAYA Official Store"

# все магазины сразу (папка без скринов, но с подпапками -> обходит их все)
python "C:\Users\User\Desktop\скрины магазинов\cut_products.py" "C:\Users\User\Desktop\скрины магазинов"

# без аргумента — берётся папка, где лежит сам скрипт
python "C:\Users\User\Desktop\скрины магазинов\cut_products.py"
```

Прогон по всем магазинам занимает несколько минут — запускай в фоне (`run_in_background`).

## Результат

Вырезки кладутся **в ту же папку**, где лежат исходные скрины, и подписываются именем папки
(= имя магазина): `SANTAYA Official Store-001.png`, `Pro Tools Supply Store-1544.png`.
Нумерация сквозная по страницам, страницы сортируются по числу в имени (2 раньше 10).

Размер вырезки = ширине колонки сетки на скрине: 418, 508 или 387 px — зависит от ширины окна,
в котором снимали. Это нормально.

## Как работает

Карточки товаров лежат ровной сеткой. Скрипт ничего не хардкодит:

1. Колонки — по горизонтальному профилю не-белых пикселей, порог адаптивный
   (`max(0.25, 0.45 * max профиля)`). Адаптивность обязательна: тёмная шапка магазина идёт во
   всю ширину, при фиксированном низком пороге колонки слипаются в одну и нарезка ломается.
2. Ряды фото — по вертикальному профилю заполненности колонок (`ROW_FILL = 0.35`).
3. Берутся только **квадратные** полосы (высота ≈ ширине колонки, допуск `SQUARE_TOL`) —
   так отсекаются шапка, футер, блоки текста, цены и рейтинги.
4. Пустые ячейки (`CELL_MIN_INK`) пропускаются, точные повторы режутся по хэшу 16x16
   (соседние страницы часто перекрываются).
5. Файлы, чьё имя начинается с `<магазин>-`, не берутся как исходники, поэтому повторный
   запуск безопасен — он просто перезаписывает вырезки теми же кропами.

Настройки — константы в начале файла.

## Известные ограничения

- Если на скрине висит всплывающее окно **«Register/Sign in»**, перекрытые им ряды не
  вырежутся (обычно верх первых страниц). Признак: с этой страницы вышло заметно меньше
  карточек, чем с остальных. Лечится только пересъёмкой страницы без диалога.
- В выдачу попадают рекламные баннеры магазина («Custom size», «Exclusive link») — они лежат
  в той же сетке и от товаров технически неотличимы.
- Старые вырезки скрипт не удаляет. Если исходников стало меньше, лишние файлы с прошлого
  прогона останутся — перед перезапуском чисти:
  `Remove-Item "<папка>\<магазин>-*.png"`.

## Проверка результата

Быстрый контроль — собрать контактный лист из случайных вырезок и посмотреть глазами:
взять по 1-2 файла из каждой папки, ужать до 150 px, склеить в сетку через PIL, прочитать
картинку. Так сразу видно, если сетка где-то съехала и в кроп лезет текст.
