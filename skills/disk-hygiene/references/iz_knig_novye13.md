## Tiago Forte «Building a Second Brain» (4)


### CODE и PARA для нашей системы (скиллы Claude, память, `znaniya`, Диск, бот «Дела», новости, конспекты)

- **Disk-hygiene: «Archive + дата» вместо разбора по одному.** Если разобрать тысячи старых файлов невозможно, перенести всё старое целиком в одну папку «Архив <дата>» и начать с чистого рабочего пространства; всё останется доступным поиском. У автора никто не пришёл жаловаться на «потерянные файлы». Для нас — не удаление, а перенос (удаляет она сама, правило сохраняется). Когда: при разборе `Downloads` и рабочего стола; после — в корень Диска только активные проекты. (гл. 5, стр. 90–95) → disk-hygiene
- **Диск и ПК — одна схема PARA в трёх местах.** Одинаковые названия категорий в папках на ПК (`C:\Users\User\...`), на Диске (`G:\Мой диск\...`) и в заметках/памяти, чтобы проект был «тем же проектом» везде. Сейчас на Диске темы по областям — оставить, но проекты на верхнем уровне вынести в «Проекты». Зачем: не терять нить при переходе между программами. Когда: при следующем разборе Диска. (гл. 5, стр. 76–77, 85–86) → disk-hygiene
- **Рабочий стол и «Загрузки» очищать раз в неделю.** Файлы, нужные проектам, — в папки проектов, остальное — «Архив <дата>». Входит в недельный обзор шагом 3. Зачем: захламлённая среда мешает думать. Когда: еженедельно по её команде. (гл. 9, стр. 189) → disk-hygiene

### Новости, данные, Claude Code и агенты

- **Большие файлы и спецформаты — не в «внешний мозг».** Видео, PSD, тяжёлые xlsx/базы (`tg_monitor.db`) хранить отдельно, в заметках — ссылка и 2 строки. Когда: сохранение результатов сборщиков. (гл. 4, стр. 52) → disk-hygiene
