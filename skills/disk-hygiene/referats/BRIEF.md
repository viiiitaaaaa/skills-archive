# Задание: полный реферат по одной теме

Хозяйка папки просит: по учебным материалам сделать ПОЛНЫЙ реферат на тему, после чего исходники будут удалены,
останется только твой реферат. Значит, реферат обязан заменить собой все исходники: всё полезное из них должно
в нём оказаться. Потеря знания хуже, чем лишняя страница.

## Где материалы
- Список файлов темы: `<work>/manifest.json` → `files["<КОД ТЕМЫ>"]` (пути относительно папки
  учебной папки (путь в задании)).
- Текст каждого документа уже извлечён: `<work>/src/<путь, где "\" заменён на "__">.txt`.
- Расшифровки видео/аудио: `<work>/tr/<путь, где "\" заменён на "__">.txt` (если нет — медиа ещё не расшифровано,
  сообщи об этом в отчёте).
- `.gdoc` / `.gsheet` — локально пустые ссылки. Их текст забирай инструментом Google Drive
  `mcp__claude_ai_Google_Drive__read_file_content` (загрузи его через ToolSearch `select:mcp__claude_ai_Google_Drive__read_file_content`)
  по id из своего задания. gdoc WB-курса НЕ качай — те же тексты есть в docx.
- Картинки (png/jpg) можно посмотреть инструментом Read по исходному пути на G:.
- Если извлечённый текст битый — прочитай исходный файл сам (docx — все w:t из word/document.xml, не python-docx: он теряет списки).
- `<work>` — рабочая папка, путь даётся в задании помощнику.

## Как работать
1. Прочитай ВСЕ файлы темы. Большие — частями (Read с offset/limit). Версии одного документа (v3…v9, «(1)», «_1»)
   — сравни и возьми самую полную, но добавь то, что есть только в старых версиях.
2. Копи конспект по ходу в `<work>/notes/<КОД>.md` (чтобы не держать всё в голове).
3. Напиши итог в `<work>/ref/<КОД>.md`.

## Каким должен быть реферат
- Русский язык, простыми словами, как для новичка; термины расшифровывать в скобках при первом упоминании.
- Структура: `# Название`, короткое «О чём этот реферат и из чего он собран», оглавление, затем разделы `##`/`###`
  по логике предмета (не по порядку файлов). Внутри — все правила, шаги, формулы, цифры, пороги, примеры, ошибки,
  чек-листы, инструменты и сервисы, советы спикеров. Живые кейсы из лекций — кратко, с цифрами.
- Разговорный мусор, приветствия, повторы, реклама курсов — выкинуть.
- В конце: `## Чек-лист / краткая выжимка` и `## Источники` — список исходных файлов, что из каждого взято
  (одна строка на файл; дубли-версии можно группировать).
- Разметка только такая (её переведут в Word): `#`, `##`, `###`, абзацы, списки `- ` и `1. `, таблицы `| a | b |`
  с строкой `|---|---|`, `**жирный**`. Без HTML, без картинок, без кода длиннее 15 строк.
- Объём — сколько нужно, чтобы ничего важного не потерять (для больших курсов это десятки страниц).

## Отчёт (последнее сообщение)
3–6 строк: путь к реферату, сколько разделов/примерно слов, какие файлы не удалось прочитать или они не по теме
(с предложением, куда их отнести).
