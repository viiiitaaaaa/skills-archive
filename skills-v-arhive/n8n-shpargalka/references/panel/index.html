Закладка «Коллекция»

Собирает коллекцию из избранного на витрине одним нажатием: создаёт, публикует, ставит обложку, добавляет в меню и очищает избранное.

Установка один раз: перетащите эту кнопку на панель закладок браузера (Ctrl+Shift+B, если панель скрыта):

♥ Коллекция

Пользоваться: наберите сердечки на витрине, откройте страницу избранного и нажмите закладку. Панель должна быть запущена.

Закладка «Ключи Comfy»

Один раз передаёт панели ключ входа в Comfy Cloud, чтобы пересъёмка фото работала без открытого браузера. Ключ уходит только на этот компьютер, в файл рядом с ключами Shopify.

Установка: перетащите кнопку на панель закладок (Ctrl+Shift+B, если панель скрыта):

⚙ Ключи Comfy

Пользоваться: откройте cloud.comfy.org, войдите, если просит, и нажмите закладку. Появится сообщение «Ключи Comfy сохранены». Панель должна быть запущена.
