# Dolphin{anty}: профили и скрины

Готовые скрипты лежат в `C:\Users\User\dolphin_anty\`. Не пиши их заново — используй.

## Файлы

- `dolphin.py` — клиент Local API: старт/стоп профиля, автопоиск порта, открытие вкладки.
  Класс `DolphinLocal` + функция `start_with_retry(api, profile_id)`.
- `shots.py` — полностраничные скрины страниц магазина AliExpress через профиль с прокси.
- `batch.py` — пакетная съёмка магазинов по списку ссылок из txt, с сохранением прогресса.
- `probe_pagination.py`, `probe_storename.py` — разведка DOM, если вёрстка поменяется.
- `state.json` — прогресс пакетной съёмки (снятые / упавшие ссылки).

## Команды

```powershell
cd C:\Users\User\dolphin_anty

python dolphin.py --check                          # жив ли Local API
python dolphin.py --profile ID --no-automation     # просто открыть профиль
python dolphin.py --profile ID --stop --no-automation   # погасить
python dolphin.py --token JWT --list               # список профилей (Remote API)

python shots.py --profile ID --pages 4             # скрины страниц 1-4 одного магазина
python shots.py --profile ID --url ССЫЛКА1 --url ССЫЛКА2
python shots.py --profile ID --urls-file links.txt --out "C:\путь\папка"

python batch.py --status                           # прогресс: снято / осталось / упало
python batch.py --profile ID --pages 4             # продолжить с места остановки
python batch.py --profile ID --limit 5             # обработать только 5 магазинов
python batch.py --profile ID --retry-failed        # повторить упавшие
```

Скрины: `C:\Users\User\Desktop\скрины магазина\<магазин> — страница N.png` (одиночный),
`C:\Users\User\Desktop\скрины магазинов\<магазин>\<магазин> — страница N.png` (пакетный).

## Пакетная съёмка (batch.py)

Список ссылок — `C:\Users\User\Desktop\сайты али.txt` (экспорт переписки: строка с
названием магазина, следом ссылка). Скрипт сам:
- разворачивает короткие ссылки `a.aliexpress.com/_xxx`;
- если ссылка ведёт на ТОВАР, находит на его странице магазин и снимает магазин;
- подписывает файлы названием магазина из списка (у товарных ссылок — из заголовка
  страницы, иначе в подпись попадёт длинное имя товара);
- пишет прогресс в `state.json` ПОСЛЕ КАЖДОГО магазина — обрыв, лимиты или Ctrl+C
  ничего не теряют, повторный запуск продолжает с места остановки;
- падение одного магазина не роняет пачку — ошибка пишется в `failed`.

**Продолжить после перерыва:** `python batch.py --profile 859648353` — уже снятые
пропускаются автоматически. Ничего дополнительно указывать не нужно.

## Как это устроено

1. Local API Dolphin{anty} — `http://localhost:3001` (порт может съехать, в приложении
   Settings -> Health; `DolphinLocal.discover()` сканирует 3001-3005).
   Доступен только с этой же машины и только пока запущено десктоп-приложение.
2. `POST /v1.0/browser_profiles/{id}/start` с `{"automation": true}`
   -> `{"success": true, "automation": {"port": N, "wsEndpoint": "/devtools/browser/..."}}`
3. Цепляемся: `p.chromium.connect_over_cdp(f"ws://127.0.0.1:{port}{wsEndpoint}")`
4. `GET /v1.0/browser_profiles/{id}/stop` — погасить и синкнуть датадир.

Документация: https://docs.dolphin-anty-cdn.com/index.html

## Грабли (проверено на практике)

- **`automation` требует платный план.** На Free — HTTP 402, временные профили — 403.
  Аккаунт обновлён до платного, автоматизация работает.
- **`E_BROWSER_RUN_DUPLICATE` («already running»)** — Local API держит стейл-пометку даже
  после успешного `stop`. Лечится `start_with_retry()`: stop -> пауза 10с -> до 6 попыток.
  Всегда используй её, а не голый `api.start()`.
- **Пагинация магазина AliExpress клиентская.** Параметр `&page=N` в URL сайт
  **игнорирует** — будешь снимать одну и ту же страницу. Переключать надо кликом по `<a>`
  с текстом номера (без `href`, обработчик на JS), а факт переключения проверять по смене
  заголовков карточек `a[href*="/item/"]`, потому что URL не меняется.
- **Порядок товаров нестабилен** — при «best match» между запусками список тасуется,
  так что состав страниц от прогона к прогону отличается. Это не баг.
- **Гео-редирект.** С российского IP `aliexpress.com` принудительно уводит на
  `aliexpress.ru?gatewayAdapt=glo2rus`, а страница магазина там отдаёт 404. Параметр
  `rus2glo` не помогает — редирект по IP. Нужен профиль Dolphin с не-российским прокси.
  В `shots.py` есть защита: если хост оканчивается на `.ru`, скрипт выходит с кодом 2
  и не снимает 404-страницу.
- **Скрин на 10000px не влезает в дефолтные 30с** Playwright — в `page.screenshot()`
  выставлен `timeout=180_000`.
- **Горячие клавиши расширений (FireShot, Alt+Shift+1) через CDP не работают** — Chrome
  обрабатывает их сам через `chrome.commands`, синтетические события до них не доходят.
  Снимай через `page.screenshot(full_page=True)`.
- Перед скрином прокручивай страницу до низа (`autoscroll`) — иначе картинки товаров
  останутся ленивыми заглушками.
- **Жди карточки товаров**, а не `domcontentloaded`: `page.wait_for_selector('a[href*="/item/"]')`.
  Иначе снимешь полупустую страницу, а пагинатор не найдётся и решишь, что страниц нет.
- **`noTabs=true` не помогает** — профиль всё равно восстанавливает свои вкладки, зато
  страница не успевает прогрузиться. Не используй; лишние вкладки закрывай через
  `close_extra_tabs(ctx)`.
- **Не плодить вкладки** (просьба пользователя): один магазин = одна вкладка, закрывать
  сразу после съёмки, жёсткий лимит `MAX_TABS = 10`.
- **Только десктопная версия.** Короткие ссылки `a.aliexpress.com/_xxx` разворачиваются
  в мобильную `m.aliexpress.com/store/<id>` — там другая вёрстка и нет пагинации.
  Всегда переоткрывай `www.aliexpress.com/store/<id>/pages/all-items.html`
  (функция `to_desktop()` в `open_links.py`).
- **Браузер Dolphin гаснет вскоре после завершения запустившего его процесса.**
  Прицепиться к нему отдельной командой не выйдет: порт ещё висит в netstat, а сокет
  уже мёртв. Старт профиля и вся работа должны быть в ОДНОМ процессе. Чтобы оставить
  вкладки открытыми для пользователя — процесс должен продолжать жить (`open_links.py`
  держит браузер заданное число часов).
- У разных магазинов **разное число страниц** — 2, 4 и т.д. Это нормально, скрипт
  останавливается сам, когда номера в пагинаторе кончились.
- **Идемпотентность (курс Vercel «обвязка агента», kursy-konspekty):** перед стартом проверить, не запущен ли уже
  профиль; после подключения по CDP — проба простой командой в странице, не ответила — переподключить; статус
  брать свежий из API Dolphin, не из своего файла; остановка профиля — в `finally` (кроме режима «оставить вкладки»).

## Профиль уже запущен руками (без automation)

`start` с automation отдаёт `E_BROWSER_RUN_DUPLICATE`, а `start_with_retry` его
**погасит** — пользователю это не нужно. Вместо этого цепляться напрямую:
Dolphin запускает браузер с `--remote-debugging-port=0`, реальный порт лежит в
`%APPDATA%\dolphin_anty\browser_profiles\<ID>\data_dir\DevToolsActivePort`
(две строки: порт и путь `/devtools/browser/...`). Дальше
`connect_over_cdp(f"ws://127.0.0.1:{port}{path}")`, вкладки —
`[pg for c in b.contexts for pg in c.pages]`. Проверено 03.09.2026 (тогда на старом профиле; сейчас — 859648353).
Закладки профиля — `data_dir\Default\Bookmarks` (JSON), через CDP их не создать.

**Python:** `requests` и `playwright` стоят только в 3.13 — запускать
`py -3.13 ...`, дефолтный 3.14 их не видит.
