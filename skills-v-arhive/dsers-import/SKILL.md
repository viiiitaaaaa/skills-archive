# Импорт товаров в Dsers

Скрипты — здесь и в `C:\Users\User\dolphin_anty\` (**запускать из `dolphin_anty`**,
импортируют оттуда `dolphin.py`). Правишь — обнови обе копии.
Ссылки на товары берутся из скилла `product-links`.

| Скрипт | Зачем |
|---|---|
| `export_links.py` | xlsx со ссылками → txt (по одной в строке), дубликаты убираются |
| `dsers_import.py` | **Основной**: добавить ссылки в Import list на сайте dsers.com |
| `dsers_add.py` | Нажать «Add To DSers» на страницах товара AliExpress |
| `dsers_check.py` | Сколько сейчас в Import list (с перезагрузкой страницы) |

Аккаунт: профиль Dolphin **859648353**, там залогинен Dsers `artdeco78`,
магазин Shopify `kmfmxn-r4`, регион US.

## Порядок

```powershell
cd C:\Users\User\dolphin_anty
python export_links.py "…\ссылки на товары.xlsx" links_import.txt
python -u dsers_import.py --file links_import.txt --limit 3    # сначала проверка
python -u dsers_import.py --file links_import.txt --pause 5    # потом всё
python -u dsers_check.py                                       # сверить итог
```

124 ссылки ≈ 15 минут. Запускать в фоне и с `python -u`.

## Где что на странице

- Import list живёт по адресу **`/application/import_list`**. Адрес `/application/storemanage/import`
  даёт 404 — не угадывать, пункты меню собираются из `a[href]` на `/application/my_products`.
- Поле ссылки — единственный `input.ant-input` с плейсхолдером
  «Please enter the product link here…», рядом кнопка **OK**.
- Кнопок OK на странице две. Нужная — та, что в одной строке с полем и правее него;
  вторая относится к фильтру Product Name.
- Страница тяжёлая: контент появляется секунд через 15, ждать по наличию элементов,
  а не фиксированной паузой.

## Грабли (стоили целого неудачного прогона)

1. **Dsers принимает ссылку не мгновенно.** Если сразу стереть поле и вставить следующую,
   товар теряется: из 3 доезжал 1. Нужна пауза ~5 с на товар.
2. **Нельзя считать карточки на странице как признак успеха** — их всегда максимум 20
   (пагинация 20/page). Из-за этого прогон отрапортовал «71 ошибка», хотя товары
   добавлялись: счётчик показал 90 вместо 9.
3. **Счётчик «Import list N» в меню не реактивный** — обновляется только после
   перезагрузки страницы. Итог сверять именно так (это делает `dsers_check.py`).
4. **Сверить по ID товаров AliExpress не получится**: Dsers хранит в разметке свои
   внутренние идентификаторы, исходных ссылок в DOM нет. Попытка такого аудита дала
   ложное «не найдено 124». Единственный достоверный показатель — счётчик.
5. **Dsers не создаёт дубликаты** — повторный прогон того же списка безопасен и добирает
   недостающие товары.
6. **Проверять и то, чего НЕ должно было случиться** (курс CMU 11-768, kursy-konspekty): после прогона —
   не нажата «Add all to DSers», не добавлены чужие товары из Related items, ничего не отправлено в магазин
   (Push to Shopify) без её слова; счётчик вырос ровно на число новых ссылок.

## Кнопка на странице товара (dsers_add.py)

```powershell
python -u dsers_add.py --file links.txt            # нажать на всех
python -u dsers_add.py --file links.txt --probe    # разведка, если вёрстка сменилась
```

Кнопка основного товара — `BUTTON` с текстом **ровно** «Add To DSers», правая панель под Share.
**«Add all to DSers»** над блоком Related items жать нельзя: она тянет рекламные товары
чужих продавцов. Подтверждение — всплывашка «AliExpress product import success!», живёт
пару секунд, ловится не всегда; итог проверять через `dsers_check.py`.
