Все скрипты в `fashion-trend-radar/fashion-trend-radar` (парсинг AliExpress, трендов и т.д.) обязаны работать через профиль Dolphin{anty} **859648353** — это профиль нового магазина (см. [[novyy-magazin-shopify-profil3]]), а не 828976678.

**Why:** 828976678 — профиль другого магазина «Ремешки»/VENCOD (см. [[dolphin-profile-id]]). Пользователь уже несколько раз поправлял это ("сколько раз говорила") — путаница произошла из-за захардкоженной константы `PROFILE = 828976678` в `src/clients/aliexpress_dolphin_client.py`, которая осталась от другого проекта/копипаста и не была проверена перед использованием в контексте нового магазина.

**How to apply:** перед любым запуском кода, открывающего браузер Dolphin для fashion-trend-radar или второго магазина, явно проверять номер профиля в коде (grep "PROFILE" / "8599" / "8289") — не доверять старым захардкоженным значениям. Общая память [[dolphin-profile-id]] про 828976678 актуальна только для магазина «Ремешки», не для профиля 3.
