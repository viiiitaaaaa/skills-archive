07.10.2026: сотруднику удобнее Claude Desktop, но коннектор Google Диска там очень медленный, а без него чат не видит
файлы, обработанные в Claude Code. Решение: основная работа в Claude Code (вкладка Code в Desktop), чат — вспомогательный.

**Why:** контекст Claude Code (прочитанные файлы) живёт только в сессии Кода; в чат попало лишь вставленное руками.
Выгрузить чат через браузер/JS нельзя — фильтр блокирует, обход запрещён.

**How to apply:** выгрузка чата = она сама просит в Claude Desktop «выгрузи всю нашу переписку в один файл» и кладёт
в `<дело>\_служебное …\переписка claude.ai <дата>.md`. `G:\Мой диск\Дела\CLAUDE.md` заставляет Claude Code при старте
в папке дела читать `_журнал.md` + все `переписка*`. Для чата-дублёра на claude.ai лучше Проект с базой знаний
(«О деле — кратко и хронология.docx» + итоговые), а не коннектор Диска. См. [[bot-dela-telegram]], [[dela-papki-ponyatno]].
