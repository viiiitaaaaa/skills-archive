повторно — `--resume`. Статусы — опрос `claude agents --json` раз в 3 с: работает / ждёт вас (+уведомление Windows) /
свободна. Раскладка и задачи — `state.json` (в .gitignore). План и чеклист — `pult\PLAN.md`.
