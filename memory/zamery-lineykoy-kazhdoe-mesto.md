09.10.2026 она прислала снимки сайта с линейкой Ruler mode (лежат в «Ножницах»: %LOCALAPPDATA%\Packages\Microsoft.ScreenSketch_8wekyb3d8bbwe\TempState\*.png) и попросила «подровнять». Я сделала все отступы одинаковыми — она: «зачем ты всё подровнял под один размер».
**Why:** каждое её число — желаемый размер именно этого места (фото→цифры 22, цифры→марки 39, заголовок→содержимое 26, между блоками 138); «на глаз» значит ровнять только похожие места между собой.
**How to apply:** выписать её замеры по местам таблицей, ровнять только однотипные, мелкие внутренние отступы не трогать; проверять замером программой. См. [[lead-engine-proekt]].
