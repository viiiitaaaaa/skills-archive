Подложка сайта магазина генерится скиллом `site-mockups` в ComfyUI Cloud (модель flux1-dev-fp8, фиксированный рецепт). Дизайн-система принципиально двухслойная: ахроматическая оболочка + два токена коллекции (акцент и подложка фото).

**Why:** заказчик дважды отклонил результат — сначала за скучную нейтральность («как миллион других»), потом за тёплую палитру, которая оказалась палитрой одной коллекции из десяти. Рабочий ответ: характер несут свет, сериф и форма, цвет приходит только от коллекции.

**How to apply:** при любой правке подложки не подмешивать оттенок в оболочку; проверять новую версию на трёх разных акцентах коллекций. Файлы — `Downloads\comfy_shell\` (актуальное в `neutral_shell\`). Связано с [[kollektsii-po-stilyam]].
