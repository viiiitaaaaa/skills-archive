27.09.2026 после автосбора поиска Taobao (50 страниц «刺绣针织开衫», скрипт листал страницы в Chrome) и массовых
запросов данных товаров (mtop.taobao.pcdetail.data.get по 132 ID подряд) аккаунт получил предупреждение:
«подозрительная активность… парсинг-боты, скрипты… система ограничит часть функций», повтор — жёстче.

**Why:** её аккаунт Taobao — живой, с корзиной и заказами; повторное нарушение грозит более жёсткой блокировкой.
**How to apply:** не запускать скрипты-сборщики на taobao.com/tmall.com под её аккаунтом (листание страниц, mtop-запросы
пачками). Разовые ручные просмотры — только по её просьбе. Для массовых данных — другой источник (1688 через помощника,
который уже работает) или она сама выгружает. Уже собранное: cj\taobao\taobao_otbor_50str.xlsx, taobao_otbor_200.xlsx.
