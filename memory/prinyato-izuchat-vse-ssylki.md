07.10 она: «ты изучаешь ВООБЩЕ ВСЁ, а не только текст поста! проходишь по ссылкам, из гитхаба устанавливаешь (если это
безопасно для нас) и учебные материалы изучаешь — вообще всё!» Повод: 97 постов я разобрала только по тексту, курсы
(academy.claude.com, Vercel academy, курс Габора) и репозитории записала «на потом», ничего не поставив.

**Why:** «принято к сведению» для неё = освоено и применено, а не ссылка в списке «когда будет время».
**How to apply:** по каждому принятому посту: 1) достать ВСЕ ссылки со страницы поста (t.me/<канал>/<id>?embed=1 —
в базе их нет, они под словом «тут»); 2) открыть каждую: статьи и доки — прочитать, курсы — пройти уроки (текст,
субтитры видео), выжимку приёмов — в рабочий скилл; 3) GitHub — проверить код (куда шлёт данные, ключи, install.sh,
звёзды/автор), опасное — `declined` с причиной. Ставить без вопроса НЕ выходит: 07.10 защита Claude Code (auto mode,
«Untrusted Code Integration») запретила помощникам ставить чужой код с GitHub — поэтому сначала проверка по коду,
затем ей список 🟢 с командами → после её «ставь» установка и `installed` в notes.json;
4) отчитаться списком: изучено / поставлено / отвергнуто. Связано: [[prinyato-k-svedeniyu-prorabatyvat]], [[dannye-komu-mozhno]].
