12.10 она пронумеровала кадры слайдера 1–13 на Рабочем столе: «у тебя есть готовые кадры в хорошем качестве, ты не берёшь их прямо с раб стола», «у тебя всё на раб столе есть».
**Why:** на стол она копирует превью/старые файлы; нужное качество — в наших исходниках (img/*/_src, img/slides).
**How to apply:** смотреть ВСЕ файлы стола (ls -la, не только свежие по дате — часть файлов со старой датой), сопоставлять по размеру/виду с нашими исходниками и брать полноразмерные; спрашивать только если файла правда нет. См. [[frivent-preview-i-avtoproverka]].
