# Правила проекта ARTMELLIO

Общий свод для Cursor и Claude Code. Оба инструмента читают этот файл.

## Магазин

- Магазин: `kmfmxn-r4.myshopify.com`, тема на базе Dawn 16.
- Базовая валюта — **PLN**, витрина показывает **GBP** через рынок. Не путать при расчётах.
- В текстах магазина **не указывать город и страну**. Контакт только email.

## Запреты

- **Не публиковать тему автоматически.** Публикация — только руками человека,
  каждый раз спрашивать. Перед публикацией **побайтно сверить
  `config/settings_data.json` обеих тем**: публикация молча откатывает
  настройки — цвета, логотип, пользовательский CSS, app embeds.
- **`theme push` затирает тему целиком** — точечные правки слать через
  `themeFilesUpsert` (см. `scripts/theme/`), а не пушем.
- **Не менять цены и наличие** без явного подтверждения.
- **Не коммитить секреты.** Ключи, токены, `.env` — только вне репозитория.
- **Не запускать `shopify app` и `shopify store auth`.** Они открывают системный
  Chrome, а вход в магазин только через профиль Dolphin{anty}.

## Источник правды

**Metafields** — единственный источник правды по свойствам товара: стиль интерьера,
материал, цвет, размеры, статус пересъёмки фото, ссылка на исходник, статус в Dsers.

Свойства не хранятся текстом в описании. Описание — витрина, метаполя — данные.

## Доступ к API

Admin API вместо админки: админка за прокси Dolphin регулярно требует
Cloudflare-капчу и автоматизация на ней встаёт.

```powershell
# Shopify CLI — только через обёртку, она подставляет токен
& C:\Users\User\dolphin_anty\shop.ps1 theme list
```

```python
# GraphQL к Admin API
from shop_api import gql
gql("{ shop { name } }")
```

Токен выпускается по client credentials и **живёт 24 часа**. Кэш —
`C:\Users\User\dolphin_anty\shopify_token.json`. После выдачи новых прав кэш
удалить, иначе запросы идут со старым токеном.

Прежде чем просить новые scope — проверить текущие:
`{ currentAppInstallation { accessScopes { handle } } }`. Запрашивать сразу весь
набор одним списком: при релизе он заменяет старый, а не дополняет.

## Разделение автоматизаций

- Действие целиком внутри Shopify → **Shopify Flow**.
- Действие выходит наружу (API, уведомления, очереди) → **n8n**.

У Flow **нет триггера «товар изменён» и нет триггеров по коллекциям вообще** —
это уходит в n8n на вебхуки `products/update` и `collections/update`.

## n8n

Установлен глобально, панель на http://localhost:5678, запуск —
`.\n8n\start-n8n.ps1` (подставляет ключи и снимает запрет на переменные
окружения). Подробности и грабли — `n8n/README.md`.

- **Узел Shopify из коробки не использовать** — он требует OAuth, а OAuth
  открывает системный Chrome. Только HTTP Request.
- **Токен выпускать первым узлом каждого воркфлоу.** Он живёт 24 часа,
  постоянного токена у нас нет.
- Экспорт каждого рабочего воркфлоу класть в `n8n/exports/` и коммитить.

## Тема

Перед правкой темы — `python scripts/theme/sync_live_theme.py`, иначе правится
слепок недельной давности. Заливка точечная:
`python scripts/theme/push_files.py <файл>`.
