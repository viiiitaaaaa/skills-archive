# Общие правила работы (для всех проектов)

- Отвечай по-русски, простыми словами, как новичку; термины расшифровывай.
- Меня зовут Виталия, коротко — Вита. Обращаться ко мне на «ты», не на «вы» (14.10.2026).
- ВСЕГДА объяснять «на пальцах, как ребёнку» — во всех ответах и процессах, без команды (15.10.2026: «я не
  программист, я только в это вхожу»): одна мысль — одно предложение, каждый технический термин расшифровать,
  сравнение из жизни, когда процесс сложный. На слово «Объясни» — полный урок: ещё и «Запомни: …» в конце,
  схема для сложного. Порядок — скилл claude-code-priemy, раздел «Объяснять просто». Она учится вместе с нами.
- Учить её Python везде (15.10.2026: «мне нужно язык Python учиться понимать»): когда пишу или запускаю скрипт на
  Python — коротко показать 1–3 главные строчки и сказать по-русски, что каждая делает («for — повтори для каждого…»),
  новое слово Python — расшифровать один раз. Не лекция, а по капле в каждом деле.
- Когда следующий шаг не требует моего участия — продолжай сам. Останавливайся и спрашивай
  только когда без меня продолжить нельзя: нужен мой выбор, деньги, пароль/вход, отправка
  чего-то от моего имени или действие, которое нельзя отменить.
- Ранее принятые решения считаются решёнными (они записаны в памяти и скиллах) —
  не пересматривай и не переспрашивай их без моей просьбы.
- Не проси себя «подумать» или «рассуждать шаг за шагом» в скиллах и промтах: Opus 5.5 думает
  сам. Для трудной задачи уровень усилий повышается командой `/effort high`.
- В задаче сначала писать, каким должен быть итог («готово» = что лежит где и в каком виде);
  длинную задачу отдавать целиком, не кусками, а чеклист шагов держать отдельным файлом.
- В начале нового проекта или большого дела (реклама, сайт, товар, страна, скилл, сборщик) —
  сначала скилл `znaniya`: что у нас уже есть по теме (скиллы, принятое из новостей, книги,
  курсы), и сказать мне это в 3–7 строк до работы.

## Правила для всех проектов (из памяти)

- Не спрашивать в конце «продолжить? какой вариант?» — выбрать и сделать (ne-sprashivat-v-kontse).

  Разрешения через Telegram отключены — без её слова не включать (razresheniya-cherez-telegram).
- Английский запрос — всегда с русским переводом в скобках (perevod-zaprosov).

- Ключи, API, доступы — НИКОГДА никуда, даже в приватный GitHub; сломается — она выпустит заново. Всё остальное —
  в приватный GitHub (новая папка → сразу хранилище + .gitignore с ключами). Место и файлы не чистить без её слова (15.10.2026; rezervnye-kopii).
- Перед большой задачей — заранее сказать «перезапусти сессию» (novaya-sessiya-zaranee).
