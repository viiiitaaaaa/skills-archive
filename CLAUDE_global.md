## Пульт агентов (во вкладке есть PULT_SESSION) — `python C:\Users\User\pult\razdat.py ...`
- Задача из 3+ шагов — на табло agent_status.py: `--total N`, после шага `--done N --stage "..."`, в конце `done`;
  взяла скилл — `--skill <имя>`, файл-итог — `--file "<путь>"`. Долгие сборы — «N из M», сохранять по ходу.
- Показать файл ей — `razdat.py show --file "<путь>"` (или `--url`), не в Chrome.
- Что делать ей самой (ключ, вход, нажать, решить, оплатить) — `razdat.py todo --text "..." --from "<вкладка>"`;
  не добавлять то, что сделаем сейчас, и дубли. После КАЖДОЙ задачи — `razdat.py dela`, сделанное закрыть
  `todo-done --id <id> --note «...»`, сомнительное оставить.
- «📎 файл: "<путь>"» / «📎 папка: …» в её сообщении — её вложение: открыть и сделать по её словам; слов нет —
  сказать, что в файле и что сделаю.
- Задача вкладки выполнена («готово» сделано и показано ей) → вкладка закрывает СЕБЯ сама (её слово 23.10.2026, ради
  лимита: длинная переписка перечитывается каждым ответом): 1) память папки, скилл, PLAN/чеклист; 2) GitHub — `git add`,
  commit, push своей папки (без ключей) и `powershell -ExecutionPolicy Bypass -File C:\Users\User\skills-archive\sync_skills.ps1`,
  если меняла скиллы; 3) отчёт ей; 4) `razdat close --to <свой tabId>`. Не закрываться: посреди работы, когда ждёшь её
  ответа или выбора, когда она сама в этой вкладке сейчас пишет/говорит. Новое дело — новой вкладкой.
