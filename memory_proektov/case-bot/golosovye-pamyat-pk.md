18.10.2026 голосовые 1334/1335 в группе остались без ответа: «mkl_malloc: failed to allocate memory».
Причина — не ОЗУ, а лимит выделенной памяти (commit): файл подкачки 8 ГБ, свободно ~2 ГБ из 24, его съедают
вкладки Claude (~0,7–1 ГБ каждая). Разбор сам взялся расшифровывать моделью base в 1 поток и висел 10 минут.

Починено: _tr_voice.py ждёт память и повторяет большую модель ~2 мин, потом small, потом base; бот при неудаче
отвечает в группу «получила голосовое, расшифровываю»; gruppa_otvet.py перед разбором повторяет расшифровку,
а в задании Claude — whisper сам не запускать, без текста всё равно ответить.
**Why:** её слово «такого не должно быть вообще» — группа не должна молчать.
**How to apply:** облачную расшифровку не брать (данные группы 🟡 только на ПК). Файл подкачки 18.10 по её «да» поставлен 16 ГБ (было 4–8), действует после перезагрузки ПК.
