18.10.2026 она спросила, почему личный бот перестал присылать «сделали то-то». Причина: вкладка «Мой бот» починила бота
(дубли, сигнал облаку, заседания), но задачу на табло не поставила. Тогда pult\gotovo_tg.py ничего не шлёт.

**Why:** напоминание в личку она получает только после `agent_status.py done` (или `razdat.py uborka-done`).
**How to apply:** любая доработка из 2–3 шагов и больше: в начале `agent_status.py set <id> --title … --total N`, в конце `done <id>`,
даже если работу просили между делом. Проверка: `pult\gotovo\zhurnal.log` — «ушло: 1».

**Обновлено 18.10, её слово: «надо после каждого сделанного дела мне отправлять сообщение», а не после напоминания.** Теперь это делается
автоматически: хук Stop `pult\hooks\gotovo_stop.py` (в ~\.claude\settings.json). Он срабатывает только во вкладках пульта,
когда в ходе были Edit/Write, git commit/push, wrangler deploy или razdat todo, и ставит «✅» в очередь gotovo_tg.py.
Если в ходе уже был `agent_status done`, он не дублирует. Табло всё равно вести — оно нужно для % в пульте.
