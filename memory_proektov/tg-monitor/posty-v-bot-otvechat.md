**Why:** 27.09.2026 я дважды разложила посты про парсеры и хаки Claude Code по папкам без ответа. Она переслала их снова: «почему ты упорно игнорируешь посты… опять тишина».

**How to apply:** при разборе входящих каждый пост → разбор в бот (`send_result.py --reply <msg_id>`) + файл `Мои задачи/Инструменты/разбор_постов_<дата>.md`. Правило записано и в скилл dela. С 27.09 разбор запускается сам: сторож case-bot\auto_razbor.py (она попросила «нужно, делай» — чтобы шло и при закрытой сессии, ценой лимита). См. [[bot-dela-telegram]].
