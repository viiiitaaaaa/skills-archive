Когда она просит «озвучь», а мой ответ состоит из вариантов, разбора по базе и вывода, читать вслух всё целиком. Не сокращать до одного вывода.

**Why:** 25.10.2026 я прочитала только вывод по четырём вариантам сообщения. Её слова: «Озвучь весь свой итог по вариантам и твой вывод. Ты озвучила только вывод».

**How to apply:** для озвучки брать весь последний ответ дословно, без таблиц и путей к файлам. Сокращать только по её прямому слову «только вывод». Связано с [[pravda-po-baze-ne-poddakivat]].
