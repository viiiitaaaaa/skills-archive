Разговор с Perplexity и сложный глубокий поиск — я сама задаю вопросы на perplexity.ai в её Chrome
(claude-in-chrome; она там вошла в Pro), читаю ответ (get_page_text) и пересказываю по-русски простыми словами,
со ссылками на источники. Уточнения задаю там же, в том же разговоре. Простой поиск — обычный WebSearch.

**Why:** Вита 14–15.10.2026: хочет постоянно и вживую общаться с Perplexity, оплатила Pro последними деньгами.
Перебрали все пути:
- API — официальный, но платный отдельно; в консоли баланс 0,00 $, бесплатного кредита к Pro нет (проверено 15.10.2026);
- копировать и вставлять ответы сама — не хочет;
- «почтовый ящик» через Автоматизацию Perplexity — тратит лимит «Компьютера» (она на нём обжигалась) и
  запускается не чаще раза в час, а нужно вживую.
Условия Perplexity (Terms of Service: боты, скраперы, автоматизация) это запрещают, возможна блокировка Pro;
ей объяснено, 15.10.2026 выбрала «ты сама задаёшь вопросы в Chrome». Не переспрашивать.

**Только с её слова (15.10.2026):** «Без меня ты ничего на Perplexity не запрашиваешь». Вопрос в Perplexity —
только когда она сама прямо попросила в этом разговоре; сама по себе, по задаче от другой вкладки, из проверки
или «потому что полезно» — нельзя (можно предложить одной строкой). Повод: Claude в пробной копии пульта принял
тестовую голосовую фразу «Спроси у Perplexity…» за поручение и задал вопрос с её Pro.

**How to apply (осторожно, чтобы не походить на бота):** одна вкладка, по одному вопросу, ждать ответа целиком,
без пачек, циклов и параллельных вкладок. Режим: кнопка «Поиск ▾» под полем → «Поиск» (обычный) или
«Глубокое исследование» — его только когда правда нужно (в Pro месячный лимит, число Perplexity не публикует).
После разговора вкладку закрыть. Если сайт начнёт показывать капчу/проверку на бота — остановиться и сказать ей.

Цены API на будущее (docs.perplexity.ai/docs/getting-started/pricing, 14.10.2026): быстрый ≈ $0.003–0.005,
обычный ≈ $0.008, глубокий (high, его берёт perplexity_research) ≈ $0.065, xhigh ≈ $0.16 за вопрос.
Если пополнит API: официальный MCP `@perplexity-ai/mcp-server@1.3.0` (авторы — сотрудники perplexity.ai),
`MSYS_NO_PATHCONV=1 claude mcp add --scope user perplexity -e PERPLEXITY_TIMEOUT_MS=600000 -- cmd /c npx -y
@perplexity-ai/mcp-server@1.3.0`, ключ — окном `C:\Users\User\komputer\perplexity_klyuch.ps1` (переменная
PERPLEXITY_API_KEY, в чат не печатать). Связано: [[hermes]].
