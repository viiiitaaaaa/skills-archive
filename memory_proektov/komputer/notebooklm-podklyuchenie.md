15.10.2026 Вита спросила, можно ли подключить NotebookLM (переименован в Gemini Notebook) — дёшево разбирать купленные книги.
Разобрано (ничего не ставили):
- Официального API для обычного NotebookLM нет. Есть только Gemini Notebook Enterprise API в Google Cloud (v1alpha):
  нужен платёжный аккаунт Cloud и Enterprise-лицензии (по блогам ~9 $/лицензия/мес, мин. 15); в документации — создание
  блокнотов и загрузка источников, метода «задать вопрос» не нашла. Официального MCP нет.
- Неофициальные MCP через браузер — чужой непроверенный код (только с её слова) + риск для Google-аккаунта, как с Perplexity.
- Страна: NotebookLM работает в странах, где доступен Gemini API. Она и её аккаунт НЕ в России (её поправка 15.10.2026).
  Antigravity на аккаунте gokjhfrr писал «not available in your location» ([[gemini-cli-otklyuchen-antigravity]]) — причина
  не выяснена; про NotebookLM не гадать, просто проверить, открывается ли у неё notebooklm.google.com.
  Проверено 15.10.2026: сайт у неё открывается, вход есть.
- Безопасный путь: она сама грузит книгу в NotebookLM и сохраняет конспект/заметку в Google Docs, мы читаем файл с Диска.
Связано: [[perplexity-poisk]].

**Решение 15.10.2026:** «Книги кладу я, спрашиваешь ты» — её выбор, без автоматизации NotebookLM (риск для Google-аккаунта).
- Книги уже на её Google Диске: `G:\Мой диск\куплено` (89 файлов, аккаунт Диска gokjhfrr@gmail.com — тот же
  аккаунт нужен в NotebookLM). Новые книги кладу туда же копированием на G: (0 токенов), не через MCP.
- Я пишу ей готовые вопросы; она в NotebookLM: блокнот → «Добавить источник» → Google Диск → куплено → книга;
  задаёт вопрос, сохраняет ответ в заметку и экспортирует в Google Документ; я читаю его через Google Drive MCP.
- Сама в NotebookLM запросы не отправляю. EPUB/MOBI NotebookLM может не взять — тогда PDF/txt.

15.10.2026 «куплено» разложена по темам (её просьба «строго по темам»): папки 01 Маркетинг … 13 Личные финансы, 99 Не по делу;
лекции (рефераты из «Учёба — маркетплейсы…») СКОПИРОВАНЫ в те же темы (оригиналы на месте); недокачанные .tmp → «_Можно удалить».
Журнал для отката — `куплено\_журнал раскладки *.csv`. Рейтинг «что читать первым» от Perplexity —
`куплено\_ТОП книг — что читать первым (Perplexity, 15.10.2026).html`. Новые книги класть сразу в нужную тему.
