28.09.2026 она: «а если поставщиков поискать в … Baidu.com», «бинг не надо… только байду».
Рабочий способ: открыть в Chrome
`https://graph.baidu.com/details?isfromtusoupc=1&tn=pc&carousel=0&promotion_name=pc_image_shituindex&extUiData%5bisLogoShow%5d=1&image=<URL картинки, urlencode>`
→ блок «相关商品» (та же вещь в продаже: цена, площадка — Taobao и др.) и «图片来源» (где это фото встречается: Xiaohongshu,
Douyin, сайты — по самой ранней записи виден первоисточник / чья это модель).
- Картинки с 1688 (cbu01.alicdn.com/img/ibank/…-0-cib.jpg) Baidu берёт. Ссылки PDD из pdd_items (commimg-2.pddpic.com
  long-pic-generate) — НЕ берёт («未找到相关结果»). Поэтому: фото PDD → поиск по фото 1688 → ссылка на ту же съёмку на 1688 → Baidu.
- Кнопка ⊕ на image.baidu.com открывает системное окно выбора файла — Claude туда не попадает (закрыть Escape).
  Прямая загрузка на graph.baidu.com/upload из Python — «Reject».
Пример: юбка лист 3 №85 (макси с оборкой) — первоисточник фото Xiaohongshu 12.2021 «Celine大秀 超大裙摆羊毛格纹半身裙»
(копия подиумной Celine), в продаже только Taobao 75–199 ¥ — фабрики не видно.
**How to apply:** для юбок без подходящей фабрики на 1688 — Baidu по ссылке 1688-фото; результаты — в «ИТОГ».
Связано: [[plan-pdd-vs-1688-otbor]], [[treg-1688-api]].
Пример 2: №98 (твидовая «гусиная лапка» с разрезом, 芳琦 980496905021, 230 ¥) — Baidu: то же фото на Taobao 135–340 ¥ и на PDD
у «翰代维» 64 ¥; первоисточник — пост Taobao (淘江湖) осень 2022. «翰代维» на 1688 — общая метка у разных продавцов, не фабрика.
Вывод: Baidu хорош для «где ещё продаётся и с какого года», фабрику напрямую не называет.

28.09 оптовые рынки вне 1688 (для №98):

  потом требует вход. Есть поиск по фото ПО ССЫЛКЕ: stu.17zwd.com/SearchSimilar?img_url=<url> — но сам выбирает объект
  (взял майку), а рамку «框选主体» для фото с 1688 не открыть (картинка не грузится). Годится для фото, где юбка — главное.
