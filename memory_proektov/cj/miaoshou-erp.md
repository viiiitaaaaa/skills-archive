妙手ERP — китайская ERP для кроссбордера: сбор товаров (产品采集) с 100+ площадок, выкладка в Shopify/TikTok/Temu/Ozon…,
заказы, закупка, склад, автоперевод фото. 28.09.2026 у неё открыта вкладка «授权店铺 platform=shopify» — Shopify подключён.
17zwd (17网) — официально поддерживается (справка help_center/article_9448): 1) 货盘采集 «产品 → 跨境产业带»;
2) 插件采集 — с их расширением на странице поиска 17zwd «采集选中/采集本页» или на карточке; 3) 链接采集 «产品采集 →
链接采集» — вставить ссылки. Сначала нужно авторизовать аккаунт 17网 в 妙手 (СДЕЛАНО 29.09). Собирает название, фото,
цену, остатки; дальше правка и публикация в Shopify.
Расширение: шапка «插件下载» → галочка согласия с условиями → «谷歌/QQ浏览器» (скачивание — только с её согласия).
Открытого API у 17zwd не нашли; у VVIC API есть по заявке разработчика. Связано: [[baza-postavshchikov]].

29.09.2026 06:40: аккаунт 17网 (TEL_6rgl_16750258376, ID 1320015) подключён в 妙手 — статус «已授权». Раздел: 授权 → 货源账号 → 17网. Отключить — «解除授权». Следующее: расширение 妙手 («插件下载», её согласие) и сбор «产品 → 跨境产业带» / «产品采集 → 链接采集».

29.09 грабли: бесплатный аккаунт 妙手 — максимум 10 собранных товаров ВСЕГО («免费账号最多可采集10个商品»); лимит съели 10 товаров
老金马, собранных в 06:56 (не наши). Выгрузки в файл в «公用采集箱» нет (в «更多» только «批量备注»). Расширение: галочка —
кружок справа вверху карточки при наведении; «采集本页» — вся страница одной кнопкой. Страница прогружается с разной
прокруткой — клики мимо открывают товары (она: «каждый товар не надо открывать», «словим бан») → перед кликами делать
снимок экрана, на 17zwd не кликать вслепую. Если расширение пишет «не вошли… режим инкогнито» — включить у расширения
«Разрешить в режиме инкогнито».
Кнопка расширения «下载» (29.09 проверено): НЕ данные товаров, а CSV со ссылками — сначала «获取本页链接» (берёт ВСЕ ссылки
страницы, 120 шт, не только отмеченные), потом «下载» → «商品链接导出<дата>_N.csv» (GBK, один столбец «商品链接»).
Лимит сбора не тратит. Полные данные (цена, фото, размеры, остатки) — только «采集» в 妙手, бесплатно 10 шт на аккаунт.
Соседняя кнопка «清除» чистит сохранённые ссылки (спрашивает подтверждение — «取消»).

29.09 ВЫГРУЗКА АССОРТИМЕНТА БЕЗ ЛИЦЕНЗИЙ (её задача «выгрузить ассортимент магазина без лицензий»): cj\17zwd\.
1) vygruzka_magazina.py <ссылка магазина> — читает витрину постранично (пауза 4–8 с), товары НЕ открывает; без входа
   17zwd отдаёт только 3 страницы (360 шт). 2) Остальное — JS в её Chrome (fetch страниц магазина с её входом, DOMParser,
   название — img[title], номер — ячейка после «找同款», фото — img_url в ссылке «找同款»), ~13 страниц за 1,5 мин.
3) Вынести данные: автоскачивание второго файла Chrome блокирует, localhost-приёмник и буфер тоже не работают →
   вставить на страницу зелёную кнопку-ссылку blob («Скачать таблицу…»), ОНА нажимает один раз. 4) sobrat_excel.py
   <main.csv> <names.csv> <магазин> → xlsx с фото. Итог 伊可可: 1446 товаров, 1434 с фото.
29.09: столбцы «Нам подходит» (✅/🟡/❌) + «Почему» — cj\17zwd\otsenka.py (радар: юбка в клетку = ТЕСТ, макси/миди +70%,
