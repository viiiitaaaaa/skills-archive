Всё, что связано с 1688 и китайскими сайтами (1688.com, air.1688.com «云牛顿», документы alidocs.dingtalk.com), открывать **только в обычном браузере Chrome** через инструменты claude-in-chrome — не в профилях Dolphin (ни 859648353, ни 828976678).

**Why:** пользователь прямо сказала 24.09.2026: «все что связано с 1688 китайские сайты только через обычный хром браузер» (после того как я открыла их в профиле 3).

**How to apply:** для таких ссылок — `tabs_context_mcp` → новая вкладка → navigate; входы в аккаунты делает сама пользователь. Dolphin остаётся для магазина и радара ([[dolphin-profil3-dlya-trend-radar]], [[novyy-magazin-shopify-profil3]]).
