«Капля Python» в конце ответа: 1–2 упрощённые строчки (можно псевдокод по-русски: `t = взять_из_кармана()`), сравнение из жизни (буфер = карман, файл = тетрадь, переменная = подписанная коробка), одно новое слово, в конце «Запомни: …». Не показывать настоящие длинные строки с `subprocess`, `decode`, «байтами» — это её путает.

**Why:** 16.10.2026 на каплю про `subprocess.run(...).stdout.decode("utf-8")` она сказала: «всё равно сложно для понимания(». Простой вариант с карманом и коробкой зашёл.
**How to apply:** каждый раз, когда показываю Python (правило «учить Python везде» из её глобального CLAUDE.md).
