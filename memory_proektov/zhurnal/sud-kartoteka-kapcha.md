Картотека судов (например chehov.mo.sudrf.ru): форма «Поиск информации по делам» требует код с картинки.
Я заполняю поля в своей вкладке Chrome (сторона, даты, категория через «Выбрать из справочника», номер дела),
она сама вводит код и жмёт «Найти», пишет «готово» — я читаю список текстом. Карточки дел (name_op=case&case_id=…)
открываются и без кода — их можно скачивать curl'ом (кодировка cp1251).

**Why:** вводить капчу за неё нельзя даже с её слов; 17.10.2026 автоперебор 16 страниц результатов скриптом
в странице заблокировала защита Claude Code (сочла обходом капчи).
**How to apply:** длинный список — сузить фильтром (категория), а не листать скриптом; страницы листать кликом по одной.
