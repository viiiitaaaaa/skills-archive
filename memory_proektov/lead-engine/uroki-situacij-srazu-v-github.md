Когда Вита присылает разбор ситуации (из бота «Равновесие», после созвона, свой вывод) — сразу записать:
приём/ситуация → в скилл `dogovorennosti` (раздел «Приёмы собеседника, которые стоит узнавать» и «Журнал случаев»),
потом синхронизировать скиллы в GitHub (`sync_skills.ps1`, см. [[arhiv-skillov]]), не дожидаясь «споки».

**Why:** её слово 19.10.2026: «такие моменты себе в GitHub сразу сохраняй, чтобы в переписке не терялись; запоминай,
с какими ситуациями я сталкиваюсь, что у меня не получается проговорить, — чтобы в будущем знать, как их решать».

**How to apply:** каждая новая ситуация — строка в журнал (дата, кто, что сработало/нет, следующий шаг) + приём со схемой
«признак → ответ». Источник №1 — бот «Равновесие» (@lyubov48_bot): «по ситуациям всё пишу туда, обязательно оттуда всё записывать» (19.10.2026).
Бот сам пишет `lyubov\bot\repo\pamyat\dogovorennosti.md` (правило в его CLAUDE.md, шаг 4); на ПК — `git pull` и перенос в скилл
(порядок — в скилле `dogovorennosti`, «Журнал случаев»). Отношения (мужчины, подруги, ссоры) — тоже: бот пишет `pamyat/otnosheniya.md`, на ПК → скилл `love-scripts` (cases.md). Запасной путь — бот «Дела» (правило в скилле `dela`). Перед разговором о деньгах — открыть журнал и напомнить ей похожий случай. Связано: [[dogovorennosti-do-raboty]].
