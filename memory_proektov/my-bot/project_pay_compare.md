Сверка «К перечислению» (колонка C нижнего блока «Динамики финансы», строки
~112–129, где B = «с ... по ...») с реальными суммами кабинета WB.

**Источник:** кнопка «Скачать excel» НА СПИСКЕ
seller.wildberries.ru/.../reports-weekly-new — без модалки, сразу качает
сводный файл всех отчётов в сокращённой форме («Еженедельный отчет
2024-01-29 - ...xlsx», один лист, строка на отчёт, колонка «Итого к оплате»).
Внутрь отчётов заходить не нужно.

**Конвейер:** `node pay-compare.js` (скачивает через CDP-клик в pay/, парсит,
суммирует пару Основной+По выкупам за неделю) или `--local` (по последнему
файлу). Пишет в «Динамику финансы»: AG = Итого к оплате ВБ (число),
AH = формула `=IFERROR(ROUND($C/$AG*100;1);"")` — 100 значит сошлось.
Больше ничего в этом листе не трогает.

**Грабли с форматом:** строки 112–129 у владельца отформатированы как
проценты на всю ширину — записанное в AG/AH там отображалось «55964166%».
Формат-режима у Apps Script-деплоя НЕТ (format:true — это ДРУГОЙ деплой,
из compare.js). Чинится через открытую вкладку самой таблицы: поле имени
(#t-name-box) ← `'Динамика финансы'!AG112:AH129` + Enter, затем
CDP Input.dispatchKeyEvent Ctrl+Shift+1 («форматировать как число»).

Типовой результат сверки: 97–104 %, т.е. C систематически чуть расходится
с кабинетом (C — расчёт из деталей отчёта, ВБ — фактическое «Итого к оплате»).
