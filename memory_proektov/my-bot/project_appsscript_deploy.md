Правка Apps Script книги идёт скриптом: `monaco.editor.getModels()` → `setValue`
→ Ctrl+S → Развернуть → Управление развертываниями → карандаш → «Новая версия».

**Три способа молча получить старый код в проде:**
1. **Ctrl+S не срабатывает**, а публикация идёт дальше — в проде остаётся
   прошлая версия. Обязательно ждать в тексте страницы «Сохранено на Диске»
   и только потом публиковать; «Несохраненные изменения» — стоп.
2. **Вкладка Apps Script зависает**: `Runtime.evaluate` начинает отваливаться по
   таймауту. Лечится закрытием вкладки через `/json/close/<id>` на порту 9222 и
   открытием свежей — переоткрытие URL в той же вкладке не помогает.
3. Меню развертывания не реагирует на `el.click()` — нужны настоящие
   `Input.dispatchMouseEvent` по центру элемента.

**Скрипт заливки — `deploy-gs.js`** (04.08.2026). Что в нём оказалось важным:
кнопка в шапке называется **«Начать развертывание»**, а её текст содержит глиф
иконки — сравнивать надо по началу строки, а не целиком; карандаш имеет
`aria-label="Редактировать"`; кнопка подтверждения в окне — это `<button>` с тем
же текстом, что и `<div>` в шапке, поэтому искать надо строго `button`; список
версий по умолчанию стоит на ПОСЛЕДНЕЙ версии — если не переключить его на
«Новая версия», публикуется старый код, а скрипт рапортует об успехе. Перед
началом надо дважды нажать Escape: открытое с прошлого раза окно перехватывает
первый клик.

**Проверять результат запросом, а не сообщением об успехе:** после публикации
дёрнуть новую команду и убедиться, что ответ изменился.

**Как отличить новый код от старого:** послать команду на НЕСУЩЕСТВУЮЩИЙ лист.
Новый код отвечает `no-sheet`, старый проваливается в ветку записи, создаёт
лист и отвечает `ok`. Имя листа каждый раз новое — иначе лист от прошлой
проверки уже существует и тест врёт (04.08.2026 из-за этого дважды решил, что
развертывание не прошло). Пустые «ЛистN» от таких проверок убирает команда
`deleteSheet`.

Ошибка Apps Script возвращается HTML-страницей, а не JSON — клиент должен это
различать (`text.startsWith('<')`), иначе `JSON.parse` падает с непонятным
«Unexpected token <». Разовые сбои случаются: набор настроек диаграммы, упавший
один раз, при повторе прошёл без изменений.

Чтобы не переразвёртывать скрипт ради подбора параметров, делай их
передаваемыми снаружи (как `options` у команды `chart`).
