`book.gs` не умеет ставить числовой формат (нет ни setNumberFormat, ни команды
для него), поэтому формат чинится клавишами в самой вкладке таблицы через CDP:
**Ctrl+Shift+1** = «Число». Новые строки «Динамики» приходят с процентным
форматом и показывают `16808856%` вместо `168 088,56` — значение при этом
верное, врёт только отображение.

Рабочая последовательность (04.08.2026):
1. `Page.bringToFront` и клик по сетке — без фокуса в таблице клавиши просто
   не доходят, выделение не двигается, а скрипт при этом рапортует «готово»;
2. клик по `#t-name-box`, **Ctrl+A** (поле держит старый текст), набрать
   диапазон, Enter;
3. **после Enter выделение уезжает на строку ниже** (набрал `W112:X112` —
   получил `W113:X113`). Поэтому проверять `#t-name-box` ПОСЛЕ Enter и
   дотягивать Shift+↑ / Shift+↓, а не верить набранному;
4. Ctrl+Shift+1 (`modifiers: 2|8`, `Digit1`, vk 49).

Проверять результат чтением через endpoint: `values` возвращает отображаемые
строки, и `%` в них сразу видно.
