01.08.2026 две книги слиты в один документ по просьбе владельца («делаю один
документ без прыганий»). Выжила книга **«1» — `12OLxU8EDwN6nJQGySGEczKe0wflJN1dr4-4Y1Dynyxw`**:
в ней невосстановимое (Себестоимость, «История хранения/воронки/рекламы/отчетов»,
«Динамика финансы», недельные вкладки), а листы книги сравнения генерируются
скриптами. Стало 15 листов: 10 прежних + Цены, Юнит-экономика, Цены — сценарии,
Evirma, Сравнение.

**Единый путь: `book.js`** — `BOOK_URL`, `BOOK_ID`, `BOOK_HTTP`, `gvizCsv(sheet)`.
Все скрипты берут адрес только оттуда (`require('./book')`). Четыре старых
/exec-адреса (книга сравнения, «Цены», «Evirma») мертвы, старые ID в коде не
осталось. Старая книга `12Bmi7Jih…` («Новая таблица») не тронута — резервная
копия, но данные там больше не обновляются.

**Исходник Apps Script лежит в репозитории: `my-bot/apps-script/book.gs`.**
Редактор Apps Script истории не хранит — правь локальный файл, потом заливай.
Единый скрипт = объединение обоих старых: `read`, `dup`, `clearRanges`,
`at`/`col`/`wipe`, `formulas` (от книги «1») + `=IMAGE` в rows, `paint`, `groups`,
`collapse`, `format` (от книги сравнения) + новые `list` и `pull`.
`pull: {from, sheets, replace}` переносит листы из другой книги (`openById`
дополнительной авторизации не потребовал).

**Переразвёртывание обязательно, иначе /exec отдаёт старый код:** Развернуть →
Управление развертываниями → карандаш → Версия «Новая версия» → Развернуть.
Так URL сохраняется; сейчас версия 8. Кликается через CDP только НАСТОЯЩИМИ
мышиными событиями (`Input.dispatchMouseEvent` по центру rect) — `el.click()`
меню Apps Script игнорирует. Код в редактор заливается через
`monaco.editor.getModels()` → `setValue` → Ctrl+S.

**Грабли переноса (стоила часа):** после `copyTo` все фото в «Сравнении» стали
`#REF!`. Причина не в копировании — в новом документе Google требует отдельного
разрешения на внешние URL в формулах: жёлтый баннер «Некоторые формулы пробуют
обмениваться данными с третьими сторонами» → **«Разрешить доступ»**. После
клика 442 фото поднялись сами. Порядок переноса важен: сначала листы-источники
(Юнит-экономика), потом те, что на них ссылаются (Сравнение), иначе ссылки
превратятся в #REF! уже необратимо.
