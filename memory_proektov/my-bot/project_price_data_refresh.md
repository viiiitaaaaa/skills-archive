Обновить ТОЛЬКО цены (наши из кабинета + конкурентов из Evirma), не трогая
фото, цвет, рейтинг и финотчёты — это шаги 1–3 и 8 из `run.bat`:

1. `node toggle.js` — фильтр «С остатками» в кабинете;
2. `python wb_spp8.py spp8.csv --no-stock` → `spp8.csv` (наши цены и СПП);
3. `node pipeline.js --full` — заливает лист «Цены» и выгружает Evirma
   по каждому артикулу в `excel/` и лист «Evirma»;
4. `node compare.js` — пересборка «Сравнения»; фото/цвет/рейтинг берутся из
   `photo-cache.json`, `color-cache.json`, `my-goods.json`, то есть шаги 4–7
   можно спокойно пропускать;
5. `node pricing.js` — колонки K..Z; при желании `node price-scenarios.js`.

Chrome нужен свой: `--remote-debugging-port=9222 --user-data-dir=C:\chrome-wb`.

**Поломки, найденные 01.08.2026 (все починены в коде):**
- `wb_spp8.py` цеплялся Selenium'ом к ПЕРВОЙ вкладке, а не к активной, и читал
  случайную карточку товара → «холдер не найден». Теперь ищет вкладку по URL.
- Ценовая ячейка WB бывает в трёх видах: `451 ₽ / СПП 13,8% / 389 ₽`,
  `451 ₽ / СПП / 451 ₽` (процент не показан = СПП 0) и просто `451 ₽`.
  Старая регулярка знала только первый — 46 из 122 строк уходили ПУСТЫМИ
  (пустели разом цена после скидки, СПП и витрина).
- `harvest()` запоминал строку при первой встрече и больше не обновлял, а блок
  СПП догружается с задержкой → рано пойманные строки навсегда оставались
  неполными. Теперь строка заменяется, если ценовая ячейка стала полнее.
- Блок Evirma на карточке стал СВЁРНУТЫМ: кнопки «Экспорт в Excel» нет в DOM,
  пока не кликнуть «показать блок». Без этого падало по таймауту на каждом
  артикуле. Расширение при этом установлено и работает — проверять надо не
  наличие расширения, а текст «показать блок» на странице.
- `pipeline.js` дописывал лист «Evirma», никогда его не чистя: там копились
  прогоны внахлёст (4880 строк вместо 2420, старые цены вперемешку со
  свежими). Теперь `--full` = очистка + перевыгрузка, без флага = догрузить
  недостающие артикулы (полезно после сбоев: с первого прохода упало 7 из 122,
  повторный запуск без флага их добрал).

**Проверять покрытие «Сравнения» только формулами В КНИГЕ.** gviz отдаёт кэш
(бывало 93 строки при 443 в листе), из-за чего блок формул строился короче
листа и нижние строки оставались пустыми. В `pricing.js` пол теперь 520 и есть
`--last=N`. Перейти по адресу в `AB1` НЕЛЬЗЯ — в листе всего 26 колонок (до Z),
поле имени такой адрес не принимает; контрольные формулы надо писать во
временный лист через Apps Script (формулы в строках он принимает).

**Факт на 01.08.2026:** WB обнулил СПП почти по всему ассортименту — цена после
скидки продавца прежняя, а витрина выросла примерно на 10 % (452 → 502,
716 → 795). Все расчёты до этой даты считались от старой витрины.
