Её голосовое 15.10: PDF для китайского партнёра называть по-китайски (например «简历 — Vita — …», «合作提案 — …»).
Страницы — кнопки English / 中文 / Русский (русский — чтобы она сама проверяла); шрифты только системные — Google Fonts в Китае не открываются.
**Why:** получатель китаец; имя файла и шрифт — первое, что он видит. **How to apply:** любой пакет китайцу — так; PDF печатать Chrome headless через ASCII-путь в scratchpad и копировать с китайским именем. См. [[pitch-kitay-korotkiy-15-10]].
