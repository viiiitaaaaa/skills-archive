Когда она просит книги и авторов — давать сразу чистый список «Название — Author (издательство)».
Имена авторов не транскрибировать по-русски, пояснения не добавлять.

**Why:** 15.10.2026: «не пиши русским автор, просто дай список книг и авторы сразу».
**How to apply:** любой список книг/курсов для покупки — одна строка на книгу, без лишнего.
