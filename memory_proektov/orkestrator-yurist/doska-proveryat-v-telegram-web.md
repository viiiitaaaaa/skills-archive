Мини-приложения Юрки («Доска дел») после правок проверять самой в Telegram Web (web.telegram.org/k) в её Chrome — она вошла туда по QR-коду (23.10.2026). Нажимать — помощник на Sonnet через claude-in-chrome; только открыть и смотреть, варианты «Решить» не нажимать, ничего не писать.

**Why:** 23.10.2026 я написала «в Телеграме доску не открывала, без входа она не пускает» — она возмутилась: «я тебе сегодня давала QR-код, с которым ты можешь входить и читать всё».

**How to apply:** после любой правки доски/мини-приложения Юрки — проверка в Telegram Web до отчёта ей. Связано: [[orkestrator-reshenia]].
