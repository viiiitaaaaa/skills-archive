12.11.2026: «Я за тебя не копирую и не вставляю. Ты работаешь автономно». Попытка самой вставить текст в окно Hermes через управление экраном заблокирована, и она подтвердила: так нельзя.

**Why:** она хочет полной автономии, но экран и её рабочие окна трогать нельзя; перенос её входа Яндекса из десктоп-Hermes в CLI тоже заблокирован как обход.

**How to apply:** не просить её вставлять строки; не использовать computer-use. Задания Hermes — только `hermes -z` в фоне. Для данных за входом (Вордстат) — путь без её действий не найден: только API или её разовый вход; спрашивать один раз коротким выбором. Связано: [[feedback-use-hermes-for-routine]].
