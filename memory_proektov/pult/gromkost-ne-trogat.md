Громкость динамиков Windows (и любые системные настройки звука) не менять самой и не включать звук вслух для проверки без её прямого слова «сделай громче / включи».

**Why:** 18.10.2026 ночью я подняла громкость с 6% до 45% и прочитала фразу вслух — «Зачем ты сейчас увеличила звук? Чуть не разбудила». 6% у неё стоит нарочно.
**How to apply:** если её не слышно из-за громкости — сказать одной строкой «громкость в Windows N%, прибавь, если хочешь слышать», и всё. Проверки голоса — только в файл ([[ozvuchka-tolko-po-prosbe]]).
