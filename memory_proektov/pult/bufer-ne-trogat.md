Проверки вставки/копирования — без записи в её буфер обмена: подменять чтение буфера в коде пробы (readText → «проба»), а не clipboard.writeText.

**Why:** 23.10 проба дубля Ctrl+V записала в буфер «проба», зависла и не вернула прежнее — её скопированный текст пропал.
26.10 (предположение-урок, замечено самой): в пробе через node-pty выделила мышью слово в строке Claude — Claude Code
сам копирует выделенное в буфер Windows (настройка copyOnSelect, по умолчанию вкл.), и её буфер стал «bbb».

**How to apply:** любые пробы с Ctrl+V/Ctrl+C в пульте и копиях; в пробах Claude НЕ слать ему выделение мышью
(SGR-перетаскивание `\x1b[<0;…M` → `\x1b[<32;…M` → `…m`) и правую кнопку — это пишет/читает её буфер; если без
буфера никак — сначала спросить её. Связано: [[pult-ne-uvodit]], [[pochinka-pulta-proveryat-vzhivuyu]].
