Если «Главная» сама запускает долгий фоновый скрипт без вкладки (например, расшифровка видео Whisper на ПК), сразу
поставить его на табло: `agent_status.py set <id> --title … --total N --glob "<готовые файлы>" --file "<лог>"` —
прогресс считается сам по числу файлов.

**Why:** 21.10.2026 расшифровку курса 5 запустила скриптом без вкладки — Вита: «мне не отобразилось, что она вообще
идёт, не открылась вкладка в работе».
**How to apply:** любой фоновый процесс дольше нескольких минут → табло в тот же ход; остановили — `agent_status.py rm <id>`.
